# 项目描述：CMB 各向异性综合分析系统

## 项目概述

本项目是一个宇宙微波背景辐射（CMB）各向异性的综合分析系统，涵盖从第一性物理（线性化爱因斯坦‑玻尔兹曼方程）到天体物理可观测量（角功率谱、声学峰、前景污染、卫星扫描策略）的全流程数值模拟。项目包含多个独立但顺序依赖的科学计算模块，通过 `main.py` 中的统一入口串联执行。

## 文件清单与职责

### `main.py`
统一调度入口。依次调用各模块完成宇宙学参数的初始化、微扰演化求解、转移函数插值、角功率谱积分、声学峰定位与峰间距比计算、球面网格生成、巡天掩膜几何分析、前景污染模拟与边缘检测、卫星姿态动力学和扫描覆盖性评估、以及参数拟合和 Fisher 矩阵预测。最终输出运行时间和总体状态。

### `utils.py`
基础数学工具库，提供以下纯数学算法：
- **Lanczos 近似 Gamma 函数**及对数 Gamma 函数
- **球 Bessel 函数** j_l(x)：使用向上递推（从 j_0、j_1 开始），处理小自变量的渐近行为，支持数组化的批量计算
- **连带 Legendre 函数** P_l^m(cosθ)：基于 Ferrers 定义的递推实现
- **Wigner 3j 符号** (j1 j2 j3; 0 0 0) 的简化解析形式（用于 Gaunt 积分）
- **二项式系数** C(n,k)
- 若干数值鲁棒性函数：安全除法、区间裁剪到 [-1,1]、正数断言、2 的幂次判定

### `boltzmann_solver.py`
线性化爱因斯坦‑玻尔兹曼方程求解器，负责单个 k 模式（共动波数）下的光子‑重子流体微扰演化。
- **CosmologyParams 类**：存储 ΛCDM 宇宙学参数（普朗克 2018 型）。
- **BoltzmannSolver 类**：
  - 内部维护共形时间 η 网格（均匀步长）。
  - 通过分段解析近似计算尺度因子 a(η)、共形 Hubble 参数 H(η)、汤姆孙散射不透明度 τ'(η)（含简单重组拟合）。
  - 求解变量：光子单极 Δ_0、偶极 Δ_1、四极 Δ_2、重子速度 v_b、引力势 Φ。
  - 右端项利用紧耦合近似处理强散射时期的滑移 Δ_1−v_b，同时给出引力势演化的泊松约束简化模型。
  - 采用改进 Euler 法（预测‑校正）进行时间积分。
  - 提供 `transfer_function_today` 方法，基于复合时期声视界和 Sachs‑Wolfe 近似计算今天的转移函数 T(k)。

### `transfer_function.py`
CMB 转移函数的 Chebyshev 谱插值。
- **ChebyshevInterpolator 类**：在任意区间 [a,b] 上，使用第一类 Chebyshev 节点采样目标函数，通过离散余弦变换计算谱系数，并用 Clenshaw 递推实现稳定、快速的求值。
- **TransferFunctionComputer 类**：
  - 保持参数化解析转移函数模型 T_l(k)，包含球 Bessel 函数（基于 η_0−η_rec）、Silk 阻尼因子、声学峰调制。
  - 对每个多极矩 l 预计算一个 ChebyshevInterpolator 对象，实现 O(1) 的转移函数查询。

### `los_integration.py`
线‑of‑sight 快速数值积分模块。
- **Gauss‑Legendre 节点与权重**：通过 Jacobi 矩阵特征值分解（Golub‑Welsch 算法）计算。
- **Fejér 第一/二型节点与权重**：分别基于余弦开节点集，权重利用 FFT 加速或三角级数求和计算。
- **Clenshaw‑Curtis 节点与权重**：基于包含端点的余弦节点，权重由离散余弦变换得出。
- **FastQuadrature 类**：统一接口，将任意被积函数从 [−1,1] 线性映射到给定区间 [a,b]。
- `los_integral_power_spectrum`：实现角功率谱的单 k 积分 C_l = 4π ∫ (dk/k) P_R(k) |T_l(k)|^2。
- `compute_sachs_wolfe_integral`：计算 Sachs‑Wolfe 线‑of‑sight 积分，包含可见度函数的高斯近似和球 Bessel 函数求值。

### `power_spectrum.py`
角功率谱计算与声学峰定位。
- `primordial_power_spectrum`：给定标量谱指数和振幅的原初功率谱。
- `bisection_root`：经典二分法求根算法（要求端点异号，线性收敛）。
- `find_acoustic_peaks`：通过对平滑功率谱进行数值微分检测正‑负斜率变化，在变号区间内使用二分法定位峰位，并插值给出峰值 C_l。
- `compute_peak_spacing_ratio`：计算相邻峰的 l 比值（平均）。

### `spherical_mesh.py`
球面三角剖分与像素化（HEALPix 风格）。
- 生成单位球内接二十面体（12 顶点，20 面）。
- `subdivide_mesh`：对网格进行一次 4 等分细分，利用边中点唯一化、归一化到球面。
- **SphericalMesh 类**：
  - 支持任意细分级别，计算顶点、面、邻居关系。
  - 利用 L'Huilier 定理计算球面三角形面积。
  - 提供面积总和校验、节点球坐标获取、网格文本输出（节点、单元、邻居，采用基于 1 的索引）。

### `mask_beam.py`
巡天掩膜几何与波束卷积。
- 多边形几何矩计算（Green 定理转化为边界线积分，支持任意阶 (p,q)），用于面积、质心、椭圆率。
- 点在多边形内判断（射线交叉法，处理边界情况）。
- 圆盘矩积分（解析，利用 Gamma 函数），用于波束等效建模。
- 高斯波束窗函数 B_l 及对 C_l 的卷积（B_l^2 因子）。
- **SurveyMask 类**：封装掩膜几何描述子（面积、质心、椭圆率、包含判断、球面覆盖比例 f_sky）。

### `foreground_edges.py`
前景污染模拟与边缘检测。
- 生成双 C 形合成数据（两种嵌套的弧形分布，用于模拟前景成分在参数空间中的聚类结构）。
- 模拟银道面附近的温度剖面（高斯形状加噪声）。
- 一维边缘检测：在滑窗内分别对左右邻域进行线性最小二乘拟合，比较斜率差异并标记跳变点。
- Shepp‑Logan 二维幻影生成（10 个椭圆叠加，强度缩放），作为标准边界测试图像。
- 二维 Sobel 梯度边缘检测：计算离散梯度幅值，超过阈值标记为边缘。
- 前景残留 RMS 评估（给定掩膜区域）。

### `satellite_dynamics.py`
卫星刚体姿态动力学与扫描策略。
- **GyroscopeDynamics 类**：
  - 描述刚体绕质心的欧拉角 + 角速度演化，包含外力矩（简化重力梯度）。
  - 使用四阶 Runge‑Kutta 积分，并在欧拉角运动学中处理 sinθ 奇点的正则化。
- 生成 Planck 型扫描轨迹：自转轴以固定倾角和进动速率旋转，卫星绕自转轴高速旋转，计算 boresight 指向在球面上的 (θ,φ) 序列。
- 将扫描轨迹映射到命中图（经纬度像素网格），计算覆盖均匀性（1 − σ/μ）。

### `parameter_fit.py`
参数最小二乘拟合与 Fisher 预测。
- 实现 Householder QR 最小二乘求解器，对病态矩阵自动回退到 SVD 截断。
- 提供病态
