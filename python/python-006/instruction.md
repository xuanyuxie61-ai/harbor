## 项目描述

# 项目描述：中子星物态方程与致密物质多物理场数值模拟平台

本项目是一个面向中子星内部物理的多模块科学计算代码库，涵盖核物质状态方程（EOS）、星体结构（TOV 方程）、地壳晶体与核 pasta 相、中微子扩散输运以及数值算法稳定性验证。代码主要采用 Python，依赖 NumPy 等科学计算库，按功能拆分为多个源文件，并由一个入口脚本 `main.py` 串联执行所有计算阶段。

## 文件与职责

- **`utils_physics.py`**  
  提供天体物理基本常数（牛顿引力常数、光速、核子质量等）、几何化单位转换基础、费马素性检验生成伪随机素数种子、ROT13 字符串编码/解码工具、安全的数学运算（平方根、除法）以及费米动量和数密度之间的转换函数。

- **`eos_legendre.py`**  
  实现与核物质状态方程紧密相关的两类功能：  
  1. **连带 Legendre 多项式计算**：采用递推算法计算 \(P_n^m(x)\)，并基于多项式展开计算角度依赖的相互作用势。  
  2. **Skyrme 型状态方程类**（`SkyrmeEOS`）：利用 Skyrme 有效相互作用参数（如 SLy4 参数组）计算非对称核物质的能量密度、压强、化学势、对称能及声速平方。  
  此外还包含 **多方物态方程类**（`PolytropicEOS`）用于高密度物态描述，以及构建拼接 EOS 的可调用对象函数。

- **`tov_solver.py`**  
  TOV（Tolman-Oppenheimer-Volkoff）方程数值求解模块。将方程置入几何单位制（长度基准 km），使用自适应步长的四阶 Runge-Kutta 方法从给定中心压强积分到星体表面，获得质量、半径等结果。  
  提供函数进行参数扫描以构建质量-半径关系，并支持潮汐形变参数 \(\Lambda\) 的近似计算。

- **`crust_integrals.py`**  
  处理中子星地壳中核 pasta 相（gnocchi、lasagna、spaghetti）所需的多区域数值积分。  
  包含：  
  - 三角形/四边形/楔形区域上单项式的精确积分值计算，用于检验积分规则的精确度。  
  - Witherden-Vincent 四边形积分规则（低阶显式节点与权重）。  
  - 基于三角形、四边形和楔形区域积分的简化物理模型，估算不同 pasta 结构的自由能密度。

- **`lattice_grid.py`**  
  负责晶格网格生成与弹性力学相关数值计算。  
  包含：  
  - 在任意多边形内部通过重心坐标细分生成规则网格点。  
  - Gauss-Jordan 消元法求解线性方程组（用于弹性平衡方程）。  
  - 构建六边形紧密排列晶格并生成三角形单元，基于有限元方法估算地壳的剪切模量。

- **`neutrino_diffusion.py`**  
  中微子输运方程的一维数值求解。  
  定义扩散-对流-反应 PDE 的参数与系数函数，并采用显式有限差分法（满足 CFL 条件）推进电子丰度和温度演化。  
  提供计算中微子总光度和电子丰度弛豫时标的后处理函数。

- **`matrix_stability.py`**  
  矩阵数值稳定性分析工具，用于评估病态问题对 EOS 反演等计算的影响。  
  功能包括：  
  - 下三角矩阵行列式计算与求逆。  
  - 生成 Hilbert 矩阵及其精确逆矩阵。  
  - 基于 SVD 的条件数估计。  
  - 构造 TOV 线性化稳定性矩阵并进行特征值稳定性分析。  
  - 在 Hilbert 矩阵上进行线性求解的误差测试。

- **`quadrature_verify.py`**  
  高精度数值积分规则的生成与验证。  
  通过三对角 Jacobi 矩阵的特征值分解生成 Gauss-Hermite 和广义 Gauss-Laguerre 积分的节点与权重。  
  基于 Hermite、Chebyshev、Laguerre 正交多项式的精确积分公式，检验不同阶数积分规则的数值误差，并验证物态方程相关积分（如费米-狄拉克积分）的精度。

- **`main.py`**  
  项目的统一入口脚本，无需命令行参数。依次执行八个计算阶段：  
  1. 物态方程与 Legendre 展开测试  
  2. TOV 结构计算与质量-半径参数扫描  
  3. 地壳多区域积分验证与 pasta 相自由能估算  
  4. 晶格网格生成与弹性常数估算  
  5. 中微子扩散演化与输运特征量计算  
  6. 矩阵稳定性分析（病态 Hilbert 矩阵、特征值检验）  
  7. 积分规则精度验证  
  8. 综合摘要与 ROT13 编码输出  

## 模块间关系

`main.py` 作为顶层控制流，依次导入并调用所有其他模块中的关键函数与类。  
- **物态方程链**：`eos_legendre` 提供物态方程对象，`tov_solver` 使用该 EOS 的可调用形式 (`eps_of_P`) 进行 TOV 积分。`quadrature_verify` 验证 EOS 计算中出现的积分形式的数值精度。  
- **地壳结构链**：`crust_integrals` 和 `lattice_grid` 分别负责核 pasta 相的能量积分和晶格力学的离散化，两者共同为中子星地壳的物性估计提供支持。  
- **输运与稳定性链**：`neutrino_diffusion` 单独处理中微子相关的 PDE 演化；`matrix_stability` 单独检验所用线性代数算法的数值可靠性，其测试对象包括 TOV 稳定性矩阵及 Hilbert 矩阵等经典病态系统。  
- **基础工具**：所有模块共享 `utils_physics` 提供的物理常数、安全运算函数和种子生成工具。

## 实现要点总结

- 所有物理量均使用统一的单位转换模块，TOV 方程在几何单位制下积分，物态方程能量和压强可在物理单位（MeV/fm³）与几何单位之间转换。  
- Legendre 多项式使用稳定递推公式，避免直接计算高阶导数的数值溢出。  
- 积分规则（三角形、四边形、楔形、Gauss 型）的精确度通过单项式检验（exactness test）量化评估。  
- 有限差分求解中微子扩散时，通过 CFL 条件自动选择时间步长，并使用迎风格式处理对流项。  
- 矩阵求解（Gauss-Jordan）和条件数分析注重演示病态系统的行为，不追求用于实际大型工程矩阵。  
- `main.py` 各阶段输出均为科学结果的简要展示与交叉验证，以确认各模块集成无误。

开发者需根据上述文件职责与函数接口，在保留 `main.py` 的前提下重新实现所有缺失的 `.py` 文件，使其能通过 `main.py` 中各阶段的调用并产生合理的物理结果与数字输出。
