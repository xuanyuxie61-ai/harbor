## 项目描述

# 分数量子霍尔效应：Laughlin态多体数值模拟平台

该项目是一个分数量子霍尔效应（FQHE）的多体数值模拟系统，围绕 Laughlin 波函数构建了从单粒子基函数、多体关联、平均场自洽、边缘态到拓扑不变量计算的完整工具链。所有模块由一个主入口 `main.py` 调度，执行零参数即可运行的完整模拟流程。

## 文件功能概览

### `utils.py` — 物理常数、数值工具与基本物理量
- 定义自然单位制下的常数（约化普朗克常数、电子电荷等）。
- 提供数值稳定性函数：安全的指数、对数、向量归一化、矩阵条件数、格拉姆‑施密特正交化、费米‑狄拉克分布。
- 实现基础物理量的计算：磁长度、回旋频率、Landau 能级能量、填充因子、二维高斯函数。  
这些函数被项目中所有其他模块调用。

### `landau_levels.py` — Landau 能级与单粒子基函数
- 在对称规范下计算 Landau 轨道波函数，利用复坐标、角动量量子数和连带 Laguerre 多项式，包含自动归一化与边界情况处理。
- 提供一维谱有限元基函数及其导数，用于径向方程的谱展开，并构建相应的刚度矩阵。
- 实现局部拉格朗日插值基函数和一维有限元求值，用于检验单元精度。
- 计算单个 Landau 能级的简并度，以及用洛伦兹展宽的态密度函数。

### `laughlin_wavefunction.py` — Laughlin 多体波函数与准粒子激发
- 计算 Laughlin 波函数（包括对数形式以避免乘积极大/极小），支持 Jastrow 因子和高斯包络。
- 构建准空穴和准电子波函数，插入位置携带分数电荷。
- 从电子构型计算配对关联函数 g^(2)(r)（通过距离直方图并归一化到圆盘面积）和静态结构因子 S(q)（对方向角平均）。
- 用于分析多体关联的幂律行为和结构因子特征。

### `monte_carlo_sampler.py` — 准蒙特卡洛采样与变分 Monte Carlo
- 生成 Hammersley 低差异序列，基于素数的 radical inverse 函数。
- 将二维序列映射到圆盘或环形区域（面积保持映射）。
- 实现变分 Monte Carlo 能量估计器：使用 Metropolis‑Hastings 采样，根据波函数的对数概率接受提议构型，收集局部能量样本并计算期望值和统计误差。
- 提供准蒙特卡洛积分器，对给定函数在 Hammersley 点集上求均值并乘区域体积。

### `hartree_fock_solver.py` — 自洽 Hartree‑Fock 求解器
- 数值代数工具：共轭梯度法（CGNE）求解正则方程 AᵀAx = Aᵀb，用于最小二乘问题；Newton 迭代法求解非线性方程组，支持阻尼和自动正则化。
- 实现二维电子气的屏蔽库仑势（含短程截断），构建 Hartree‑Fock 有效哈密顿矩阵：包括单粒子能、Hartree 势（离散卷积）和简化的非对角耦合。
- 提供自洽迭代求解器：根据当前基函数和占据态构造密度、HF矩阵，对角化后更新单粒子轨道，利用密度混合增强收敛性。
- 该模块使用 `landau_levels` 中的 Landau 轨道波函数作为初始基。

### `edge_state_solver.py` — 边缘态 BVP 求解与手性 Luttinger 液体
- 提供欧拉法 ODE 积分器，用于初值问题。
- 实现打靶法求解二阶 ODE 边值问题：通过猜测初始斜率，将 BVP 转化为 IVP，用割线法迭代修正。
- 构建边缘态径向 ODE，包含磁场、有效质量和角动量项。
- 提供手性 Luttinger 液体的线性色散关系，以及热展宽下的一维态密度。
- 包含一个带有稳定化的爆炸型 ODE 模型，用于模拟临界非线性增长。

### `density_evolution.py` — 密度矩阵演化与反应‑扩散动力学
- 一维波动方程的有限差分解（中心时间、中心空间格式），自动调整时间步长以保证稳定性。
- Fisher‑KPP 反应扩散方程的行波精确解及各阶导数，以及有限差分数值解（前向 Euler + 零通量边界）。
- 模拟开放量子系统的 Lindblad 主方程演化：采用欧拉步进，在每步后强制密度矩阵的厄米性、迹归一和半正定性。

### `correlation_functions.py` — 关联函数与最近邻分析
- 实现针对两组点集的最近邻搜索算法（双重循环）。
- 提供高维空间的距离统计：在单位超球内均匀采样并计算配对距离的均值和方差；在超立方体表面上采样并统计。
- 计算量子霍尔系统的两点关联函数 g^(2)(r)，通过电子距离直方图并基于二维环形壳面积进行归一化。
- 计算密度‑密度关联函数（静态结构因子）：对二维密度格点做 FFT，对波矢方向进行径向平均。

### `quadrature_integrals.py` — 高维数值积分与精确性检验
- 实现组合枚举算法，将整数分割为定数目的非负整数部分。
- 提供单项式在楔形体上的精确解析积分公式，以及通用计算函数。
- 构建一维 Gauss‑Legendre 求积节点和权重，并扩展到二维、三维张量积积分。
- 检验给定求积规则在楔形体上的多项式精确性。
- 专门针对库仑势，在二维极坐标下实现 Gauss 求积并对比解析结果。

### `topological_invariants.py` — 拓扑不变量：Berry 相位与 Chern 数
- 离散化 Berry 联络的计算（利用波函数重叠的相位差）。
- 用四点 plaquette 公式计算二维参数空间的 Berry 曲率，并从中积分得到 Chern 数。
- 实现 TKNN 公式将 Chern 数转换为霍尔电导（以 e²/h 为单位）。
- 计算插入磁通量子时的 Berry 相位和分数电荷。
- 基于轨道参数演化思想，提供绝热角度参数化和三维坐标生成（受原始天文类比启发）。

### `main.py` — 主程序入口
- 按顺序导入所有上述模块，并设定统一的物理参数（磁场、有效质量、电子数、Laughlin 指数等）。
- 依次运行九个分析模块：
  1. Landau 能级与态密度
  2. Laughlin 波函数与准粒子激发
  3. 准蒙特卡洛采样与积分
  4. Hartree‑Fock 自洽场
  5. 边缘态求解与 Luttinger 液体
  6. 密度演化动力学
  7. 关联函数与最近邻分析
  8. 高维数值积分与精确性验证
  9. 拓扑不变量与 Chern 数
- 每个模块打印关键数值结果，最后汇总核心物理量。

## 模块间依赖关系
- 所有模块均依赖 `utils.py` 提供的基础函数和物理常量。
- `hartree_fock_solver.py` 调用 `landau_levels` 中的 Landau 轨道波函数作为初始基。
- `correlation_functions.py` 可接收来自 Laughlin 波函数或 Hartree‑Fock 生成的电子坐标。
- `monte_carlo_sampler.py` 通常用于采样 Laughlin 波函数的电子构型，以计算变分能量或关联函数。
- 其余模块之间相对独立，由 `main.py` 统筹调用。

## 关键算法与数值方法概述
- **波函数与积分**：Landau 轨道使用连带 Laguerre 多项式的解析公式；Laughlin 波函数通过乘积和求和实现，配有对数稳定版。多维积分采用 Gauss‑Legendre 张量积或准蒙特卡洛低差异序列。
- **线性代数**：CGNE 共
