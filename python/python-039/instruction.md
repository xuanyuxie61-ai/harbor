## 项目描述

# 项目描述：QGP-Transport — 重离子碰撞夸克胶子等离子体输运与相变动力学全链路模拟

本项目实现了一套用于模拟相对论重离子碰撞中夸克胶子等离子体（QGP）产生、演化和实验可观测量的计算工具链。核心内容涵盖核几何建模、三角网格生成、粘性流体力学演化、椭圆积分与色散关系、蒙特卡洛事件采样、SVD涨落分析、参数优化拟合、格点线性系统求解以及统计推断。所有模块通过一个统一的入口脚本串联。

项目包含以下 Python 源文件，每个文件负责一个相对独立的子领域。

## 文件职责概览

### `nuclear_geometry.py`
**核几何与 Woods-Saxon 分布建模**
- 提供 `NuclearGeometry` 类，封装两核碰撞的几何描述。
- 基于 Woods-Saxon 密度分布计算核子密度、厚度函数、重叠函数。
- 利用 Glauber 模型计算参与者数 `N_part`、二叉碰撞数 `N_coll`。
- 计算重叠区的二阶和四阶偏心距 `ε₂`、`ε₄`。
- 支持通过边界字追踪思想生成核表面离散化多边形。
- 被 `main.py` 和 `hydro_evolution.py` 等调用，提供初始能量密度分布所需的参与者密度剖面。

### `mesh_generator.py`
**三角网格生成与有限元基础操作**
- 提供 `MeshGenerator` 类，用于在横向平面生成均匀或自适应三角网格（基于密度函数加密）。
- 内部使用 SciPy 的 Delaunay 三角剖分。
- 实现三角形面积、质量（等边度量）、节点邻接数、边界节点识别。
- 支持在网格上积分标量场以及计算分段常数梯度。
- 主要用于为流体力学演化提供空间离散化，与 `hydro_evolution.py` 配合。

### `hydro_evolution.py`
**2+1 维相对论粘性流体力学演化**
- 提供 `HydroEvolution` 类，描述纵向 Bjorken 膨胀下的横向演化。
- 包含状态方程（`P = c_s² ε`）、能量–温度转换（Stefan-Boltzmann 近似）、比熵密度。
- 实现一维 Bjorken 解析解（含一阶粘滞修正）和二维显式欧拉格式演化。
- 可计算冻结面（温度降到指定值的时间）、横向流速近似（基于压力梯度）、以及粘性熵产生率。
- 是核心的动力学模块，从 `main.py` 接收初始能量密度分布并推进至冻结。

### `elliptic_integrals.py`
**Carlson 对称形式不完全椭圆积分**
- 提供函数 `rf_carlson`、`rc_carlson`、`rd_carlson`、`rj_carlson`，使用迭代平均算法计算 RF、RC、RD、RJ 积分，具有错误检测。
- 提供 `QGPDispersionRelation` 类，将椭圆积分应用于：
  - 胶子能量损失简化模型（RC 积分）
  - 部分子横向动量展宽（RF 积分）
  - 双轻子谱函数（RJ 积分）
- 属于物理应用层，模块依赖较单一，可为流体力学后续的硬探针计算提供工具。

### `random_generator.py`
**混合伪随机数生成器**
- 提供 `MiddleSquareHybrid` 类，将中平方法与线性同余生成器混合，生成均匀分布随机数，并可分析序列周期。
- 提供 `QGPEventSampler` 类，基于上述生成器实现：
  - 碰撞参数分布采样（dN/db ∝ b）
  - 相对论热动量分布采样（拒绝采样）
  - 含椭圆流调制的方位角采样
  - 高斯涨落采样（Box-Muller 变换）
- 为蒙特卡洛事件生成和参数扫描提供基础随机源。

### `monte_carlo_sampler.py`
**组合计数与部分子级联**
- `CombinatorialPhysics`：计算物理中组合数（第二类 Stirling 数、Bell 数、整数分拆数、子集和计数），主要用于胶子色单态计数和相空间体积。
- `HistogramAnalysis`：对数据计算直方图、概率密度、累积分布及统计量（均值、方差、偏度、峰度及各阶中心矩）。
- `PartonCascade`：简单的部分子级联模型，包含 DGLAP 分裂函数近似、多重数分布模拟、喷注能量谱分析以及胶子色单态组合数估计。
- 模块内部使用组合数学，并与随机采样结合。

### `svd_analysis.py`
**事件涨落的 SVD/PCA 分析**
- `EventSVDAnalyzer`：对多个事件的空间分布矩阵进行 SVD 分解，提取主成分模式、计算解释方差比例、重建数据、将新事件投影到主成分空间。
- `FlowHarmonicDecomposition`：提供流谐波相关计算，包括流矢量构造、从椭圆流反推初始偏心距、以及基于粒子方位角的二阶和四阶累积量 `v₂{2}`、`v₄{4}`。
- 用于理解事件间涨落模式和集体流特征。

### `parameter_optimization.py`
**参数优化与实验数据拟合**
- `QuadraticOptimizer`：基于三点二次插值的单变量优化器，用于寻找目标函数的极小值。
- `QGPParameterFit`：利用上述优化器拟合 QGP 模型参数：
  - 通过椭圆流 `v₂(pT)` 拟合比剪切粘滞系数 `η/s`
  - 通过平均横动量拟合声速平方 `c_s²`
  - 通过带电粒子赝快度密度拟合初始热化时间 `τ₀`
  - 联合拟合所有参数。
- 为从物理观测量反推 QGP 物理参数提供优化框架。

### `linear_solver.py`
**线性系统求解、误差检测与格点 Dirac 方程**
- `RREFSolver`：基于行简化阶梯形（RREF）求解线性方程组，并以此实现矩阵求逆、秩和行列式计算。
- `HammingErrorDetection`：利用 Hamming(7,4) 码的思想对线性系统解进行冗余校验和单比特纠错。
- `LatticeDiracSolver`：构造简化的 Wilson-Dirac 矩阵（自由场）并求解格点 Dirac 方程。
- 将数值代数技术与格点 QCD 线性求解及可靠性检验关联。

### `statistical_inference.py`
**统计推断与相变分析**
- `NonCentralTDistribution`：非中心 t 分布的累积概率近似计算及分位数二分搜索。
- `BisectionInteger`：整数域上的二分求根。
- `QGPStatisticalInference`：利用上述工具进行物理统计推断：
  - 参与者数偏离的显著性检验
  - 椭圆流信号显著性（考虑系统误差）
  - 临界温度的置信区间估计
  - 基于热 susceptibility 的相变临界点定位（含二次插值精化）
- 提供从实验数据得出物理结论的统计方法。

### `main.py`
**全链路模拟入口**
- 零参数可运行的主脚本，串联上述所有模块。
- 执行流程：
  1. 核几何建模（Au+Au 碰撞）
  2. 重叠区自适应三角网格生成
  3. 二维粘性流体力学演化（含一维 Bjorken 对比）
  4. 椭圆积分计算与色散关系物理量（能量损失、动量展宽、双轻子谱）
  5. 混合随机数生成与蒙特卡洛事件采样
  6. 组合数学与部分子级联、直方图分析
  7. SVD 事件涨落分解与流谐波累积量分析
  8. 参数优化拟合（η/s、c_s²、τ₀）
  9. 线性系统求解与 Hamming 误差检测、格点 Dirac 方程求解
  10. 统计推断与临界温度分析
- 输出各步骤的关键数值结果，不依赖外部配置文件。
