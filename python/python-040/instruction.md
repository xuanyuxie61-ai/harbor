## 项目描述

# BSM 新物理信号提取与共振峰重建数值分析平台

本项目构建了一套从探测器模拟、径迹重建、信号处理到统计推断的完整数值分析流程，用于在大型强子对撞机（LHC）的双轻子末态中寻找 Z' 共振信号，并评估超越标准模型（BSM）的参数空间排除能力。

## 模块概览

| 文件名 | 主要职责 |
|--------|----------|

## 各模块详细说明

### 1. `bsm_physics.py` – 物理模型核心
- 定义 `ZPrimeModel` 数据类，封装 Z' 玻色子的质量、总宽度、矢量/轴矢量耦合、动能混合参数，并在初始化时检查微扰幺正性边界。
- 实现 Breit‑Wigner 传播子（复数结构），用于计算 Z' 交换的振幅。
- 计算 e⁺e⁻ → ℓ⁺ℓ⁻ 过程的微分截面，包含 Z' 贡献与可选的标准模型 Drell‑Yan 背景，使用有效耦合因子和角分布。
- 提供有效场论（EFT）四费米子接触相互作用的截面修正，引入阻尼因子处理超出 EFT 有效范围的情况。
- 计算 Z' 到轻子对和强子对的部分衰变宽度，并检查输入总宽度与微扰计算的自洽性。
- 构建散射振幅矩阵，用于后续 SVD 分析。
- 提供简化的卡方统计量计算和 95% CL 排除限近似公式。

### 2. `detector_response.py` – 探测器响应模拟
- 使用 Lax‑Wendroff 格式求解一维平流‑扩散方程，模拟带电粒子在探测器材料中的能量沉积剖面（初始条件为 Bragg 峰近似）。
- 实现 NEWS（北‑东‑西‑南）边缘检测算子，用于从二维击中图中识别径迹边界。
- 生成模拟的 LHC 硅径迹探测器二维击中图，包含两条背对背轻子径迹及高斯噪声。
- 构建基于非周期平铺规则的探测器像素几何（准晶近似），用于研究非周期布局的影响。
- 参数化电磁量能器的能量分辨率，并加入高斯展宽。

### 3. `track_reconstruction.py` – 径迹重建与动量估计
- 将探测器各层的击中点关联问题建模为旅行商问题（TSP），使用启发式算法（2‑opt 交换与单点插入）优化击中点序列，形成完整径迹候选。
- 使用 Hermite 三次样条对径迹数据进行平滑插值，同时输出函数值、一阶导数、二阶导数和三阶导数。
- 从二维径迹坐标通过最小二乘圆拟合提取曲率半径，结合磁场强度估算横向动量。
- 采用一维有限元方法拟合径迹上的能量损失（dE/dx）分布，最小化数据拟合误差与光滑性惩罚项。
- 基于 dE/dx 中位数与动量关系进行简化的粒子鉴别（电子、缪子、π介子、质子）。

### 4. `shower_model.py` – 簇射与强子化模型
- 使用火焰增长 ODE 的隐式梯形法求解，类比电磁簇射的指数增长与饱和过程，并给出纵向能量沉积剖面。
- 利用 Burgers 方程的 ETD‑RK4 谱方法模拟强子化过程中的非线性能量激波传播，以 Fourier 空间处理粘性项。
- 生成基于 Lund 弦碎裂模型近似的强子化能量分布，采用 Beta 分布采样并施加能量守恒修正。

### 5. `signal_processing.py` – 信号处理与降维
- 对数据矩阵进行截断 SVD，生成低秩近似，用于提取信号事例的低维特征。
- 计算奇异值谱的归一化 Shannon 熵，量化事例结构的复杂度。
- 训练基于 SVD 主成分的信号/背景判别器：将事例向量化，投影到主成分空间，以投影范数作为判别分数，并自适应调整分数方向。
- 使用 PCA 保留累计方差达到阈值的主成分，实现噪声抑制。
- 在不变质量谱上通过滑动窗口局部信噪比寻找共振峰，返回峰位、超出计数和局部显著性。

### 6. `interpolation_utils.py` – 多维插值
- 对散乱二维数据点采用基于最近三点的重心坐标线性插值，若点位于三角形外则回退至反距离加权。
- 实现 Smolyak 稀疏网格方法：定义 Clenshaw‑Curtis 节点和层级映射，通过组合系数与 Lagrange 基张量积进行多维插值，用于 BSM 参数空间的高效采样。
- 提供 BSM 参数空间（质量、耦合）的二维双线性插值，从小截面表中查询任意参数点的信号截面。

### 7. `matrix_solver.py` – 特殊结构矩阵求解
