## 项目描述

# 项目描述：地震波全波形反演与层析成像综合系统

本项目是一个面向地球物理科研场景的数值模拟与反演框架，综合了波动方程正演、频域求解、随机噪声建模、贝叶斯不确定性量化、分形散射分析、自适应网格生成以及伴随状态全波形反演等关键技术。所有代码划分为多个功能模块，由主入口 `main.py` 统一调度，展示从速度模型构建到反演结果评估的完整流程。下文将描述各模块的职责和核心算法思路，不提供具体的实现细节或公式推导。

## 文件列表与职责概述

### `main.py`
项目入口文件。按顺序调用各模块的演示函数，执行完整的地震波正演与反演工作流，包括：速度模型生成、波动方程精确解验证、Helmholtz 频域求解、噪声建模、蒙特卡洛几何面积估计、分形散射分析、谱元法积分精确度测试、贝叶斯采样以及一维全波形反演与旅行时层析成像。程序结束时汇总各环节结果并计时。

### `velocity_model.py`
负责构建复杂的地下速度模型。综合了三种非均质性成分：
- 利用 2D Ising 蒙特卡洛模拟生成具有空间聚簇特征的岩相分布；
- 通过分形孔隙度场引入多尺度扰动；
- 可选地对模型进行 Centroidal Voronoi Tessellation (CVT) 自适应网格优化，并使用 Hermite 三次样条插值实现光滑连续的速度场。
该模块还包含 CVT 生成器优化、样条插值与积分等基础工具函数。

### `wave_propagation.py`
时间域波动方程求解与验证模块。提供：
- 一维声波方程的 RK4 时间积分求解器，支持吸收和反射边界条件；
- 双弹簧耦合系统（可类比粘弹性本构模型）的 ODE 定义与参数设置；
- 一维驻波精确解及其残差计算，用于验证数值算法的收敛性；
- 通用四阶 Runge-Kutta 积分器，被其他模块（如伴随反演）调用。

### `helmholtz_solver.py`
频域 Helmholtz 方程求解模块。实现：
- Arnoldi 正交化构建 Krylov 子空间基；
- Givens 旋转用于上三角化 Hessenberg 矩阵；
- GMRES 迭代算法求解大型非对称线性系统；
- 一维 Helmholtz 矩阵的构造，包含 Perfectly Matched Layer (PML) 吸收边界；
- 将复数系统转化为实数系统后调用 GMRES 求解频域波场。

### `noise_model.py`
地震噪声建模模块。基于 Ornstein-Uhlenbeck (OU) 随机过程对背景噪声进行仿真：
- 使用 Euler 和 Euler-Maruyama 方法离散 OU SDE，生成具有均值回归和指数型协方差的时间序列；
- 生成多道地震记录噪声矩阵；
- 扩展到二维空间生成速度模型的随机扰动场（通过稳态采样与空间平滑模拟随机非均匀性）。

### `monte_carlo_utils.py`
蒙特卡洛几何估计与网格质量检查模块。包含：
- 二维多边形有向面积计算及射线法点在多边形内判定；
- 四边形面积计算、凸性检查及点在凸四边形内判断；
- 基于均匀随机采样的蒙特卡洛面积估计、基于规则网格的面积估计；
- 利用 Hammersley 准随机序列的 QMC 面积估计；
- 相关的几何工具函数，用于地质构造面积估算和有限元单元质量评估。

### `inverse_problem.py`
全波形反演（FWI）与层析成像核心模块。包括：
- 观测数据与合成数据的 L2 残差计算；
- 伴随状态法计算速度模型梯度：先正演模拟得到波场残差，再反向时间积分伴随方程获得伴随波场，通过相关运算得到梯度，并进行平滑和 Tikhonov 正则化；
- 梯度下降迭代反演流程图，包含步长自适应调整和模型裁剪约束；
- 一维旅行时层析成像，基于梯形法则数值积分计算射线理论旅行时。

### `fractal_scattering.py`
分形散射特性分析模块。提供：
- Mandelbrot 集的逃逸时间算法，支持标量和数组输入；
- 基于逃逸时间的地震波散射强度场计算（结合高斯包络）；
- 迭代函数系统（IFS）生成分形点集（如蕨类叶片），用于模拟裂缝网络；
- 使用分数布朗运动谱方法生成具有指定分形维数的孔隙度扰动场。

### `quadrature_rules.py`
谱元法求积规则与精确度验证模块。提供：
- 多种正交多项式权函数（Legendre、Jacobi、Laguerre、Hermite 及其广义形式）下的单项式积分解析计算；
- 多维混合权函数的积分；
- Gauss-Lobatto-Legendre (GLL) 积分点和权重的计算；
- 对二维 GLL 求积规则的精确度进行数值测试。

### `bayesian_sampling.py`
贝叶斯不确定性量化模块。基于超几何分布模型：
- 实现从有限总体中无放回随机抽取 K 个不同整数的算法（Fisher-Yates 思想）；
- 模拟彩色弹珠抽取，输出各类别被抽中的数量；
- 计算双颜色 urn 的超几何概率质量函数（PMF）；
- 通过拒绝采样从先验分布中生成后验样本，实现参数不确定性估计。

## 主要算法关系与工作流

在 `main.py` 中，程序按以下顺序执行并展示各模块的功能：

1. **速度模型构建** (`velocity_model.py`)：生成具有多相分形特征的 2D 速度场，可在此基础上进行 CVT 优化和 Hermite 样条插值。
2. **波动方程验证** (`wave_propagation.py`)：利用驻波精确解验证求解器的残差，并演示双弹簧系统的特征频率分析。
3. **频域正演** (`helmholtz_solver.py`)：针对一维带低速异常体的速度模型，用 GMRES 求解 Helmholtz 方程得到频域波场。
4. **噪声建模** (`noise_model.py`)：生成 OU 过程噪声和二维速度扰动场，展示均值回归和理论稳态统计量。
5. **几何估计** (`monte_carlo_utils.py`)：对模拟的地质构造多边形，用 MC、网格法和 QMC 估计面积，并检查四边形网格质量。
6. **分形散射分析** (`fractal_scattering.py`)：计算 Mandelbrot 逃逸时间、散射强度场、IFS 分形点集和孔隙度场。
7. **求积规则验证** (`quadrature_rules.py`)：测试 GLL 积分点对多项式被积函数的精确度，并计算混合积分实例。
8. **贝叶斯采样** (`bayesian_sampling.py`)：演示岩相 urn 模型抽样和超几何分布 PMF，通过拒绝采样估计后验参数分布。
9. **全波形反演与层析** (`inverse_problem.py`)：生成带低速异常的真速度模型和线性背景的初始模型，用 RK4 正演产生含噪声的观测数据，通过伴随状态法梯度下降迭代更新速度模型，比较初始模型与反演结果的残差和误差，并输出旅行时对比。
10. **CVT 优化** (`velocity_model.py`)：独立展示观测网生成器的均匀布设优化过程，计算最近邻距离标准差以评估均匀性。

整个项目通过上述模块的协作，示范了从介质建模、波场计算、不确定性分析到反演成像的完整科研计算流程。所有模块之间通过清晰的数据接口（如 NumPy 数组、网格参数、随机数生成器）传递信息，各算法均基于标准数值方法实现，可根据本描述独立复现。
