## 项目描述

# 项目描述：海啸生成与传播的数值模拟系统

本项目是一个模块化的海啸生成与传播模拟系统，融合了多个数值算法来模拟海底地震引发的海啸全生命周期。系统包含断层破裂动力学、初始海面位移计算、随机地形生成、球面几何校正、网格插值与排序、自适应多分辨率覆盖、并行任务调度、矩阵链优化、浅水波方程求解、能量守恒检验以及不确定性量化等模块。

主程序 `main.py` 负责调用各模块完成完整的模拟流程，其余 `.py` 文件为功能模块，各自封装一个独立的科学计算组件。后续将仅保留 `main.py`，你需要根据本描述实现所有缺失的模块。

## 模块文件说明

### `bathymetry_sampling.py`
**随机海底地形生成器**  
提供 `BathymetryGenerator` 类，接收网格坐标数组，生成统计上合理的随机海底地形。主要方法包括：
- `generate_random_bathymetry`：利用 von Kármán 功率谱和傅里叶反变换生成高斯随机地形，可叠加双曲正切剖面的大陆坡，并通过迭代比例调整（IPF）修正边缘分布，最终返回水深矩阵（正值）。
- `generate_bathymetry_with_rcont_constraints`：基于 rcont 算法的思想，给定行总和与列总和约束，生成满足双向约束的随机二维地形表。

内部使用随机排列（unicycle）作为相位种子，并强制傅里叶系数共轭对称以保证实值输出。
