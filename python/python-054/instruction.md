# 项目描述：海洋酸化与碳循环综合模拟系统

## 项目概述
本项目是一个集成化的海洋碳循环与酸化模拟工具，将多个数值算法整合到一个统一的科学计算框架中。代码组织为多个 Python 模块，每个模块负责一类特定的科学问题或数值方法，通过 `main.py` 中的演示流程串联起来。主要涉及海洋碳酸盐化学平衡求解、一维垂向碳输送、观测数据插值、海洋锋面检测、有限元网格生成、三维数值积分、传感器网络优化、参数不确定性分析、碳封存深度优化和区域连通性图分析等。

后续将保留 `main.py` 作为主入口，其它模块需要根据下述描述重新实现。

## 各模块职责与核心算法

### 1. carbonate_chemistry.py
**职责**：海洋碳酸盐化学系统的核心计算，包括平衡常数求解、碳酸盐体系求解器以及海-气 CO₂ 通量计算。

**主要内容**：
- 根据温度、盐度计算海水碳酸盐系统中的关键平衡常数（K0, K1, K2, Kw, KB, Ksp 等），使用文献中公认的经验公式。
- 实现 **Muller 二次插值法** 作为非线性方程求根器，用于求解质子平衡方程，得到 [H⁺] 浓度；该求根器支持复数运算，通过三个初始点拟合抛物线并迭代收敛。
- 提供 `solve_carbonate_system` 函数，根据总溶解无机碳（DIC）、总碱度（TA）、温度、盐度，返回 [H⁺]、pH、各碳酸盐物种浓度、pCO₂、碳酸钙饱和度 Ω 等。
- 提供批量求解与海-气通量计算函数，通量采用 Wanninkhof 风速参数化及 Schmidt 数公式。

**与其它模块的关系**：被 `carbon_transport.py`、`uncertainty_analysis.py` 等调用，用于计算 pCO₂ 和碳酸盐状态。

### 2. carbon_transport.py
**职责**：海洋碳输送的常微分方程与反应-扩散方程求解，实现显式前向欧拉法、自催化碳酸盐动力学、一维垂向碳输送模型和箱式碳循环模型。

**主要内容**：
- 实现 **显式前向欧拉法** 积分器，用于求解 dy/dt = f(t,y) 的初值问题。
- 定义 **自催化碳酸盐动力学** 的右端项，模拟 CO₂、HCO₃⁻、CO₃²⁻、CaCO₃ 四种状态变量在 Gray-Scott 型自催化反应下的演化，包含自催化项 x*y²。
- 构建 **一维垂向水柱 DIC 输送模型**，采用有限体积法在均匀深度网格上离散，包含平流、扩散、生物泵（Michaelis-Menten 型光合作用消耗）、再矿化和海-气交换通量，使用欧拉法进行时间步进。
- 实现 **三箱碳循环模型**（大气-表层海洋-深层海洋），反映箱间交换通量、人为碳排放和 Revelle 缓冲因子对海洋吸收的抑制。
- 提供人为碳库存计算函数，基于工业革命前与现代 DIC 剖面之差进行垂直积分。

**与其它模块的关系**：调用 `carbonate_chemistry.py` 中的海-气通量计算和碳酸盐体系求解器；被 `main.py` 驱动演示。

### 3. front_analysis.py
**职责**：海洋二维场（温度、盐度、DIC 等）的锋面检测与梯度分析，基于图像边缘检测中的 NEWS 差分算子。

**主要内容**：
- 实现 **NEWS 梯度算子**，计算标量场在中心差分下的 L1 梯度幅度，用于快速边缘检测。
- 实现 **Sobel 梯度算子**，提供更精确的梯度幅度和方向计算。
- 提供 **多变量锋面检测** 函数，对各物理场进行归一化后，按权重组合 NEWS 梯度，通过百分位阈值提取锋面掩码。
- 提供锋面统计函数，计算锋面长度、平均梯度等信息。
- 包含一个简化的温跃层深度估算函数（当前为 demo 级别）。

**与其它模块的关系**：独立被 `main.py` 调用，用于生成锋面检测案例。

### 4. ocean_mesh.py
**职责**：二维海洋有限元四边形网格的生成与拓扑分析，服务于浅海数值模拟的前处理。

**主要内容**：
- 实现三角形面积、四边形面积、Q4 等参元形函数等基础几何计算。
- 生成 **矩形区域** 和 **半圆形区域**（山/海沟模拟）的四边形网格，网格节点坐标和单元-节点连接表。
- 从单元-节点连接计算 **节点邻接表**，用于构建有限元刚度矩阵的稀疏结构。
- 计算 **网格带宽**（上带宽、下带宽、总带宽），评估稀疏矩阵存储效率。
- 计算所有单元的面积、识别边界边，以及按面积加权在网格内随机采样。

**与其它模块的关系**：由 `main.py` 调用演示网格生成与带宽分析。

### 5. quadrature_engine.py
**职责**：三维数值积分引擎，用于计算海洋碳库存等体积积分，并支持非结构化网格上的积分和高维参数空间采样。

**主要内容**：
- 提供一维 Gauss-Legendre 求积节点和权重（支持若干阶），在三维长方体上构造张量积高斯求积规则。
- 实现 **立方体区域上的积分** 和专门针对 DIC 库存的积分函数（结合密度函数）。
- 实现基于 **Keast 规则** 的四面体数值积分，支持多个精度的重心坐标规则，并包含从参考四面体到物理四面体的映射。
- 提供 **单位超球面面积计算**、**均匀随机采样** 以及基于超球面的 Monte Carlo 积分，用于后续参数敏感性分析。

**与其它模块的关系**：被 `uncertainty_analysis.py` 和 `main.py` 调用，提供积分和采样能力。

### 6. region_connectivity.py
**职责**：海洋区域连通性图网络的数据结构与算法，用于分析各海洋功能区之间的碳输送路径。

**主要内容**：
- 定义 `OceanRegionGraph` 类，支持节点和边的增删、邻接表构建。
- 实现 **图的连通分量** 查找（DFS）、**Dijkstra 最短路径** 算法（距离定义为边权重的倒数，权重越大传输越容易）。
- 提供 **GRF 格式** 的序列化与反序列化，便于图文件的读写。
- 提供创建示例海洋盆地连通图的工厂函数，以及碳传输路径分析功能。

**与其它模块的关系**：独立模块，由 `main.py` 演示图分析与最短路径。
