## 项目概述

本项目是一个集成的大气科学数值模拟系统，用于中尺度对流系统（MCS）的预报与诊断。系统将多个物理过程模块化，涵盖热力学诊断、对流动力学、滞弹性压力求解、水汽通量辐合、随机微物理参数化、集合预报、不确定性量化、降水估算、地表通量积分以及观测网络优化等。主程序为 `main.py`，它按顺序调用各模块完成完整的预报流程并输出诊断结果。其余 Python 文件为被 `main.py` 依赖的功能模块，需根据本描述复现。

## 模块文件与职责

### 1. `thermodynamics.py` — 大气热力学核心
- 提供物理常数（干空气气体常数、水汽气体常数、比热、潜热、重力加速度等）。
- 实现饱和水汽压的 Clausius‑Clapeyron 公式。
- 提供 Lambert W 函数（用于隐式方程求解）和 log‑Gamma 函数（用于微物理分布）。
- 计算潜在温度、虚温、由温度/相对湿度/气压求比湿。
- 实现 Brent 求根法，用于精确定位 LCL、LFC、EL。
- 实现不动点迭代（带 Aitken 加速），用于饱和调整。
- 计算抬升凝结高度 LCL、湿绝热抬升气块温度、以及 CAPE 和 CIN 的垂直积分。

### 2. `vertical_quadrature.py` — 垂直积分高斯求积
- 基于 Golub‑Welsch 算法生成 Gauss‑Legendre 节点与权重。
- 实现区间 [a, b] 上的 Gauss‑Legendre 求积函数。
- 利用该求积方法计算可降水量（PW）、质量加权积分以及 CIN 的负浮力积分。所有积分均以气压为垂直坐标，采用线性插值获取廓线值。

### 3. `moisture_flux.py` — 水汽通量辐合模块
- 实现二维和三维场的中心差分梯度计算，边缘点使用单侧差分。
- 提供二维散度计算。
- 计算三维水汽通量辐合（MFC = -∇·(ρ qv V)），以及二维简化版本。
- 实现 9 点 Laplacian 模板（带周期性边界）和 5 点 Laplacian（支持 Dirichlet 或周期性边界）。这些算子用于对流动力学模块中的扩散项。
