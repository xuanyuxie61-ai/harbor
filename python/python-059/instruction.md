## 项目描述

# 气溶胶辐射效应与气候反馈综合分析系统（PROJECT_59）

## 项目概述
本项目实现了一套从气溶胶微物理参数化、辐射传输计算到统计分析与源区反演的综合科学计算工具。所有模块围绕大气气溶胶的理化特性与辐射效应展开，并由入口程序 `main.py` 串联运行。项目需要实现以下功能模块，每个模块对应一个 Python 源文件。

## 模块清单与职责

### 1. `aerosol_microphysics.py`
气溶胶微物理特性计算模块。  
- 提供对数正态粒径分布及其多模态叠加。  
- 基于离散网格的化学组分混合态分类（通过计数公式区分内混/外混态）并计算混合态指数。  
- 实现 Bruggeman 有效介质近似，用于从多组分体积分数及其复折射率计算等效复折射率。  
- 利用组合优化算法从连续粒径网格中选取最优粒径分档，并给出各档数浓度。  
- 提供小参数近似下的消光效率计算（适用于小粒径或 Rayleigh 区）。

### 2. `mie_scattering.py`
Mie 散射与相函数展开模块。  
- 通过递推关系计算勒让德多项式的值。  
- 生成 Henyey-Greenstein 相函数的勒让德展开系数，并计算该相函数本身。  
- 将勒让德系数重构为相函数值。  
- 使用简化物理近似（Rayleigh、几何光学、van de Hulst）计算 Mie 散射的消光截面、散射截面及不对称因子。

### 3. `radiative_transfer_solver.py`
一维平面平行大气辐射传输方程求解器。  
- 利用光学厚度和角度离散化（提供高斯‑勒让德节点）构建线性方程组，方程中包含 Henyey-Greenstein 散射相函数、单次散射反照率及可能的普朗克源项。  
- 使用逐次超松弛（SOR）迭代法求解辐射强度分布。  
- 由求解出的强度场计算辐射通量和大气加热率。

### 4. `monte_carlo_photon.py`
三维蒙特卡洛光子传输模拟模块。  
- 模拟大量光子在大气层中的随机游走：从层顶入射，按指数分布抽样自由程，使用 HG 相函数抽样新散射方向，并在层边界处逃逸或被地表吸收/反射。  
- 统计光子归宿（逃逸至层顶、地表吸收、大气吸收）及总光路长度。  
- 基于光路长度估计有效光学厚度。

### 5. `atmospheric_mesh.py`
全球网格与三角化质量分析模块。  
- 使用球面余弦定理计算经纬度点间的距离。  
- 生成均匀经纬度网格节点并构建距离矩阵。  
- 计算平面三角形的内角，并对给定三角剖分估计 Delaunay 离散度（基于最小角偏差）。  
- 定义高度均匀分层的大气垂直边界。  
- 对矩形节点生成简单三角化，并输出角度质量指标。

### 6. `inverse_source.py`
气溶胶源区反演定位模块。  
- 基于点源扩散模型将观测浓度转换为伪距离（使用 Lambert W 函数的近似）。  
- 通过经典多维标度法（cMDS）从距离差矩阵重建低维相对位置。  
- 结合已知站点位置和浓度梯度，通过加权平均和梯度方向估计源的实际坐标，并给出预测残差。

### 7. `aerosol_activation.py`
云凝结核活化动力学模块。  
- 根据 Köhler 理论计算给定粒子的临界过饱和度（需要考虑曲率效应与溶质效应）。  
- 使用 Logistic 增长方程的解析解描述活化分数随时间的变化，其中最大活化分数（承载量）由 Abdul‑Razzak & Ghan 参数化给出（依赖于过饱和度与临界过饱和度的比值及粒径几何标准差）。  
- 计算 CCN 谱的导数（dN/dlnS）以及综合数浓度。

### 8. `numerical_utils.py`
基础数值工具模块。  
- 实现二分法求根。  
- 利用对数伽马函数安全计算二项式系数。  
- 根据字典序索引生成组合（用于粒径分档选取）。  
- 提供 Box‑Muller 变换生成标准正态随机数。  
- 给出 Wilson‑Hilferty 变换将正态变量近似为卡方变量。  
- 安全反余弦函数。

### 9. `quadrature_engine.py`
高维数值积分引擎。  
- 提供单位四面体上的 24 点 Felippa 求积规则，并支持仿射变换后的积分。  
- 提供正方形上的最小点高斯求积规则（若干度数），用于二维区域积分。  
- 实现第一类切比雪夫求积节点和权重的生成，用于处理带奇异权函数的积分。

### 10. `statistical_covariance.py`
气溶胶观测的统计协方差分析模块。  
- 根据尺度矩阵和自由度生成 Wishart 分布随机矩阵（基于 Cholesky 分解和 Wilson‑Hilferty 近似）。  
- 计算数据集的样本协方差矩阵。  
- 执行经验正交函数（EOF）分析，输出特征值、特征向量和方差解释率。  
- 基于站点经纬度和指数衰减空间相关模型构建理论的 AOD 协方差矩阵。

### 11. `main.py`（保留文件）
统筹所有模块的主程序。依次调用上述模块展示气溶胶微物理参数、Mie 散射特性、辐射传输 SOR 求解、蒙特卡洛光子传输、全球网格质量分析、源区反演、CCN 活化动力学、统计协方差 EOF 分析以及数值积分和工具验证，输出计算结果。

## 模块间的依赖关系
- `aerosol_microphysics.py` 使用 `numerical_utils.py` 中的组合函数。  
- `mie_scattering.py` 的相函数展开依赖于自身实现的勒让德多项式。  
- `radiative_transfer_solver.py` 使用 HG 相函数和 SOR 迭代。  
- `monte_carlo_photon.py` 使用 HG 散射角抽样。  
- `inverse_source.py` 使用 `atmospheric_mesh.py` 的距离函数（在协方差模型中也如此）。  
- `statistical_covariance.py` 使用 `numerical_utils.py` 中的正态随机数和卡方近似。  
- `aerosol_activation.py` 中的 Logistic 求解是独立实现的。  
- `quadrature_engine.py` 独立，但提供积分规则给需要高维积分的模块（如主程序演示）。
