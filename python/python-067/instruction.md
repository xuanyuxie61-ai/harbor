## 项目描述

# 项目描述：裂隙介质渗流与示踪试验数值模拟系统

本项目是一个面向水文地质研究的科学计算工具集，用于模拟裂隙介质中的渗流、示踪剂迁移以及相关参数反演与不确定性分析。系统由多个独立模块组成，通过主入口 `main.py` 串联执行完整工作流。后续测试将保留 `main.py`，删除其余 `.py` 文件，Agent 需要根据本描述重新实现缺失的模块。

## 文件清单与职责

- `main.py` — 主入口脚本，依次调用各模块完成裂隙网络生成、几何解析、网格生成、插值验证、水力求解、流量积分、溶质运移、参数反演和不确定性量化，并输出各步结果。
- `random_generator.py` — 伪随机数生成器，基于中平方法（Middle-Square）产生均匀、正态、对数正态、指数等分布的随机数，用于裂隙网络和蒙特卡洛研究。
- `fracture_network.py` — 二维裂隙网络模型，利用迭代函数系统（IFS）生成分形裂隙点集，将其栅格化为开度场，计算水力传导系数（Cubic Law），更新连通性，检测渗流路径，并计算等效渗透率、迂曲度等宏观参数。
- `geometry_parser.py` — 三维裂隙几何解析器，解析 Wavefront OBJ 格式的裂隙表面数据，提取顶点、面片，计算面积、法向量、粗糙度、方向分布，并支持生成示例正弦波形裂隙表面。
- `mesh_generator.py` — 计算网格生成器，支持均匀网格、随机点、质心 Voronoi 剖分（CVT）优化采样、Delaunay 三角剖分、线性三角元到二次元的升级（中点插值），以及网格细化（中点细分），并提供三角形质量指标。
- `sinc_interpolator.py` — Sinc 谱插值器，提供归一化 sinc 函数及其一、二阶导数，实现一维和二维 Whittaker-Shannon 插值，以及一维导数插值，用于浓度场后处理。
- `hydraulic_solver.py` — 水力压力场求解器，基于有限差分法求解稳态渗流方程，支持 Gauss-Seidel（含超松弛）和共轭梯度法，可计算达西流速和边界流量。
- `flow_integrator.py` — 数值积分与通量计算模块，包含高斯-盖根堡尔（Gegenbauer）求积器（通过 Jacobi 矩阵特征值问题计算节点和权重），用于积分抛物线速度剖面，并提供突破曲线统计矩、弥散度、回收率、Peclet 数、Reynolds 数等分析函数。
- `transport_solver.py` — 示踪剂迁移求解器，使用显式迎风-中心差分格式求解二维对流-弥散方程（考虑滞留和衰减），监测质量守恒，计算突破曲线，并检查 CFL 与弥散稳定性条件。
- `inverse_model.py` — 参数反演模块，使用 Regula Falsi 法从穿透时间反演裂隙开度和渗透率，通过最小二乘拟合突破曲线反演弥散度，提供 Dirichlet 分布最大似然估计（Newton-Raphson）和双孔隙模型经验标定。
- `uncertainty_quant.py` — 不确定性量化工具，计算非中心 Beta 分布 CDF、Gamma 分布统计量，执行蒙特卡洛不确定性传播，估计渗透率对数正态置信区间，进行有限差分参数敏感性分析，以及一阶可靠性方法（FORM）计算失效概率。
