# 项目描述：森林冠层光合与碳通量耦合模拟系统

本项目是一个模拟三维异质性森林冠层中光合‑呼吸‑碳分配过程的 Python 软件系统。项目入口为 `main.py`，它调用多个专用模块完成从冠层结构构建到碳通量输出、不确定性分析的全流程科学计算。在 benchmark 中，`main.py` 将被保留，其他所有 `.py` 文件将被删除；你的任务是根据本描述重新实现这些缺失的模块。

本描述说明了每个文件的职责、模块边界、核心数据结构和主要算法思路，但**不包含**具体的数学公式、完整的实现代码或数值技巧细节。实现时应遵循这里描述的函数接口和功能需求，但需要自行填补算法细节和辅助逻辑。

## 文件列表与功能概要

### `canopy_geometry.py`
冠层几何结构模块。负责生成树冠的二维多边形网格点和叶面积指数（LAI）的空间分布。
- 提供函数基于多边形顶点生成内部网格点（重心坐标细分）。
- 实现一个用于计算冠层 LAI 垂直剖面的函数，该剖面由归一化的 Beta 分布在高度上描述，形状受两个参数控制。
- 构建二维冠层截面网格：以六边形近似冠层轮廓，利用多边形细分得到点集，并给每个点赋予 LAI 值。
- 构建三维 LAI 场：在柱坐标系下采样，考虑高度剖面和径向衰减。

### `radiation_transfer.py`
辐射传输模块。模拟冠层内直射和散射辐射的衰减及光斑‑阴影异质性。
- 实现基于 Beer‑Lambert 定律的光强衰减函数。
- 实现一个对比度增强滤波器，用于在二维辐射场上模拟光斑与阴影的异质性，增强因子由锐度参数控制。
- 提供 Campbell 椭球体投影函数 G(theta) 的计算。
- 提供冠层辐射剖面的计算，包括直射和散射分量。
- 提供二维网格辐射场构建函数：根据高度上的累计 LAI 计算初始光强，再应用对比度增强。

### `leaf_angle_sampling.py`
叶片角度分布采样模块。在叶片倾角和方位角的分布上进行蒙特卡洛采样，估算有效投影面积 G 函数。
- 提供在单纯形（概率单纯形）上均匀采样的两个工具函数：一个在标准单纯形上采样，另一个通过顶点变换映射到一般单纯形。
- 计算标准单纯形的体积。
- 实现基于正态截断分布的叶片倾角、方位角随机采样，并计算 G(theta_s) 的蒙特卡洛估计量。
- 提供预计算不同太阳天顶角下的 G 函数表的函数。

### `microclimate_fem.py`
冠层微气候有限元模块。用有限元法求解二维温度场演化，包含辐射热源和潜热汇。
- 实现 T3 线性三角形基函数及其梯度。
- 提供基于 Tetens 公式的饱和水汽压计算和潜热通量计算。
- 提供三角形 Gauss 求积规则（3点或7点）。
- 组装有限元系统（质量矩阵 + 刚度矩阵 + 源项），处理 Dirichlet 边界条件。
- 主求解函数：使用向后欧拉时间离散，通过带状矩阵求解温度场，支持外部指定的辐射剖面和气孔导度剖面。
- 依赖 `utils.py` 中的 `bandwidth`, `basis_11_t6`, `reference_to_physical_t3`, `triangle_area_2d`, `banded_solve` 等功能。

### `photosynthesis_model.py`
光合生化模型模块。实现 Farquhar‑von Caemmerer‑Berry (FvCB) 模型。
- 实现 Arrhenius 型温度响应函数（含高温失活），用于修正关键参数。
- 实现非矩形双曲线方程求解电子传递速率 J。
- 核心函数：根据胞间 CO₂、O₂、温度、吸收光强等计算净光合速率，返回 Rubisco 限制速率、RuBP 再生限制速率、J 和暗呼吸。
- 使用中心差分计算 A_n 对温度的敏感性导数。
- 提供在冠层垂直剖面上积分总光合速率的函数。

### `cvt_leaf_distribution.py`
三维叶片空间分布优化模块。基于 Centroidal Voronoi Tessellation (CVT) 的 Lloyd 算法优化叶片簇位置。
- 实现 3D Lloyd 迭代：给定密度函数和域，在采样网格上计算每个 Voronoi 区域的质心，更新生成器位置，并记录能量与运动量。
- 提供一个封装函数，针对冠层场景（圆柱域）构建光强驱动的密度函数，并调用 Lloyd 迭代返回最优叶片簇中心。
- 使用 SciPy 的 `cKDTree` 进行最近邻搜索。

### `soil_carbon_flux.py`
土壤‑冠层界面碳通量模块。在四边形区域上用高阶数值求积计算面积分，并计算生态系统净碳交换量（NEE）。
- 生成参考四边形 `[-1,1]²` 上的 Witherden 型求积节点与权重（针对不同多项式精度提供不同的规则）。
- 实现等参映射将参考四边形映射到物理四边形，并计算雅可比行列式。
- 积分冠层呼吸：对给定的 LAI 函数和呼吸函数在四边形区域上积分。
- 实现 Lloyd‑Taylor 土壤呼吸模型。
- 计算 NEE：根据 GPP、冠层呼吸和土壤呼吸求和。

### `co2_diffusion.py`
CO₂ 反应扩散模块。用有限差分法求解冠层内 CO₂ 浓度的演化。
- 构建二维周期边界条件的五点拉普拉斯矩阵（稀疏矩阵）。
- 主求解器：使用向后 Euler 时间离散，通过 Picard 迭代线性化 Michaelis‑Menten 型光合吸收项，调用稀疏直接求解器更新浓度场，返回各时间步的浓度分布。

### `carbon_allocation.py`
碳分配模块。基于贪心策略分配每日光合产物到叶、茎、根和储存器官。
- 贪心分配函数：按边际收益递减排序（边际收益由异速生长模型导出，储存收益固定），依次满足器官需求直至碳源耗尽。
- 生物量更新函数：根据分配量和碳转化效率更新各器官生物量。
- 计算分配效率（满足需求的比例）。

### `environment_response.py`
环境响应插值模块。提供温度、饱和水汽压差（VPD）、土壤水分对光合速率的影响曲线。
- 实现分段线性插值函数，支持标量和数组查询。
- 提供三个解析响应函数（非对称高斯温度响应、指数 VPD 响应、逻辑土壤水分响应）作为可选替代。
- 构建标准环境响应查找表（离散节点和对应响应值）。
- 综合计算环境限制因子（三个响应的乘积）。

### `data_assimilation.py`
数据同化与噪声模块。为通量观测添加噪声并实现简化滤波。
- 添加异方差高斯噪声（标准差由真值线性决定）。
- 添加尖峰噪声（以一定概率叠加大幅度随机值）。
- 简化标量卡尔曼滤波更新（由预报值和观测值计算分析值及方差）。
- 简化集合卡尔曼滤波（EnKF）：对集合成员逐个观测更新，包含协方差膨胀。

### `boundary_flux.py`
边界通量蒙特卡洛模块。在单位六边形上采样并估计冠层侧边界碳通量。
- 计算单位六边形面积。
- 使用拒绝采样在六边形包围盒内生成均匀采样点。
- 提供六边形区域上的蒙特卡洛积分函数。
- 侧边界通量估算：对法向浓度梯度函数进行蒙特卡洛积分。

### `optimization_parser.py`
优化解析模块。用贪心/线性规划思想解决碳分配优化问题。
- 用贪心法求解：先满足维持呼吸需求，再按收益系数将剩余碳全部分配给最高收益器官。
- 解析解向量清洗（取绝对、四舍五入）。
- 计算各约束的影子价格（通过扰动维持需求并重算目标值）。
