# 项目描述：多物理场耦合的相场法凝固模拟

## 项目概述
本项目旨在模拟二元合金在过冷熔体中的凝固过程，采用相场法耦合 Navier-Stokes 方程、热质传输方程，并利用多种数值方法（有限元、谱方法、自适应网格、随机扰动等）进行求解和分析。入口文件为 `main.py`，它负责组装各物理模块、运行数值测试并执行主模拟循环。其余 `.py` 文件将被删除，需要根据本描述重新实现。

## 文件清单与职责

### 1. `phase_field_core.py` — 相场方程核心
实现 **Allen‑Cahn 型相场模型**，以序参量 φ (+1 固相，‑1 液相) 描述液固界面演化。核心类 **`PhaseFieldModel`**，提供：
- 双阱势及其导数、插值函数（用于相态插值物理参数）
- 含 Neumann 边界条件的五点差分拉普拉斯算子
- 相场方程右端项（扩散、化学驱动力、热/溶质耦合项，可选对流项）
- 初始化圆形晶核（tanh 剖面）
- 界面法向量与曲率计算
- 界面能量密度

### 2. `navier_stokes_solver.py` — Navier‑Stokes 求解器
基于 **投影法** 求解不可压缩流体。核心类 **`NavierStokesSolver`**，包含：
- 基于相场的连续表面力（CSF）界面张力体积力计算
- 对流‑扩散速度项（迎风对流 + 中心扩散）
- 压力泊松方程 Gauss‑Seidel 迭代求解器（齐次 Neumann 边界）
- 投影步速度修正，施加无滑移边界条件
- 完整时间步推进（对流/扩散/张力 → 预测速度 → 投影修正）

### 3. `thermal_transport.py` — 热质传输求解器
求解温度场和浓度场的对流‑扩散方程。核心类 **`ThermalTransportSolver`**，提供：
- 固相分数计算、与相场相关的有效扩散系数
- 变系数扩散项的守恒型差分（∇·(D∇C)）
- 一阶迎风格式对流项
- 相变潜热源项、溶质排出源项
- 温度场和浓度场右端项的组装
- 热过冷度、溶质过冷度、总过冷度（Gibbs‑Thomson 关系）计算
