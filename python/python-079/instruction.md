## 项目描述

# 深海半潜式平台非线性水动力响应与疲劳可靠性综合分析系统

## 项目概述
本项目是一个海洋工程数值仿真系统，针对深海半潜式平台，完成从几何建模、水动力计算、动力响应时域分析到长期疲劳可靠性评估的完整流程。系统由多个独立模块组成，每个模块封装特定的数学模型与数值算法，最后由主控脚本 `main.py` 串联所有模块，输出综合分析结果。

## 文件结构与模块职责

### `utils.py` — 通用数学工具函数
提供数值计算中常用的辅助函数，包括：
- 特殊函数：Gamma 函数及其对数近似、安全反余弦、向量归一化。
- 代数工具：安全二次方程求解、标量钳位。
- 整数运算：最大公约数、丢番图方程可解性检查。
- 伪随机数：Cliff 随机数生成器。
- 带宽计算：给定邻接图与重排序列计算稀疏矩阵带宽。

### `wave_spectrum.py` — 波浪频谱与方向分布
实现海洋波浪的频率谱与方向分布模型，以及线性波理论相关计算：
- 频率谱：JONSWAP 谱，支持基于有效波高和谱峰频率的参数化，包含峰升因子。
- 色散关系：深水与有限水深（Newton 迭代求解波数）。
- 方向扩散：Mitsuyasu 型 `cos^{2n}` 分布，并数值归一化。
- 群速度：有限水深群速度。
- 波面合成：基于线性波叠加的方向波谱合成一维波面高程，利用 Cliff 随机数生成相位。
- 辅助功能：二维各向异性高斯核、超球面均匀采样。

### `mesh_geometry.py` — 网格生成与计算几何
支撑平台水线面几何建模与数值网格生成：
- 一维 CVT：Lloyd 迭代生成最优分布节点，包含能量函数计算。
- 二维多边形：面积、形心、惯性矩、惯性积（使用 Shoelace 公式与 Green 定理）。
- 多边形三角剖分：耳切法（Ear-clipping）生成简单多边形三角剖分。
- Delaunay 质量检查：通过翻转边最小角准则评估剖分的 Delaunay 一致性。
- 单纯形积分：单位单纯形体积、单矩积分，用于 FEM 质量矩阵。
- 平台水线面：生成半潜式、Spar、TLP 等典型平台的简化水线面多边形，并计算水静力学特性（面积、惯性矩、稳心半径）。

### `sparse_matrix.py` — 稀疏矩阵存储与带宽优化
实现坐标格式（COO）稀疏矩阵的基本运算与图论预处理：
- 矩阵类 `R8NCFSparseMatrix`：支持添加非零元、矩阵向量乘法、转置乘法、稠密化、行列重排。
- 自动生成矩阵：二维五点 Laplacian（用于泊松方程）、一维三对角二阶差分矩阵。
- RCM 重排序：从三角剖分构建邻接图，执行伪周长根搜索与层次 BFS 遍历，生成最小化带宽的节点排列，并应用于矩阵。

### `poisson_solver.py` — 泊松方程与速度势求解
求解流场压力泊松方程和速度势 Laplace 方程：
- SOR 迭代：基于稀疏矩阵对象的逐次超松弛求解器，支持任意松弛因子。
- Jacobi 迭代：二维泊松方程的标准五点差分 Jacobi 求解器，支持 Dirichlet 边界条件。
- 压力泊松求解：给定二维速度场，计算速度梯度张量生成右端项，调用 SOR 求解压力场。
- 速度势求解：Laplace 方程 + 入射波/辐射边界条件，使用 Jacobi 迭代。
- 速度计算：由速度势场通过中心差分计算速度分量。
