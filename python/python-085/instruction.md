# 项目描述：二维接触力学与摩擦算法集成系统

该项目是一个用于分析二维线弹性结构在 Signorini 接触和 Coulomb 摩擦条件下的多场景求解框架。主程序 `main.py` 作为统一入口，通过调用一组专用模块完成网格生成、有限元组装、接触求解、磨损演化、不确定性量化、参数优化以及稳定性评估等任务。你需要根据本文档和已保留的 `main.py` 重新实现除 `main.py` 外的所有 Python 模块，确保复现后的程序能按照 `main.py` 描述的流程运行并产生合理结果。

## 涉及的文件与核心职责

### 1. `mesh_generator.py`
负责二维三角形网格的生成与拓扑管理。核心类为 `TriMesh2D`，封装节点坐标、单元连接关系、节点到单元的邻接表以及边界提取功能。模块还提供按矩形区域生成结构化三角网格的工厂函数，以及一个简化版 ASCII STL 表面解析函数，可将三角面片数据转换为内部网格表示。网格的几何计算（面积、形函数梯度等）也在该类中实现，供有限元模块调用。

### 2. `fem_assembler.py`
实现二维平面应变线弹性有限元的核心组装。提供 `ElasticFEM2D` 类，根据给定的杨氏模量、泊松比和厚度，计算本构矩阵并组装单元刚度到全局刚度矩阵；同时提供施加 Dirichlet 约束的罚函数方法、位移场下的应变/应力计算以及内力、应变能和残差计算。此外，该模块还包含两个独立函数，用于计算接触节点的法向间隙和简化接触法向量，这些函数被接触求解器直接调用。

### 3. `banded_solver.py`
带状线性方程组的 LU 分解与回代求解器。`BandedSolver` 类支持两种模式：无选主元的紧凑带状分解（适用于正定或对角占优矩阵）和带部分选主元的一般带状 LU 分解（允许填充，用于一般非对称系统）。类提供紧凑存储与满阵之间的相互转换，并封装分解加求解的统一接口。模块还额外提供一个函数，用于从全局刚度矩阵中提取与接触自由度相关的带状子矩阵，以加速局部接触修正。

### 4. `contact_solver.py`
实现单侧接触与库仑摩擦的非线性求解。`SignoriniCoulombContact` 类采用增广 Lagrange 方法处理 Signorini 条件和摩擦定律：通过 Lagrange 乘子迭代计算法向压力和切向摩擦力，并将接触力作为外力施加到结构上。该类还提供接触压力与摩擦耗散的后处理计算。模块另包含一个独立的主动集 Newton 法求解器函数，在每个迭代步根据当前间隙确定约束自由度和滑动状态，求解缩并线性系统。

### 5. `wear_ode.py`
基于 Archard 磨损定律的磨损深度演化建模。`ArchardWearModel` 类封装磨损系数、简谐切向速度模型，并定义磨损率右端项。提供两种常微分方程积分器：隐式中点法（带不动点迭代）和经典四阶 Runge‑Kutta 方法，用于对比验证。此外，模块还提供一个耦合磨损与接触的单步更新函数，用于将磨损深度增量与压力场显式关联。

### 6. `monte_carlo_contact.py`
用于接触问题的不确定性统计模块。包含二维凸多边形内部的均匀采样算法（基于面积加权的三角剖分），三维单位金字塔均匀采样算法，以及基于这些采样的接触压力方差估计和摩擦系数随机敏感性分析。后者通过重复对摩擦系数加噪声并求解接触问题，统计输出量的多批次统计特征。

### 7. `friction_optimization.py`
提供无梯度优化和测试函数。实现了经典的 Hooke‑Jeeves 直接搜索优化器，可用于标定摩擦系数；同时复制了 MATLAB 的 `peaks` 函数及其数值梯度，并将其包装为接触势能测试曲面。优化器通过多次探索移动和模式移动自动调整步长，直至收敛。摩擦系数标定函数基于该优化器将模拟结果与目标测量值进行最小二乘匹配。

### 8. `roughness_field.py`
生成用于模拟接触面粗糙度的 1/f 噪声和一维轮廓，以及二维分形表面。利用频域滤波方法，通过功率谱密度造型生成随机粗糙高度场，并提供自相关分析和将粗糙度位移叠加到网格接触节点的工具，以影响接触间隙初值。

### 9. `diophantine_utils.py`
提供丢番图方程非负整数解的通解结构计算，并借其整数规划思想实现节点编号重排从而降低刚度矩阵带宽。模块包含一个函数计算向量最大公约数、一个函数求解感兴趣的非负丢番图系统、一个节点重编号优化函数，以及一个根据非零元估计矩阵上下带宽的辅助函数。

### 10. `complex_analysis.py`
复频域稳定性分析工具箱。包含构建复模态分析所需的质量、阻尼、刚度矩阵组的函数；基于状态空间特征值分析的复模态计算；根据特征值判断系统不稳定模态数、阻尼比、颤振频率；构造基于摩擦和接触压力的等效粘性阻尼矩阵；以及计算某一自由度上的频响函数（位移‑频率曲线）。还提供一个复数幂迭代法估算主导特征值。

### 11. `utils.py`
集合了各类低层数学工具，包括安全除法、Macaulay 括号、Heaviside 平滑近似、复向量和复矩阵的范数、矩阵的部分打印、1‑based 指示向量生成、对称性检查、基于 SVD 的条件数估计以及小规模 2×2 对称系统的解析求解。这些函数被其他多个模块使用。

## 模块间的依赖关系

- `mesh_generator` 是基础，几乎所有后续模块都依赖它输出的网格数据（`TriMesh2D` 实例）。
- `fem_assembler` 依赖网格，输出刚度矩阵、位移场相关计算结果，供给接触求解器、稳定性分析和主流程使用。
- `contact_solver` 依赖 `fem_assembler` 的间隙/法向量函数，并调用 `fem_assembler` 的 Dirichlet 施加方法。它还接收外部载荷并输出位移、接触压力。
- `banded_solver` 被主程序直接使用以验证带状求解，并提供子矩阵提取函数供接触子问题加速。
- `wear_ode` 依赖用户提供的压力函数（通常来自接触求解结果）计算磨损演化。
- `monte_carlo_contact` 调用接触求解函数（通过传入的可调用对象）来评估摩擦系数变化下的接触力学量；内部使用 `mesh_generator` 来提取接触区域。
- `friction_optimization` 通过目标函数间接调用接触求解器来标定摩擦系数。
- `roughness_field` 可以被用于在求解接触前修改网格节点坐标。
- `diophantine_utils` 优化节点编号，可影响刚度矩阵带宽，为带状求解做准备。
- `complex_analysis` 使用 `fem_assembler` 的刚度矩阵，结合构造的质量、阻尼矩阵进行稳定性评估。
- `utils` 被广泛使用，尤其是条件数估计、Macaulay 括号等。

所有模块最终由 `main.py` 串联，形成一个完整的分析流程：网格生成 → FEM 组装 → 接触求解 → 磨损/蒙特卡洛/优化/稳定性等后处理。

## 关键数据流和算法要点

- **网格与有限元**：通过生成矩形网格并分切为三角形建立离散域。应用平面应变弹性矩阵，利用形函数梯度构建 B 矩阵，按自由度索引装配全局刚度矩阵。施加约束时采用大数罚方法避免矩阵修改直接消去行列。
- **接触求解**：采用迭代的增广 Lagrange 方法，交替更新位移（求解线弹性方程）和 Lagrange 乘子（投影到摩擦锥内）。接触力作为显式外力施加，罚刚度为接触约束提供正则化。主动集 Newton 法直接约束侵入节点位移，每次迭代重新确定接触状态。
- **带状求解**：利用带状稀疏性进行无主元或带主元 LU 分解。紧凑存储格式将矩阵的对角线区域映射到窄带矩阵，分解时仅处理带状内的元素以减少计算量。
