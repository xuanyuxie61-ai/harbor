## 项目描述

# 项目描述：圆柱壳轴向压缩屈曲与后屈曲路径跟踪分析系统

## 项目概述
本项目的目标是研究薄壁圆柱壳在轴向压力下的线性屈曲、非线性后屈曲路径以及初始几何缺陷敏感性。系统采用 Donnell-Mushtari-Vlasov 壳理论进行有限元离散，结合 Newton-Raphson 迭代与弧长法进行路径跟踪，并提供稳定性分析和几何缺陷生成工具。代码为模块化结构，主控程序为 `main.py`，其余为功能模块文件。

## 模块文件清单与职责

### `shell_geometry.py`
定义圆柱壳中曲面几何类 `CylindricalShellGeometry`。存储半径 R、长度 L、厚度 t，提供参数化曲面映射、第一/第二基本形式、主曲率、高斯曲率与平均曲率、测地距离计算、边界节点排序（便于施加边界条件和周期性条件）、表面积、长径比以及 Batdorf 参数（用于壳体屈曲分类）等工具方法。

### `mesh_triangulation.py`
实现圆柱壳中曲面三角网格类 `ShellTriMesh`。根据给定的环向和轴向离散份数生成结构化网格（将参数域矩形剖分成两个三角形），并提供单元面积计算、内角计算、基于 alpha 测度的网格质量评估、Delaunay 边翻转优化、单元邻居关系构建以及边界节点提取功能。

### `shell_fem_element.py`
包含材料类 `ShellMaterial`（存储杨氏模量、泊松比、密度，并计算薄膜刚度和弯曲刚度矩阵）和有限元模型类 `ShellFEModel`。后者负责组装线性刚度矩阵、几何刚度矩阵（对位移场的线性化响应）以及计算内力向量。采用三节点三角形壳元，每个节点三个自由度（位移 u, v, w）。内部实现了薄膜应变-位移矩阵 B_m 和弯曲应变-位移矩阵 B_b 的计算，基于参数域映射和简化的常曲率假设。

### `linear_buckling.py`
提供线性屈曲分析类 `LinearBucklingAnalyzer`。使用解析公式计算圆柱壳的经典轴向屈曲临界载荷；在给定轴向半波数 m 和环向波数 n 范围内离散搜索最小屈曲载荷及对应模态；利用 Halley 迭代计算 Bessel 函数零点以验证环向波数解；还实现了 Koiter 初始缺陷敏感性因子，估计几何缺陷对屈曲载荷的降低效应。模块内部还包含独立的 Bessel 零点计算函数。

### `nonlinear_solver.py`
实现两个求解器类：
- `NewtonRaphsonSolver`：使用带 Armijo 线搜索的修正 Newton-Raphson 法求解非线性静力平衡方程。根据用户指定的载荷因子 λ 求解 F_int(u) = λ F_ext，组装切线刚度矩阵并考虑边界条件，通过线搜索加速收敛。
- `PseudoTimeSolver`：基于伪时间步进的显式动态松弛求解器，通过添加人工阻尼将静力问题嵌入动态方程并演化至稳态，构造集中质量矩阵并监测伪能量收敛。

### `arc_length_tracker.py`
实现弧长法路径跟踪类 `ArcLengthTracker`。采用球面弧长约束（Riks-Wempner 形式），通过扩展的 Newton-Raphson 修正步（在位移-载荷空间联合求解）跟踪后屈曲平衡路径。包含自适应弧长步长控制、基于切线刚度矩阵最小特征值符号变化的极限点/分岔点检测，以及利用 Chirikov 共振重叠思想将路径离散化为高维映射后计算局部“扭转数”方差来标识混沌区域的指标计算。

### `defect_generator.py`
定义几何缺陷生成类 `DefectGenerator`。基于 Fourier 级数叠加的随机或指定模态，可生成单模态缺陷、双“C”型嵌套缺陷、蒙特卡洛多模态缺陷和基于单位球内采样的随机多模态缺陷。缺陷场可施加到网格节点上，沿法向偏移节点坐标；也可计算缺陷场的统计特征（最大缺陷、均方根、缺陷厚度比等）。

### `stability_analysis.py`
提供后屈曲稳定性分析类 `StabilityAnalyzer`。可计算切线刚度矩阵的若干最小特征值以判定当前构型的平衡稳定性；基于路径上相邻步位移变化率估计离散 Lyapunov 指数；使用简化的 Chirikov 共振重叠判据判断是否进入混沌；根据 Koiter 理论对平衡路径的初始斜率特征进行分岔类型分类（对称稳定/不稳定、snap-through 跳跃等）；并计算路径的能量势垒。

### `sparse_matrix_io.py`
提供稀疏矩阵格式转换工具，支持 COO、CSR 与 Matrix Market (MM)、Sparse Triplet (ST)、Harwell-Boeing (HB) 等格式之间的相互转换；可计算矩阵的带宽（下带宽 ML、上带宽 MU、半带宽 M），并提供基于 Reverse Cuthill-McKee 算法的矩阵轮廓缩减（节点重编号），以降低带宽并提高直接求解效率。

### `main.py`（保留文件）
主入口程序。依次执行：定义几何与材料参数；生成壳体三角网格并评估质量；装配有限元模型并计算刚度矩阵带宽；进行线性屈曲分析与 Bessel 零点验证；定义外载荷（顶部轴向压力）；执行线性静力分析；使用 Newton-Raphson 求解器进行非线性验证；调用弧长跟踪器获得后屈曲路径；进行稳定性分析（特征值、Lyapunov 指数、分岔分类）；生成多种几何缺陷并计算其统计量及 Koiter 载荷降低因子；输出稀疏矩阵格式转换和矩阵轮廓缩减结果；最后利用伪时间动松弛求解器验证。所有核心结果汇总输出。

- 网格模块依赖几何模块获取参数化表面。
- 有限元模块依赖网格模块提供节点、单元和几何信息。

## 核心数据结构
- 圆柱壳几何参数：半径 R、长度 L、厚度 t（浮点数）。
- 材料参数：杨氏模量 E、泊松比 ν、密度 ρ（浮点数）。
- 网格：节点坐标数组 `(N_nodes, 3)`，单元数组 `(N_elem, 3)`（整数索引），邻居数组 `(N_elem, 3)`。
- 有限元自由度总数：`n_dof = N_nodes * 3`。
- 外部载荷向量：形状 `(n_dof,)`，顶部节点承受法向压力。
- 路径历史：字典列表，每个字典包含载荷因子 λ、位移向量、最大法向位移、切线刚度矩阵行列式符号及最小特征值、弧长值等。
- 缺陷场：可调用函数 `f(theta, x) -> w_bar`。

## 主要算法与流程
1. **网格生成**：参数域结构网格映射到三维圆柱面，对角线交替剖分三角形。
2. **有限元装配**：对每个三角形单元计算局部薄膜和弯曲应变-位移矩阵，利用本构矩阵组装线性刚度矩阵；根据当前位移产生的薄膜应力构造几何刚度矩阵；内力计算基于线性应变和应力的线性化组合（不包含大转动非线性）。
3. **线性屈曲分析**：离散遍历 (m, n) 模态，使用 Donnell 公式计算轴向压力，找到最小值。
4. **非线性求解**：Newton-Raphson 迭代，在每个迭代步组装切线刚度矩阵，求解位移增量，并通过 Armijo 线搜索限制步长，直到力和位移收敛。
5. **弧长法跟踪**：在当前载荷步沿切向预测 (Δu, Δλ)，再执行球面约束修正步，通过扩展系统求解器同时更新位移和载荷因子；若修正步不收敛，则缩减弧长重试；收敛后根据迭代次数自适应调整下一弧长。每一步记录最小特征值，检测符号变化作为分岔点。
6. **缺陷生成**：通过设定特定模态幅值或随机采样
