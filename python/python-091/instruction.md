# 项目描述：超声成像波束形成与反演系统

本项目是一个面向多物理场耦合超声层析成像的科学计算平台，整合了网格生成、有限元/有限差分求解、非线性声学、流-声耦合、微泡动力学、信号处理、波束形成、断层反演等多个模块。主入口为 `main.py`，它串联所有模块执行完整的仿真流程；其余文件分别实现各个模块的核心算法。下面描述各模块的职责、核心算法和模块间关系。

## 文件结构与模块职责

### `acoustic_fem_mesh.py` – 声学有限元网格生成与 RCM 重排序
负责生成二维矩形域的三角网格，并利用 Reverse Cuthill-McKee (RCM) 算法对网格节点重新编号，以减小稀疏矩阵的半带宽。主要功能：
- 构建三角网格的节点邻接图。
- 实现 BFS 层级遍历，寻找伪外围节点。
- 执行 RCM 重排序，返回新旧节点编号映射。
- 应用重排序到网格节点坐标和三角形单元索引。
- 生成规则矩形域（如 0.1m×0.1m）的三角网格，采用对角线分割保持单元质量。

### `mesh_quality.py` – 网格质量评估
提供多种三角形网格质量度量指标，用于诊断有限元网格的几何可靠性。主要功能：
- 计算 Q 度量（内切圆与外接圆半径比）、Alpha 度量（最小内角标准化）、Gamma 度量（最近邻距离均匀性）。
- 计算由三角网格导出的刚度矩阵半带宽。
- 生成包含上述指标的网格质量报告。
- 根据质量阈值剔除低质量三角形。

### `transducer_dynamics.py` – 压电换能器瞬态动力学与刚性 ODE 验证
模拟压电换能器振子的阻尼受迫振动，并验证刚性 ODE 求解器的精度。核心算法：
- 将换能器运动方程转化为一阶状态空间系统，使用隐式梯形法（Crank-Nicolson）求解。
- 提供标准刚性 ODE 的精确解，验证求解器的收敛阶。
- 模拟不同频率、品质因数下的换能器位移和速度响应。

### `helmholtz_solver.py` – 声学 Helmholtz 方程有限差分求解与插值
求解一维和二维 Helmholtz 方程，支持多种边界条件，并提供分段线性插值重建功能。主要功能：
- 一维 Helmholtz 求解：使用中心差分构建三对角系统，处理 Dirichlet、Neumann 和吸收边界条件 (ABC)。
- 二维 Helmholtz 求解：五点差分格式，Dirichlet 边界，构造块三对角稀疏矩阵并求解。
- 一维分段线性插值（PWL）和帽子函数基函数生成，用于声压场插值到任意坐标。

### `nonlinear_acoustics.py` – 非线性声学椭圆函数解
基于 Jacobi 椭圆函数（Bulirsch AGM 算法）求解 Burgers 方程的行波解，并模拟冲击波形成。主要功能：
- 计算 Jacobi 椭圆函数 sn, cn, dn，支持模数 m 超出 [0,1] 的变换。
- 生成 Burgers 方程的周期行波解（cn² 形式），以及冲击波形成前后的速度分布。
- 从多频声压数据估计非线性声学参数 B/A。

### `flow_acoustic_coupling.py` – 流-声耦合背景场与插值
提供非均匀背景流场（Taylor-Green 涡、顶盖驱动腔体流）的解析解，并计算流-声耦合源项。主要功能：
- 计算 Taylor-Green 涡的精确速度场和压力场。
- 近似腔体流的多项式速度场。
- 将有限元网格上的节点值插值到规则矩形网格（使用重心坐标）。
- 计算流-声耦合源项（低速近似），以及局部 Mach 数场。

### `microbubble_diffusion.py` – 超声造影剂微泡扩散与布朗运动
模拟微泡在超声辐射力作用下的布朗运动，并计算扩散系数和浓度分布。主要功能：
- 基于 Stokes-Einstein 关系计算扩散系数。
- 生成布朗运动随机步长，模拟微泡轨迹（含声辐射力漂移和反射边界）。
- 计算均方位移 (MSD) 以验证扩散特性。
- 估算初级 Bjerknes 辐射力。
- 统计最终时刻的微泡浓度分布。

### `wavelet_denoising.py` – 小波去噪与多尺度特征提取
利用 Haar 小波对超声 A-scan 信号进行多分辨率分解和阈值去噪，并提取多尺度特征。主要功能：
- 实现一维 Haar 小波正向和逆向变换，支持多级分解与重构。
- 基于 Donoho-Johnstone 通用阈值（MAD 噪声估计）进行软/硬阈值去噪。
- 提取各尺度细节系数的能量、熵等特征，用于信号分类。

### `pca_feature_extraction.py` – PCA 特征提取与降维
对超声 B-scan 图像（高维向量）进行主成分分析，实现降维和重建。主要功能：
- 生成合成 B-scan 图像数据集（模拟不同深度和强度的反射界面）。
- 使用 Turk-Pentland 技巧计算 PCA 主成分（当样本数远小于特征维数时）。
- 计算方差保留率、执行图像投影与重建，并评估重建误差（RMSE, PSNR）。

### `ultrasound_beamforming.py` – 超声阵列波束形成与动态聚焦
模拟多阵元线性阵列的接收信号，并执行延迟叠加波束形成 (DAS)。主要功能：
- 计算导向矢量、多种窗函数（Hanning, Hamming, Chebyshev）。
- 延迟叠加波束形成：根据聚焦深度计算各阵元延迟，加权求和输出波束信号。
- 计算发射聚焦延迟，使波前在指定点同步到达。
- 计算阵列波束方向图（归一化 dB 表示）。
- 模拟阵列对多个散射点的回波信号。

### `inverse_tomography.py` – 超声断层反演与序列比对
实现基于射线理论的超声层析反演，以及整数精确线性代数和序列比对。主要功能：
- 构建简单投影矩阵（水平和垂直射线穿过像素格点，路径长度量化为整数）。
- 使用 SVD 正则化求解慢度扰动反演问题。
- 计算整数矩阵的行最简形 (IRREF) 以精确分析秩和
