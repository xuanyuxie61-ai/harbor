# 博士级合成说明：三维封闭空间多通道宽带主动噪声控制（ANC）系统

## 1. 项目概述

本项目围绕**声学工程：主动噪声控制与自适应滤波**领域，将15个原始科研代码项目的核心算法融合为一个面向前沿科学问题的博士级计算系统。系统模拟了在三维封闭空间（如机舱、车辆舱室）中，利用多通道自适应滤波、稀疏声传播建模、球面阵列优化、组合优化声源选择等高级技术实现宽带噪声主动控制的完整流程。

## 3. 新增数学物理模型与核心公式

### 3.1 一维管道声学Helmholtz方程

声压 `p(x)` 满足：

```
d²p/dx² + k² p = -j ρ₀ ω q(x)
```

边界条件（两端封闭管）：`p(0) = p(L) = 0`

中心差分离散：

```
p_{i-1} + (k²h² - 2) p_i + p_{i+1} = h² f_i
```

形成三对角系统，使用Thomas算法（前向消元+回代）在 `O(N)` 时间内求解。

### 3.2 球面Fibonacci网格与球谐展开

Fibonacci球面采样：

```
φ = (1 + √5) / 2
θ_i = 2π i / φ
z_i = (2i - N + 1) / N
r_i = √(1 - z_i²)
(x, y, z) = (r_i sin θ_i, r_i cos θ_i, z_i)
```

声场球谐展开：

```
p(r, θ, φ) = Σ_{l=0}^{L} Σ_{m=-l}^{l} a_l^m h_l^{(2)}(kr) Y_l^m(θ, φ)
```

### 3.3 圆形活塞Rayleigh积分

远场声压由Rayleigh积分给出：

```
p(r⃗) = (j ρ₀ ω / 2π) ∫_S u_n(r⃗') exp(-jk|r⃗ - r⃗'|) / |r⃗ - r⃗'| dS'
```

指向性函数：

```
D(θ) = 2 J₁(ka sin θ) / (ka sin θ)
```

辐射阻抗：

```
R_r / (ρ₀ c₀ S) = 1 - 2 J₁(2ka) / (2ka)
X_r / (ρ₀ c₀ S) = 2 H₁(2ka) / (2ka)
```

其中 `H₁` 为Struve函数，`J₁` 为Bessel函数。

### 3.4 多通道FxLMS自适应滤波

误差信号：

```
e_m(n) = d_m(n) + Σ_l Σ_k w_{lk}(n) x_l(n-k) * h_{ml}(k)
```

系数更新（带泄漏）：

```
w_{lk}(n+1) = λ w_{lk}(n) - μ e_m(n) x'_l(n-k)
```

收敛条件：

```
0 < μ < 2 / (L P_max Σ_m Σ_l ||ĥ_{ml}||²)
```

### 3.5 非线性自适应动力学（类Anishchenko模型）

将自适应系统抽象为三维非线性ODE：

```
dw₁/dt = (μ - γ) w₁ + w₂ - w₁ e
dw₂/dt = -w₁ - γ w₂
de/dt  = -η e + η H(w₁) w₁²
```

其中 `H(w₁)` 为Heaviside函数。线性化Jacobian：

```
J = [[μ-γ,  1,   0],
     [-1,  -γ,   0],
     [0,    0,  -η]]
```

稳定条件：`γ > μ/2` 且 `γ² - μγ + 1 > 0`。

### 3.6 Dirichlet统计噪声模型

多通道归一化功率 `x_j = P_j / P_total` 服从Dirichlet分布：

```
f(x; α) = (1/B(α)) Π_j x_j^{α_j - 1}
```

最大似然估计通过数值优化求解：

```
min_α  -ln Γ(Σα_j) + Σ_j ln Γ(α_j) - Σ_j (α_j - 1) <ln x_j>
```

梯度：

```
∂L/∂α_j = N [ψ(Σα) - ψ(α_j) + <ln x_j>]
```

### 3.7 RCM网格重排序

Reverse Cuthill-McKee算法通过BFS层遍历和逆序编号，将有限元刚度矩阵的半带宽从 `O(N)` 缩减至 `O(√N)` 量级。对于 `N=125` 的盒状网格，带宽从123缩减至36（约3.4倍）。

## 5. 合成后项目能够解决的科学问题

1. **三维封闭空间多通道ANC系统的设计与仿真**：从几何布置、声传播建模到自适应滤波器优化的全流程仿真。
2. **稀疏声学矩阵的高效计算**：利用ST/CCS格式处理大规模房间脉冲响应，内存复杂度从 `O(MN)` 降至 `O(nnz)`。
3. **非线性自适应系统的稳定性边界分析**：通过Jacobian特征值分析确定步长-泄漏参数的Hopf分岔边界。
4. **组合优化在工程约束下的声源配置**：在功率预算和数量限制下，实现降噪量的近似最优配置。
5. **圆形活塞辐射器的完整声场计算**：包含远场指向性、辐射阻抗、声压分布的数值与解析混合计算。
6. **多通道噪声的统计建模与贝叶斯增益控制**：利用Dirichlet分布建模非平稳多通道功率谱，实现数据驱动的自适应步长调整。
