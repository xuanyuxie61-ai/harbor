## 项目描述

# 项目描述：天线阵列波束赋形与优化系统

## 项目概述
本项目实现面向 5G/6G 大规模 MIMO 系统的自适应数字波束赋形仿真系统。系统综合考虑三维共形阵列与非均匀平面阵列的几何生成、单元间电磁互耦效应、相位噪声建模、数字移相器量化编码、高精度数值积分以及基于 ODE 的自适应相位优化。最终由 `main.py` 作为统一入口，串联所有模块并输出仿真结果。

## 模块文件说明

### 1. `em_field_core.py` — 电磁场核心计算
负责天线阵列辐射方向图与近场耦合的基础电磁计算。

主要功能：
- 定义物理常数（光速、真空介电常数、自由空间波阻抗）。
- 类 `ArrayFactorCalculator`：管理阵列单元位置、工作频率和复数权重；通过方向余弦计算阵列因子 AF(θ,φ)；计算半波偶极子单元方向图；合成总方向图并支持归一化输出（dB）；提供波束指向的相移权重生成和 Chebyshev 幅度加权以控制旁瓣；计算方向性系数。
- 类 `MutualCouplingMatrix`：基于半波偶极子的感应电动势法近似计算互阻抗矩阵；提供余弦/正弦积分近似；计算主动反射系数。
- 函数 `near_field_e_field`：基于自由空间格林函数计算近区电场（假设 z 向偶极子）。

### 2. `array_geometry.py` — 阵列几何生成与网格质量评估
负责天线阵列单元的空间位置生成和分布质量评估。

主要功能：
- 基于球面经纬网格（LLT）生成共形阵列单元坐标，并计算网格边数。
- 简化版 DistMesh 二维网格生成器：通过力平衡方程迭代生成非均匀口径面网格；使用符号距离函数和密度函数控制区域和局部边长。
- 四面体网格质量评价：基于体积、边长、外接球半径与内切球半径比、奇异值条件数等计算质量指标。
- 平面矩形/圆形阵列的生成。

### 3. `beamforming_optimizer.py` — 波束赋形自适应优化与动力学演化
将自适应波束赋形问题映射为常微分方程演化过程。

主要功能：
- 类 `RK12Solver`：一阶/二阶显式 Runge-Kutta 求解器，提供固定步长和自适应步长求解两种模式；给出局部截断误差估计。
- 类 `KeplerPerturbedArrayCoupling`：受摄开普勒 ODE 系统，模拟天线单元间互耦的等效势场扰动，包含守恒量（摄动 Hamiltonian）计算。
- 类 `LangfordBeamPhaseDynamics`：Langford 混沌 ODE 系统，用环面分岔结构描述自适应波束收敛相变过程；提供最大 Lyapunov 指数估计。
- 类 `AdaptiveBeamformerODE`：基于梯度流的相位权重自适应演化；根据波束指向约束、旁瓣抑制和信号协方差构建代价函数梯度，利用 RK12 演化相位。

### 4. `convergence_analysis.py` — 收敛性分析与误差度量
评估仿真中的分布均匀性、距离统计和收敛速率。

主要功能：
- 单位立方体内两点距离的精确 PDF 公式（分三段区间），以及蒙特卡罗采样统计均值和方差。
- 二维直方图均匀性检验：通过卡方统计量评估二维点分布的均匀性。
- 天线方向图质量指标：计算峰值旁瓣电平、积分旁瓣比、主瓣宽度效率。
- 残差收敛速率估计：基于对数-线性回归估计几何级数衰减率。

### 5. `stochastic_channel.py` — 随机信道与统计噪声建模
提供统计分布计算和随机过程模拟。

主要功能：
- 高斯正态分布 CDF 计算（`alnorm`）。
- Owen T 函数和双变量正态 CDF 计算，用于旁瓣电平等概率分析。
- 一维随机游走相位噪声模型：模拟离散随机游走轨迹，计算均方位移并与理论值对比。
- 二维离散 CDF 采样：从给定 PDF 矩阵生成采样点；基于空间相关性生成衰落信道增益样本。
- 旁瓣电平 CDF 的近似计算。

### 6. `quadrature_engine.py` — 高精度数值积分引擎
提供二维和三维区域上的高精度数值积分支持。

主要功能：
- 正方形 `[-1,1]^2` 上给定代数精度（1~20）的最小求积规则（预存节点/权重表）。
- 对应积分函数 `integrate_square_minimal`。
- 单位楔形体上单项式的精确积分公式。
- 三维求积公式的多项式精确性检验：遍历指定次数的所有单项式，比较数值积分与精确值。

### 7. `phase_quantization.py` — 数字移相器量化与编码
模拟数字移相器的有限精度量化效应。

主要功能：
- 整数到二进制/格雷码的转换，以及格雷码到整数的反向转换。
- 计算二进制向量间的汉明距离。
- 生成二进制编码与格雷码的汉明距离矩阵。
- 类 `DigitalPhaseShifter`：根据给定位数进行相位量化，输出格雷码控制字，计算状态切换的汉明距离。
- 波束码本文件名的序列生成。

### 8. `numerical_utils.py` — 数值工具模块
提供通用数值计算辅助功能。

主要功能：
- 类 `NewtonInterpolator1D`：一维 Newton 插值，基于差商表计算插值多项式和误差估计。
- `filename_increment`：文件名末尾数字递增（含进位和回绕）。
- `safe_inverse_sqrt`：数值鲁棒的倒数平方根。
- `rotation_matrix_z` / `rotation_matrix_y`：绕 Z/Y 轴的旋转矩阵。

## 项目整体流程 (`main.py`)
1. 调用 `array_geometry` 生成平面阵列和球面共形阵列，测试 DistMesh 非均匀网格和四面体质量评估。
2. 用 `em_field_core` 计算阵列方向图、方向性系数、互耦矩阵和近场电场。
3. 使用 `stochastic_channel` 模拟随机游走相位噪声、空间衰落采样、双变量正态 CDF 和旁瓣概率。
4. 通过 `beamforming_optimizer` 求解受摄开普勒 ODE、Langford 混沌系统和自适应相位梯度流。
5. 利用 `quadrature_engine` 验证正方形最小规则积分和楔形体多项式精确性；使用 `numerical_utils` 验证 Newton 插值。
6. 使用 `phase_quantization` 进行数字移相器量化演示和汉明距离分析。
7. 通过 `convergence_analysis` 验证立方体距离 PDF/MC、二维均匀性检验、方向图质量指标和残差收敛速率。
8. 利用 `numerical_utils` 的文件序列工具演示辅助功能。
