# 项目：永磁同步电机电磁场有限元分析 (python-100)

## 项目概述
本项目实现一个用于永磁同步电机（PMSM）电磁场分析的一维、二维和三维有限元求解器，并结合材料物理模型、网格生成、数值积分、转子动力学及数值稳定性分析。项目围绕“考虑非线性磁材料、材料参数不确定性、以及转子偏心故障的永磁同步电机电磁-结构耦合多场分析”这一博士级科学问题展开。

## 涉及文件及其职责

### main.py
- 主程序入口，协调整个分析流程：
  1. 生成电机 2D 截面网格
  2. 定义材料模型与不确定性
  3. 执行 1D 径向有限元分析（气隙简化）
  4. 执行 2D 轴对称有限元分析（全截面磁场）
  5. 3D 场投影与端部效应分析
  6. 电磁转矩与涡流损耗计算
  7. 转子动力学耦合分析
  8. 数值稳定性评估
- 它调用其他模块的类和方法，并输出每步结果。

### fem1d_radial.py
- 实现一维径向静磁场有限元求解器。
- 核心类 `FEM1DRadial`：
  - 基于分段线性基函数（P1 元）离散一维径向方程。
  - 组装三对角刚度矩阵和载荷向量，考虑 Dirichlet 和 Neumann 边界条件。
  - 使用 Thomas 算法（三对角求解）求解线性系统。
  - 提供计算径向磁通密度和磁场储能的方法。
- 需要的输入：径向区域、单元数、磁阻率函数、源电流密度函数。

### fem2d_axi.py
- 实现二维轴对称电磁场有限元求解器。
- 核心类 `FEM2DAxi`：
  - 使用三角形 P1 线性元离散二维 Poisson 方程。
  - 组装稀疏刚度矩阵和载荷向量，支持线性材料和非线性材料（通过 Newton‑Raphson 迭代）。
  - 应用 Dirichlet 边界条件（大数罚函数法）。
  - 计算节点磁通密度、Maxwell 应力张量、电磁转矩、磁场储能和涡流损耗。
- 需要二维修网格（`Mesh2D` 对象）以及材料函数和边界条件。

### fem3d_projection.py
- 实现三维有限元场投影，将二维截面磁势场投影到三维轴向长度分布。
- 核心类 `FEM3DProjection`：
  - 通过拉伸二维三角形网格生成三维四面体网格（TET4 单元）。
  - 组装三维质量矩阵，求解 L² 投影方程得到三维磁势分布。
  - 计算三维磁场储能和端部轴向力（端部效应简化模型）。
- 输入：二维节点与单元、轴向长度。

### material_physics.py
- 定义材料物理模型与不确定性量化。
- 核心类：
  - `NonlinearMagneticMaterial`：基于反正切函数逼近 B‑H 曲线的非线性磁材料，可计算磁阻率、微分磁导率等。
  - `PermanentMagnet`：线性退磁曲线的永磁体模型。
  - `LogNormalUncertainty`：对数正态分布，用于材料参数不确定性量化（PDF、CDF、采样、参数估计）。
- 辅助函数：电导率温度依赖关系，材料库构造。

### mesh_engine.py
- 电机有限元网格生成、读写与质量分析。
- 核心类：
  - `CVTMeshGenerator`：基于重心 Voronoi 镶嵌（CVT）的网格生成器，可在环形扇区生成高质量三角形点集与 Delaunay 剖分。
  - `Mesh2D`：二维网格数据结构，管理节点、三角形单元、区域标签、边界边。提供网格质量指标计算、连通性矩阵、Floyd‑Warshall 最短路径（磁路长度估计）、FreeFEM .msh 格式读写。
- 辅助函数：`build_simple_pmsm_mesh` 构建简化的 PMSM 截面网格。

### numerical_analysis.py
- 数值稳定性分析与误差估计。
- 核心类：
  - `ConditionEstimator`：矩阵条件数估计（Hager 算法、LINPACK 风格），支持稠密与稀疏矩阵。
  - `FEMErrorEstimator`：有限元离散误差估计（先验 H¹ 误差，网格 Peclet 数，刚度矩阵正定性检查）。
  - `NumericalRobustness`：数值鲁棒性工具（安全除法、梯度裁剪、收敛检查、矩阵正则化）。

### quadrature_engine.py
- 高斯求积与蒙特卡洛积分引擎。
- 核心类：
  - `GaussLegendreQuadrature`：一维高斯‑勒让德求积规则（通过 Jacobi 矩阵特征值问题构造）。
  - `TriangleGaussianQuadrature`：三角形单元上的高斯求积（Dunavant 7 点规则）。
  - `TriangleMonteCarlo`：三角形单元上的蒙特卡洛积分，含方差估计与置信区间。
  - `MomentMethodQuadrature`：基于矩方法的自定义权函数高斯求积（通过 Hankel 矩阵 Cholesky 分解得到 Jacobi 系数）。

### rotor_multiphysics.py
- 电机转子多物理场耦合动力学分析。
- 核心类：
  - `RotorDynamics`：转子运动方程（含齿槽转矩），可模拟转速响应。
  - `EccentricVibration`：转子偏心故障引起的非线性振动模型（极坐标下含非线性刚度项）。
  - `GyroscopicEffects`：高速电机转子的陀螺效应（欧拉方程）。
  - `NonlinearPeriodEstimator`：基于 Urabe 渐近公式估计非线性振动周期，用于偏心故障周期计算。

## 模块间关系
- `main.py` 是顶层调度器，它依次调用：
  - `mesh_engine` 生成网格并保存为 `Mesh2D` 对象。
  - `material_physics` 构建材料库。
  - `fem1d_radial` 进行一维分析，作为初步验证。
  - `fem2d_axi` 使用网格和材料进行二维全场求解，得到磁势及转矩、损耗等。
  - `fem3d_projection` 利用二维解投影到三维网格，计算端部效应。
  - `quadrature_engine` 用于数值积分验证（高斯、蒙特卡洛、矩方法）。
  - `rotor_multiphysics` 基于转矩结果进行转子动力学仿真。
  - `numerical_analysis` 对刚度矩阵进行条件数、正定性、误差估计等分析。
- 各模块之间通过标准 Python 接口（函数调用、类实例化）传递数据，主要依赖 NumPy 和 SciPy。

## 主要算法概述
- **有限元离散**：一维线性元、二维三角形线性元、三维四面体线性元，分别处理径向、轴对称和三维投影问题。
- **线性系统求解**：一维用 Thomas 算法，二维用稀疏直接求解器，三维用稀疏求解器。
- **非线性处理**：二维采用 Newton‑Raphson 迭代，基于磁阻率更新。
- **网格生成**：CVT
