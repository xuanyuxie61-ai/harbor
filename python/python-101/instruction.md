# 光子晶体带隙工程综合计算平台 — 项目说明

本项目是一个零参数可运行的博士级科研计算脚本，用于模拟二维/三维光子晶体的能带结构、带隙特性、制造缺陷与光子输运。项目采用模块化设计，每个模块聚焦于一类物理模型或数值方法，并通过 `main.py` 统一调度，完成从结构生成到局域化分析的完整流程。

## 项目文件说明

以下为项目包含的 Python 源码文件及其主要职责。在后续的 benchmark 复现中，仅保留 `main.py`，其余文件需根据此描述重新实现。

### `physics_core.py` — 核心物理模型与公式库
- 提供所有光速、真空磁导率、真空介电常数等物理常数（SI 单位制）。
- 实现色散介质模型：Lorentz 振子、Drude 自由电子气、Sellmeier 方程，用于计算复介电常数或折射率。
- 提供二维晶格的倒格矢计算，以及正方/三角晶格布里渊区高对称点路径生成。
- 给出二维 TE 偏振的 Helmholtz 算子的离散形式（中心差分），用于麦克斯韦本征问题的构建。
- 定义归一化频率、带隙相对宽度、耦合模方程（右端项）、布拉格反射率解析解、微腔品质因子、三维局域态密度等通用物理量函数。
- 这些函数被其他模块广泛调用，是物理计算的基础。

### `lattice_generator.py` — 光子晶体晶格结构生成器
- 生成二维正方晶格、三角晶格、准周期晶格（基于幻方矩阵调制）、三维木堆结构（Woodpile）以及反蛋白石结构（FCC）的介电常数空间分布。
- 包含通用几何工具：椭圆内部均匀网格点生成、椭球内部均匀网格点生成，以及奇数阶幻方矩阵的构造。
- 输出的介电常数数组是后续能带计算、无序模拟和输运分析的输入。

### `maxwell_eigensolver.py` — 麦克斯韦方程组本征值求解器
- 实现平面波展开法（PWE）求解二维光子晶体能带：构建 TE 模式的哈密顿量矩阵，通过求解本征值问题得到色散关系。
- 提供基于离散正弦变换的谱方法，用于求解一维层状结构的本征模式和频率。
- 集成了多种数值线性代数工具，用于支持本征求解或隐式格式：
  - 对称正定矩阵的 packed Cholesky 分解（`r8pp_fa`）及对应的回代求解（`r8pp_sl`）和矩阵向量乘（`r8pp_mv`）。
  - Gauss-Seidel 迭代法求解线性方程组。
  - 稀疏矩阵的 ST 格式到 CCS 格式的转换，以及 CCS 格式的矩阵向量乘法。
- 这些数值工具既服务于本征求解器，也可被其他模块（如数值核测试）直接调用。

### `bandgap_analysis.py` — 光子晶体带隙分析引擎
- 实现 k 点任务分区算法，用于将布里渊区的大量 k 点计算分配到多个并行任务。
- 提供四阶 Runge-Kutta（RK4）常微分方程求解器，用于时域耦合模传播。
- 利用 RK4 结合线性打靶法，模拟光在布拉格光栅中的传播，并计算反射率，可与解析解对比。
- 实现一维耦合模方程的有限差分时域方法（FDTM），受一维守恒律差分格式启发。
- 提供带隙检测功能：从能带数据中识别光子带隙，计算中心频率、宽度和相对宽度。
- 给出基于经验公式的带隙失配参数估计、缺陷态频率估计以及慢光群折射率计算。

### `dos_calculator.py` — 光子态密度与局域态密度计算器
- 实现单纯形上的均匀采样和体积计算
