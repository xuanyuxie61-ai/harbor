## 项目描述

# Adaptive Optics Wavefront Correction System — High-Fidelity Simulation

## 项目概述
本项目是一个完整的自适应光学（AO）波前校正数值模拟系统。它模拟大气湍流下望远镜接收到的畸变波前，通过 Shack‑Hartmann 波前传感器测量斜率，利用 Zernike 模态或 zonal 重建算法恢复波前，再经由变形镜（DM）和快速倾斜镜（FSM）进行闭环校正。系统包含大气湍流相位屏生成、多物理场扰动（光化学‑热耦合、非线性扩散修正）、控制参数优化、波前传播与焦散分析等模块。所有模块围绕 `main.py` 编排，形成零参数可运行的仿真流水线。

## 模块说明

### 1. `main.py`
**统一入口，零参数可运行。**  
顺序执行以下步骤：系统参数初始化 → 大气湍流相位屏生成 → Shack‑Hartmann 传感器采样 → Zernike 模态分解与 zonal 波前重构 → 变形镜与快速倾斜镜响应 → 闭环 PI 控制迭代 → 光学传递函数、Strehl 比、焦散分析 → 控制参数扫描优化 → 自适应采样与 CVT 优化。  
负责调用所有其他模块，并将结果写入输出文件。

### 2. `atmosphere_turbulence.py`
**大气湍流相位屏生成与多物理场修正。**  
- 实现 Hufnagel‑Valley 折射率结构常数模型，计算 Fried 参数。  
- 基于 Kolmogorov 功率谱和 von Karman 外尺度修正，使用 FFT 生成随机相位屏。  
- 提供多孔介质非线性扩散修正（Barenblatt 自相似解），用于模拟湍流耗散后的残余相位结构。  
- 包含光化学‑热耦合 ODE 系统：臭氧光解引起局部温度变化，进而影响折射率。采用经典 Runge‑Kutta 4 积分器求解。  
- 综合函数 `generate_turbulent_phase_screen` 组合上述步骤，生成最终的相位屏、Fried 参数和掩模。

### 3. `shack_hartmann_sensor.py`
**Shack‑Hartmann 波前传感器仿真。**  
- 生成子孔径网格（支持方形或金字塔型布局）。  
- 对每个子孔径计算平均波前梯度（x 和 y 斜率），并叠加光子噪声和读出噪声。  
- 提供斜率向量与一维数组之间的双向转换，以及构建斜率‑几何矩阵（用于后续重建）的函数。  
- 包含光子噪声估计模型。

### 4. `zernike_modes.py`
**Zernike 多项式模式库与单形约束枚举。**  
- 计算 Zernike 径向多项式（`R_n^m`）和完整的 Zernike 多项式。  
- 支持 Noll 索引到 (n, m) 的转换。
