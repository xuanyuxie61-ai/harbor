# 项目描述：量子纠缠光源全数值模拟平台

## 1. 项目概述
本项目是一个面向博士级科学计算的综合模拟平台，用于研究基于自发参量下转换（SPDC）的量子纠缠光子源。程序覆盖从晶体色散、泵浦传播、量子态演化、联合光谱分析、模式分解、离散参数优化到多种纠缠度量评估的全流程，并在单一入口文件中串联所有模块进行集成验证。

## 2. 文件清单与模块职责

### 2.1 `linear_solver.py`
提供高阶线性代数求解引擎，基于部分主元的高斯消元法、Doolittle 型 PLU 分解以及三角替换求解器，并包含无穷范数条件数估计。该模块被其他需要求解稠密线性系统的模块调用，是整个数值模拟的底层数学支撑。

### 2.2 `pump_propagation.py`
负责泵浦光场在非线性晶体中一维传播的建模。采用二次 Lagrange 有限元方法（FEM）求解含非线性源项和吸收的包络方程，并在求解过程中使用 Picard 迭代处理非线性项。模块同时提供一个基于 Burgers 方程解析思路的泵浦脉冲近似解，用于对比验证。该模块依赖 `linear_solver` 进行线性系统求解。

### 2.3 `quantum_evolution.py`
实现 SPDC 过程三波耦合刚性常微分方程组的时间演化。使用后向欧拉隐式积分法结合 Newton‑Raphson 迭代求解，需计算场振幅对时间的导数及其 Jacobian 矩阵（复数域拆分为实部虚部构成的 6×6 实系统）。模块同时提供 Robertson 型守恒量检查。依赖 `linear_solver` 处理 Newton 步中的线性方程组。

### 2.4 `joint_spectrum.py`
计算双光子联合光谱振幅（JSA），是光谱分析的核心模块。包含归一化 sinc 函数、相位失配计算（结合用户提供的自定义 Sellmeier 色散函数）、高斯型泵浦谱包络函数、相位匹配函数，以及 JSA 组装与归一化。此外，实施基于奇异值分解的 Schmidt 分解，输出 Schmidt 系数、模式函数、Schmidt 数及态纯度。

### 2.5 `mode_analysis.py`
聚焦光子空间‑光谱模式展开。实现归一化连带 Legendre 函数、实球谐函数基底、Jacobi 多项式以及 Bernstein 多项式基函数及其逼近算法。用于横向角向模式分解和光谱包络的光滑逼近。

### 2.6 `phase_space_integral.py`
动量空间高维数值积分引擎，用于计算耦合效率等积分量。集成三种数值求积方法：
- 二维 Fibonacci 格点规则，适用于周期光滑被积函数；
- 参考单位金字塔上的 48 点 Felippa 高阶求积规则；
- 三角形域均匀随机蒙特卡洛积分。
提供统一的积分接口，内部处理积分域映射与面积/体积归一化。

### 2.7 `parameter_optimizer.py`
离散参数空间组合优化模块，服务于准相位匹配晶体设计。提供：
- Gray 码子集枚举，便于高效遍历参数组合；
- 多元非负丢番图方程的整数解计数；
- 子集和问题的回溯搜索；
- 基于简单网格遍历的多参量优化器，在给定允许的极化周期、晶体长度和温度列表中搜索使得用户定义目标函数最大的参数组合。

### 2.8 `network_coupling.py`
多级晶体级联网络模型，用有向图描述模式之间的线性耦合与非线性增益。能够构建邻接矩阵，并将其转化为列随机转移矩阵；实现光子数在多级网络中的递推演化；提供基于 Warshall 算法的传递闭包分析，判断模式间是否存在间接耦合路径。

### 2.9 `entanglement_metrics.py`
量子纠缠度量汇总模块，计算一系列标准纠缠评价指标：
- 并发度（Concurrence），由约化密度矩阵纯度换算；
- von Neumann 纠缠熵，从 Schmidt 系数得到；
- Hong‑Ou‑Mandel 干涉可见度，基于 JSA 进行延迟扫描；
- 态保真度，评估生成态与目标 Bell 态的重叠程度；
- CHSH 不等式 S 参数，由四方关联计数矩阵计算。

### 2.10 `main.py`
程序主入口，无外部运行参数。它按顺序执行以下主要步骤：
1. 构建 KTP 晶体的 Sellmeier 色散函数（泵浦、信号、闲置折射率）；
2. 调用 `pump_propagation` 进行泵浦包络 FEM 求解及 Burgers 近似；
3. 调用 `quantum_evolution` 进行 SPDC 刚性 ODE 演化；
4. 计算 JSA 与 Schmidt 分解，并用纠缠度量评估纯度、并发度、熵等；
5. 通过 `phase_space_integral` 分别以格点、金字塔和三角蒙特卡洛方法计算动量空间耦合效率；
6. 使用 `mode_analysis` 生成球谐函数基底、Jacobi 多项式及 Bernstein 逼近；
7. 利用 `parameter_optimizer` 进行丢番图求解、子集和搜索，并在离散网格上优化极化周期、长度与温度；
8. 构建级联晶体网络并模拟光子数演化，分析传递闭包；
9. 综合输出所有主要物理量，并用 `linear_solver` 验证高斯消元与 PLU 分解的计算精度。

## 3. 核心数据结构与物理模型

- **色散模型**：通过 callable 形式提供 Sellmeier 函数，接受角频率，返回折射率。
- **联合光谱振幅**：复数二维数组（形状 [n_s, n_i]），经归一化和 SVD 分解后得到奇异值，进而导出 Schmidt 系数与纯度。
- **泵浦包络与量子态**：泵浦 FEM 求解器返回各离散节点上的复振幅；量子演化器返回三维复向量（信号、闲置、泵浦场）的时间历史。
- **级联网络**：用 (2·N) × (2·N) 复邻接矩阵表示 N 级晶体中信号与闲置模式的耦合，转移矩阵按列归一化。
- **积分区域与规则**：动量空间积分可映射到周期域、单位金字塔或三角形域，通过不同求积公式计算。
- **参数空间**：优化器遍历离散的一维或三维参数数组（极化周期、长度、温度），比较用户目标函数值得到最优解。

## 4. 主要算法概览

- **线性求解**：带部分主元的高斯消元；Doolittle 型 PLU 分解及三角替换；无穷范数条件数估计。
- **非线性 PDE**：一维稳态二次元 FEM，结合 Picard 迭代，将复系统拆分为实部、虚部组装成 2n 阶实线性系统。
- **刚性 ODE**：后向欧拉隐式格式，每步用 Newton‑Raphson 求解，Jacobian 矩阵经实虚部拆分后求解。
- **SVD 与 Schmidt 分解**：对 JSA 矩阵执行奇异值分解，归一化奇异值平方得到 Schmidt 系数。
- **数值积分**：二维 Fibonacci 格点法（周期域映射）；单位金字塔 48 点 Felippa 规则（权重点固定）；三角形域蒙特卡洛（均匀采样与面积加权）。
- **多项式逼近**：Bernstein 基函数递推构建，等距节点逼近光滑函数。
- **组合与优化**：Gray 码生成子集序列；递归求解多元丢番图方程；回溯法搜索子集和；简单网格搜索多参量最大化。
- **图论**：邻接矩阵列归一化得到转移矩阵；递推方程模拟光子数演化；Warshall 算法计算传递闭包。
- **纠缠度量**：纯度到并发度的闭合公式；香农熵式纠缠熵计算；HOM 可见度通过延迟扫描并搜索驻波极值；保真度基于离散目标态重叠积分；CHSH 参数通过计数矩阵结合相关函数定义计算。
