## 项目描述

# 量子点单光子发射综合模拟系统 项目描述

本项目是一个面向光学工程前沿的 Python 模拟工具，围绕“半导体量子点单光子发射的理论建模与性能优化”展开。系统将多个科学计算核心算法集成到一个结构化流程中，主要涉及：量子点电子/空穴受限态求解、波函数特殊函数积分、微腔网格与电磁场模式、量子点-微腔耦合主方程、单光子统计、系综聚类、界面粗糙度效应，以及参数优化。

运行时入口为 `main.py`，它依赖十个功能模块文件，按逻辑依次执行八个计算步骤并输出结果。后续 stripped 版本将只保留 `main.py`，所有缺失的模块文件需要根据本描述还原实现。

## 文件职责与模块边界

### 1. `utils.py` — 通用工具与基础线性代数
提供整个项目公用的基础设施：
- 一维/二维数组的形状与有效性校验函数。
- 安全求倒数（避免除零）。
- 一维有限差分动能项所需的 COO 格式稀疏矩阵索引构建函数，返回 (row, col, data) 三元组，用于后续 Hamiltonian 构造。
- 稀疏矩阵-向量乘法（COO 格式）。
- 稠密方阵条件数估算（基于特征值）。
- 三对角线性方程组的 Thomas 算法求解器。
- 文本文件读写矩阵的简易 IO 函数。

### 2. `qd_hamiltonian.py` — 量子点哈密顿量构建
提供半导体量子点中载流子有效质量薛定谔方程的相关组件：
- 根据材料名查询有效质量（相对于自由电子）。
- 构造球形势阱限制势（阱内为零，阱外为给定势垒高度）。
- 构造 Stark 电场线性势。
- 构造谐波限制势。
- 一维等效库仑势（带正则化，避免原点发散），用于激子计算。
- 使用 `utils` 的稀疏索引构建一维动能哈密顿量，并乘以相应物理系数。
- 将势能数组添加为哈密顿量的对角元。
- 将 COO 稀疏矩阵转换为稠密矩阵。
- 求解一维有效质量薛定谔方程的本征值与本征函数（支持选配球形或谐波势），内部组合动能与势能，调用 numpy 的 eigh。
- 计算两个波函数间的电偶极矩矩阵元（梯形积分）。
- 通过双积分估算激子结合能（Hartree 近似）。
- 计算电子与空穴的约化质量。

### 3. `wavefunction_solver.py` — 特殊函数积分与径向波函数求解
结合多项式积分与打靶法求解球对称量子点径向波函数：
- 计算 Gegenbauer 权函数。
- 基于 Clenshaw-Curtis 节点计算函数偶次 Chebyshev 系数。
- 实现 Gegenbauer-Clenshaw-Curtis 积分算法，用于带权函数的正交多项式积分。
- 计算 Newton 插值所需的差商表。
- 使用差商表在任意点求插值多项式的值。
- 利用差商与 Newton 插值在细网格上重构势场分布。
- 使用 Numerov 打靶法求解径向薛定谔方程，给定能量猜测返回波函数和边界残差。
- 在能量区间内扫描检测残差符号变化定位束缚态本征能量，并用二分法 refine，返回前若干个束缚态的能量与波函数。

### 4. `mesh_generator.py` — 二维四边形网格生成
提供微腔/量子点圆形区域的四边形网格及其几何操作：
- 根据鞋带公式计算三角形面积。
- 通过分割为两个三角形计算任意四边形的面积，自动处理顶点顺序。
- 实现参考正方形到任意物理四边形的双线性等参映射。
- 在圆形区域生成极坐标映射的结构化四边形节点和单元索引，径向可非均匀分布。
- 计算所有单元面积及网格总面积。
- 将定义在节点上的标量场平均到单元中心值。
- 在单个四边形内按面积比例随机采样点。
- 在整个网格上按单元面积加权随机采样点，并返回采样坐标与所属单元索引。
- 基于射线法判断点是否在多边形内，并用网格点计数估算多边形面积。

### 5. `em_field.py` — 电磁场模式计算与插值
提供微腔电磁场模式模拟及自发辐射增强相关计算：
- 构造高斯光束横向分布。
- 构造圆盘微腔的简化洛伦兹型场模式近似。
- 基于 FEM 思想计算二维等效模式面积：遍历四边形单元，利用单元面积与单元中心场强加权求和，求得分母最大值，返回积分与最大值之比。
- 计算 Purcell 因子（三维修正），依赖品质因子、有效模式体积、波长和有效折射率。
- 使用反距离加权插值在非结构化网格上估计查询点的场值。
- 用一维有限差分离散化求解 Helmholtz 方程的本征值问题（TE 偏振简化），返回本征值、等效传播常数和模式分布。
- 根据 Fermi 黄金定则计算自发辐射速率。

### 6. `master_equation.py` — Lindblad 主方程求解
处理量子点-腔耦合开放量子系统的动力学：
- 在基矢 {|g,n>, |e,n>} 下构建 Jaynes-Cummings 哈密顿量矩阵，包含腔场、量子点能量和旋波近似耦合项。
- 计算单个 Lindblad 耗散超算符的作用（D[L]ρ 形式）。
- 组合 coherent 和 dissipative 项，得到主方程右侧 dρ/dt。
- 实现密度矩阵的按列矢量化及其逆变换。
- 利用 Kronecker 积构建 Liouvillian 超算符 L，满足 d vec(ρ)/dt = L vec(ρ)。
- 通过求解 L vec(ρ_ss) = 0 并施加迹约束得到稳态密度矩阵。
- 提供隐式中点法积分器，用于时间演化 ODE 系统，对线性系统自动解析求解传播子。
- 指定初始密度矩阵、跳跃算符和衰减速率，数值求解 Lindblad 主方程的时间演化轨迹，返回时间序列和各时刻的密度矩阵。
- 从密度矩阵中提取激发态占据概率。
- 计算腔中平均光子数。
- 检查演化过程中密度矩阵的迹是否守恒。

### 7. `photon_statistics.py` — 单光子发射统计与蒙特卡洛模拟
提供二阶关联函数分析及随机探测统计：
- 在单位圆盘内均匀采样（径向概率密度线性）。
- 估计单位圆盘内两随机点距离的均值与方差。
- 基于弱耦合极限的简化模型计算二阶关联函数 g^(2)(τ)，在耦合较强时加入振荡修正。
- 根据 g^(2)(0) 值将光源分类为强反聚束、弱反聚束或聚束/泊松。
- 基于泊松发射和探测效率，用蒙特卡洛方法模拟光子探测事件，统计零光子、单光子和多光子概率。
- 模拟 Hanbury Brown-Twiss 实验的时间符合计数直方图，加入随机噪声。
- 估计 HOM 干涉可见度，考虑纯态重叠度与退相干。
- 根据高斯光束和探测器几何尺寸估算探测器接收效率。

### 8. `state_clustering.py` — 量子点系综聚类
基于非层次聚类算法对量子点发射谱进行分类：
- 计算类内方差和作为聚类准则。
- 实现 Transfer 步骤：将对象从当前类移到另一类如果降低准则。
- 实现 Swap 步骤：交换两个不同类对象如果降低准则。
- 使用 k-means++ 风格初始化，交替进行 Transfer/Swap 优化直到收敛，返回标签、类中心、类大小和准则历史。
- 提供封装接口，对量子点能量和线宽进行二维聚类分类。
- 定义光谱纯度指标，结合线宽和温度给出量化值。
