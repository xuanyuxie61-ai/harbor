## 项目描述

# 蛋白质折叠自由能景观多尺度数值分析系统

## 项目背景

本项目是一个面向蛋白质折叠自由能景观（Free Energy Landscape）的多尺度数值分析框架。核心问题是：对于一个简化的粗粒化蛋白质模型（10–12 残基），通过多种数值方法从不同角度计算并分析其自由能景观、动力学、统计特性以及几何特征。系统以 `main.py` 为单一入口，零参数运行，会完成一系列计算任务并输出报告与数据文件。

## 项目目标

通过组合整合多个数值方法模块，实现以下科学目标：

- 计算反应坐标（Q 分数、RMSD、回转半径等）并生成二维反应坐标网格；
- 用 Chebyshev 谱方法插值一维自由能剖面；
- 用 p-version 有限元方法求解沿反应坐标的稳态 Smoluchowski 扩散方程，并提取 Fokker‑Planck 算子的特征值；
- 用 Feynman‑Kac 路径积分方法计算折叠概率与平均首通时间，并对比 Kramers 速率理论；
- 通过球面数值积分计算取向序参数，验证溶剂效应；
- 在三维构象空间子域上计算局部配分函数；
- 生成距离函数驱动的自适应二维网格；
- 构建弹性网络模型（ENM）并进行正常模式分析；
- 利用多项式结式分析势能面的临界点与分岔点；
- 使用 Sigmoid 平滑截断函数模拟 MD 力场中的过渡区域；
- 通过不完全 Gamma 函数分析亚稳态停留时间分布；
- 利用贪心划分算法进行结构域划分与负载均衡；
- 从四面体网格中提取自由能盆地的边界，计算表面积与体积。

各模块间通过函数调用在 `main.py` 中串联，形成完整的计算管线。
