# 任务：复现缺失模块

## 目标
你面对的是一个 Python 科研代码项目。部分源码文件已缺失，导致程序无法完整运行。你需要根据保留的入口代码和项目描述，补全缺失模块，使项目恢复预期功能。

## 工作目录
代码仓库位于 `/app` 目录下。

## 项目描述

# 项目描述：DNA 损伤修复分子动力学综合模拟平台

该项目围绕 DNA 双链断裂修复的分子机制，整合多尺度计算方法，包含多个独立模块。
每个模块对应一个或多个 Python 文件，实现特定的物理模型或数值算法。
后续 benchmark 将保留 `main.py`，删除其余 `.py` 文件，要求根据本描述复现缺失代码。

---

### 模块 1: 染色质拓扑与四面体网格

#### `dna_topology.py`
- 提供粗粒化 DNA 单链拓扑生成器 `DnaCoarseGrainTopology`。
- 根据螺旋参数方程生成珠子链的三维坐标和骨架切向量。
- 基于 WLC 模型计算持久长度校正的弯曲刚度。
- 支持双倍分辨率网格填充（用于密度映射）。
- 可生成带单链泡的 DNA 结构，标记暴露区域与结合位点。
- 额外包含螺旋数据生成函数和 WLC 末端距计算。

#### `tet_mesh_core.py`
- 提供四面体网格生成和体积积分算子。
- 基于 Cayley-Menger 行列式计算四面体体积。
- 将长方体区域离散化为规则四面体网格。
- 在四面体网格上对节点标量场进行线性积分（四点平均法则）。

#### `mesh_integrals.py`
- 额外提供围绕核蛋白丝骨架构建同心圆柱壳四面体网格的方法。
- 实现简化的 TEC 格式解析器，读取节点坐标、单元连接和场数据。
- 将四面体网格输出为简化 XML 文件。
- 通过电荷密度与静电势的体积乘积估算溶剂化自由能。

### 模块 2: 修复蛋白布朗动力学

#### `brownian_dynamics.py`
- 实现 overdamped Langevin 方程积分的 `OverdampedLangevinIntegrator` 类。
- 使用 Euler‑Maruyama 格式，包含核内软边界。
- 计算多个蛋白在 3D 核质中的扩散轨迹。
- 提供 DNA 修复蛋白受到的合力计算：高斯型势阱吸引簧与短程排斥。
- 实现 Henon 混沌映射用于模拟染色质拥挤环境下的非线性偏转。
- 提供正态分布 ODE 精确解，用于描述修复因子空间密度。
- 集成 KU80 搜索时间模拟，输出首次通过时间、结合分数和均方位移。

### 模块 3: 反应‑扩散动力学

#### `reaction_diffusion.py`
- 实现 Gray‑Scott 反应‑扩散模型的 `gray_scott_step`，使用 9 点或 5 点拉普拉斯算子（周期边界）。
- 提供 γH2AX 信号波传播模拟：初始高斯损伤斑块，跟踪波前半径估计传播速度。
- 实现多孔介质方程（Barenblatt 精确解）及相关非线性扩散模拟。
- 计算 PDE 残差、L² 误差，模拟 PARP1 聚集。

#### `reaction_diffusion_dynamics.py`
- 提供 Gray‑Scott 步进函数与模拟接口，包含 CFL 自适应调整。
- 提供多孔介质方程 Barenblatt 解的全套偏导数。
- 在一维 DNA 链上实现蛋白扩散‑结合‑解离的反应扩散模型。
- 基于 Fisher‑KPP 方程近似计算反应前沿速度。

#### `protein_diffusion.py`
- 提供沿 DNA 的 1D 滑动扩散步进（Smoluchowski 方程），考虑势能景观的漂移项。
- 实现多孔介质方程的 1D 步进（非线性扩散系数）。
- 计算 Barenblatt 自相似解和正常模弛豫解析解。
- 给出滑动搜索时间的理论公式（基于 1D 扩散首次通过时间）。

### 模块 4: 自由能景观与降维

#### `energy_landscape.py`
- 实现 Sammon 非线性映射，用于高维构象（如蛋白二面角）到 2D 的降维。
- 提供二维分段线性插值（PWL），基于矩形网格的三角形分割和重心坐标插值。
- 构建基于 MD 轨迹的自由能表面：通过直方图统计得到概率密度，再经 Boltzmann 反演得到自由能，并用 PWL 插值光滑。
- 计算正则单形顶点坐标（用于多态构象均衡采样）。

#### `potential_energy.py`
- 提供正态分布 ODE 的精确解及其导数。
- 提供二维分段线性插值（标量与矢量版本），支持 Lennard‑Jones、Morse 和高斯型束缚势网格构建。
- 计算从势能表面网格插值的保守力（负梯度）。
- 提供 RAD51‑DNA 结合能估算。

#### `potential_surface.py`
- 实现另一种 2D 分段线性插值方案，基于矩形网格的对角线分割和重心坐标。
- 构建 DNA 修复蛋白的模型能量面：弯曲能、Lennard‑Jones 排斥、损伤识别阱以及激活能垒。
- 沿反应物‑产物间的直线路径计算活化能垒。

#### `conformation_sampling.py`
- 生成螺旋和圆形构象点集，模拟蛋白沿 DNA 沟槽的扫描路径或闭环构象变化。
- 生成正则单形顶点及其附近的采样点，用于多态平衡。
- 实现 Sammon 映射（用于高维数据降维），带梯度下降优化。
- 生成 Henon 保面积映射轨迹及其最大 Lyapunov 指数，量化构象搜索的混沌程度。

### 模块 5: 电静力学 Poisson‑Boltzmann 求解

#### `electrostatics.py`
- 计算 Debye 长度。
- 建立非迭代非线性 PB 方程的 Jacobian 和残差（稀疏矩阵，Neumann 边界）。
- 实现 Newton 迭代求解非线性 PB 方程（2D 五点离散）。
- 组装 DNA 电荷密度分布。
- 通过四面体网格积分计算静电自由能。

#### `electrostatic_solver.py`
- 计算 Debye‑Hückel 参数。
- 组装线性化 PB 方程的 Jacobian（2D 五点差分），支持 Neumann/Dirichlet 边界。
- 实现一般带状矩阵的 LU 分解和求解（从 LINPACK 风格简化）。
- 求解线性化 PB 方程得到电势分布。
- 插值计算静电结合能。

#### `sparse_solver.py`
- 实现带状矩阵的 PLU 分解与线性求解器（`BandedLU` 类），采用 R8GB 风格压缩存储。
- 组装 1D 非线性 PB 方程的 Jacobian 和残差。
- 集成 Newton 迭代求解 1D PB 方程，使用带状 LU 求解器。
