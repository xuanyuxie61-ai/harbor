本项目基于 **15 个种子科研代码项目**的核心算法，融合构建了一个面向**分子动力学：酶催化反应过渡态搜索**的博士级科学计算框架。项目使用 Python 语言实现，包含 11 个 `.py` 文件，零参数运行，无任何可视化代码。

## 指定科学领域

**分子动力学：酶催化反应过渡态搜索**

### 科学问题描述

酶催化反应的速率由过渡态（Transition State, TS）的自由能决定。根据过渡态理论（Eyring, 1935）：

```
k = (k_B T / h) * (Q‡ / Q_R) * exp(-ΔG‡ / (k_B T))
```

其中：
- `Q‡`：过渡态配分函数（恰有一个虚频模式）
- `Q_R`：反应物配分函数
- `ΔG‡ = G(ξ‡) - G(ξ_R)`：活化自由能
- `ξ`：反应坐标

过渡态的几何判据（一阶鞍点）：

```
∇V(x‡) = 0
H(x‡) 恰有一个负特征值 λ₁ < 0
```

对应的虚频：

```
ν_imag = √(|λ₁|) / (2πc)   [cm⁻¹]
```

本项目实现从分子拓扑构建 → 静电势计算 → 势能面插值 → 反应路径优化（NEB/弦方法）→ 过渡态定位与 Hessian 验证 → 热力学积分与速率常数计算的完整计算流程。

## 核心数学物理模型与公式

### 1. Poisson-Boltzmann 静电学

酶活性位点的静电势满足：

```
-∇²φ = ρ/ε₀          （真空/蛋白区域）
-∇²φ + κ²φ = ρ/ε₀    （溶剂区域）
```

其中 Debye-Hückel 屏蔽参数：

```
κ² = 2000 N_A e² I / (ε₀ ε_r k_B T)
```

有限差分离散化（五点模板）：

```
(φ_{i+1,j} + φ_{i-1,j} + φ_{i,j+1} + φ_{i,j-1} - 4φ_{i,j}) / h² = -ρ_{i,j}/ε₀
```

### 2. RBF 势能面插值

从头算稀疏采样点 `{x_i, V_i}` 的连续重建：

```
Ṽ(x) = Σᵢ wᵢ φ(||x - xᵢ||)
```

权重通过解线性方程组确定：

```
A w = V,    A_{ij} = φ(||x_i - x_j||)
```

核函数：
- 高斯：`φ(r) = exp(-r²/(2r₀²))`
- 逆多二次：`φ(r) = 1/√(r² + r₀²)`
- 薄板样条：`φ(r) = r² log(r/r₀)`

### 3. 弦方法（String Method）

最小能量路径（MEP）的演化方程：

```
∂γ/∂t = -∇V^⊥(γ) = -[∇V(γ) - (∇V·t̂) t̂]
```

其中 `t̂ = ∂γ/∂s / |∂γ/∂s|` 为路径单位切向量。

### 4. Nudged Elastic Band (NEB)

第 `i` 个图像的受力：

```
F_i = F_i^⊥ + F_i^∥
F_i^⊥ = -∇V(R_i) + (∇V(R_i)·τ̂_i) τ̂_i
F_i^∥ = k (|R_{i+1} - R_i| - |R_i - R_{i-1}|) τ̂_i
```

攀爬图像（CI-NEB）修正：

```
F_i^{climb} = -∇V(R_i) + 2(∇V(R_i)·τ̂_i) τ̂_i
```

### 5. 广义 Gauss-Laguerre 正交

热力学积分中的指数权重积分：

```
∫_a^∞ (x-a)^α exp(-b(x-a)) f(x) dx ≈ Σᵢ wᵢ f(xᵢ)
```

节点和权重由 Jacobi 矩阵的特征值问题确定：

```
J = diag(α₀, α₁, ...) + offdiag(β₁, β₂, ...)
αᵢ = 2i + 1 + α
βᵢ = √(i(i + α))
```

### 6. 多边形矩积分（Steger 公式）

非归一化矩：

```
ν_{pq} = ∮_P x^p y^q dx dy
       = Σ_{边} (x_j y_i - x_i y_j) S_{pq} / [(p+q+2)(p+q+1)C(p+q,p)]
```

中心矩（用于惯性张量）：

```
μ_{pq} = (1/A) ∮_P (x - x̄)^p (y - ȳ)^q dx dy
```

### 7. Clausen 函数与扭转势

Clausen 函数：

```
Cl₂(θ) = -∫_0^θ ln|2 sin(t/2)| dt = Σ_{k=1}^∞ sin(kθ) / k²
```

二面角扭转势（CHARMM/AMBER 力场）：

```
V(φ) = Σ_n (V_n/2) [1 + cos(nφ - γ_n)] - 0.1 Cl₂(2φ)
```

### 8. 稀疏 Hessian 与 Lanczos 算法

Lanczos 三对角化：

```
v₁ = random / ||random||
for j = 1, 2, ..., m:
    w = A v_j - β_j v_{j-1}
    α_j = v_j^T w
    w = w - α_j v_j
    β_{j+1} = ||w||
    v_{j+1} = w / β_{j+1}
```

Ritz 值 `λ(T_m)` 逼近 `A` 的极端特征值，用于验证过渡态恰有一个负特征值。

### 9. 隧道效应校正（Wigner 近似）

```
κ(T) = 1 + (1/24) (h c ν̃ / (k_B T))²
```

校正后速率常数：

```
k_corr = κ(T) · k_TST
```

## 边界处理与数值鲁棒性

1. **Chebyshev 级数**：自动检测 `x ∈ [-1.1, 1.1]`，越界报错
2. **CRS 稀疏矩阵**：完整维度一致性检查、列索引越界检测、行指针单调性验证
3. **Poisson 求解**：`phi` 值裁剪防止 `exp()` 溢出；边界条件双重修正
4. **RBF 插值**：正则化对角项（`1e-10`）防止矩阵奇异；自动 `r₀` 估计
5. **RKF45 积分**：步长下限保护（`h_min = 26ε|t|`）；失败步自动回退；最大函数评估限制
6. **Gauss-Laguerre**：`α > -1` 与 `b > 0` 参数校验
7. **多边形矩**：零面积检测与除零保护
8. **NEB/弦方法**：端点固定；切向量归一化保护；最大迭代限制
9. **过渡态验证**：梯度范数阈值；Hessian 特征值符号统计；虚频存在性检查
10. **Lanczos 算法**：迭代次数上限；三对角矩阵特征值排序

## 科学问题的前沿性

本项目涉及以下前沿科学计算技术：

- **Nudged Elastic Band (NEB)**：目前酶催化过渡态搜索的行业标准方法
- **String Method**：MEP 优化的变分框架，由 E, Ren, Vanden-Eijnden (2002, 2007) 发展
- **RBF 插值 PES**：从稀疏 DFT 数据构建连续势能面的机器学习方法
- **Poisson-Boltzmann 静电学**：大尺度生物分子静电的连续介质理论
- **Lanczos 算法**：大规模稀疏矩阵极端特征值计算，适用于 >10⁵ 原子体系
- **Wigner 隧道校正**：低温酶催化中的量子力学隧道效应修正

计算难度达到博士级别，涉及偏微分方程、泛函优化、稀疏线性代数、特殊函数、随机采样等多领域交叉。
