## 项目描述

# 项目概述：脂质双分子层凝胶-液晶相变综合模拟

本项目实现了一个粗粒化分子动力学模拟框架，用于研究脂质双分子层的凝胶相（Lβ’）与液晶相（Lα）转变。系统将双层膜投影到二维格点上，通过取向序、面积压缩和疏水相互作用描述能量，并整合了稳态热场、聚类分析、组合采样、自由能积分、渗透路径、相图分析和稀疏矩阵操作等多种计算工具。主入口脚本 `main.py` 依次调用各模块，运行完整的模拟流程并输出结果。

后续将保留 `main.py`，删除所有其他 `.py` 文件，要求根据本描述重新实现缺失的模块。

## 文件清单与职责

| 文件名 | 主要职责 |
|--------|----------|
| `bilayer_system.py` | 核心系统：定义二维格点上的粗粒化脂质双分子层，计算能量、力、局域/全局序参数，并使用 Jacobi 迭代求解稳态温度场。 |
| `clustering_analysis.py` | 构建脂质分子间的特征距离矩阵，执行层次聚类（单连锁），切割聚类树以识别畴结构，估算畴大小分布和界面能。 |
| `combinatorial_sampler.py` | 利用组合算法（回溯搜索、Gray 码、子集枚举、整数划分、背包问题）对构象空间进行离散采样。 |
| `density_profile.py` | 基于 Bernstein 多项式基函数拟合跨膜质量密度轮廓，计算膜厚度、面积压缩模量和弯曲刚度。 |
| `free_energy.py` | 使用稀疏网格（Smolyak 构造）进行多维自由能积分，并实现 Maier-Saupe 平均场自由能与相变温度估计。 |
| `grid_topology.py` | 生成多种计算网格（矩形、极坐标、三角网格），实现基于“边界词”的膜区域边界追踪，计算周长、面积和度量张量。 |
| `integrator.py` | 提供速度 Verlet 积分器（含 Langevin 热浴），并分析积分器在复平面上的绝对稳定区域。 |
| `order_parameters.py` | 利用 Jacobi 多项式展开取向分布函数，计算各阶序参数、取向熵及 Debye-Waller 因子。 |
| `permeation_analysis.py` | 将跨膜自由能场转换为加权图，用 Dijkstra 算法寻找最低自由能渗透路径，并估算渗透系数。 |
| `phase_diagram.py` | 通过 Newton-Maehly 多项式求根与自洽方程计算相变温度，构建相图；用 Duffing 非线性振荡器描述膜厚度涨落，估计最大 Lyapunov 指数。 |
| `sparse_matrix_ops.py` | 提供稀疏矩阵操作：邻接表转 CSR 格式、Reverse Cuthill-McKee 重排序、带宽计算；基于转移矩阵的 Markov 态模型（幂法求稳态分布、PageRank 重要性排序、隐含时间尺度）。 |
