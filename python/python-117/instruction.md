## 项目描述

# 项目描述：纳米颗粒‑生物膜相互作用的粗粒化分子动力学模拟框架

本项目是一个多物理场耦合的数值模拟框架，用于研究带电纳米颗粒与磷脂双分子层之间的相互作用。主程序 `main.py` 串联了 11 个功能模块，涵盖环境检测、拓扑校验、网格生成、静电求解、输运模拟、能量积分、统计采样、随机力生成、平衡搜索、神经网络代理以及朗之万动力学。下文将描述除 `main.py` 外，需要被复现的各个 Python 模块的职责、核心数据结构和主要公开接口。
