# 脑血流动力学多尺度耦合模拟与血管网络质量评估系统

## 项目概述
这是一个多尺度脑血流动力学模拟框架，涵盖血管几何建模、血流压力波传播、组织氧扩散、血管重构、血细胞竞争和随机采样等计算模块。主程序 `main.py` 串联九个模拟阶段并生成综合报告，所有它依赖的算法分散在多个独立的 Python 模块中。本 benchmark 任务要求：保留 `main.py` 不变，删去除此之外的所有 `.py` 文件，然后依据本文档的描述和 `main.py` 中的导入与调用，复现每一个缺失模块。

## 模块细节与边界

### 1. cerebral_vascular_mesh.py —— 脑血管网格生成
利用 DistMesh 技术生成非结构化网格。模块提供若干有向距离函数（SDF），如二维圆、矩形、三维球以及差集、并集操作。然后使用这些 SDF 指导初始点云生成，并通过类似弹簧网络的力平衡迭代优化节点位置。迭代中反复进行 Delaunay 三角化，并剔除区域外的三角形。出口为二维和三维网格的节点坐标数组及面/体单元数组。此外，封装了两个预定义函数：生成 Willis 环二维截面网格和简化三维脑血管网格。

### 2. network_topology_quality.py —— 血管网络拓扑质量评估
对网格三角形/四面体计算几何质量指标：三角形 Q 度量（基于内切/外接圆半径）、最小/最大角比（Alpha 度量）；四面体质量用体积‑边长比衡量。还包含点集的球填充度量（计算每个点最大不重叠球半径，并将球体积之和与域体积比较）以及网格连通性的半带宽。综合函数将所有这些指标合成一份字典式质量报告，供主程序调用。

### 3. blood_pressure_wave.py —— 血压波传播与压力场
- **Laplace 径向精确解**：给出二维（对数型）和三维（反比型）径向解及其导数，用于描述圆柱/球腔中的稳态压力场并检验离散求解器。
- **Burgers 方程 Godunov 求解器**：针对无粘 Burgers 方程，实现 Godunov 数值通量（求解 Riemann 问题以区分冲击波与稀疏波），并构建时间推进格式。支持周期和 Dirichlet 边界条件。
- **二元件 Windkessel 模型**：将动脉顺应性和外周阻力模型离散化，提供出口压力随时间演化的递推解。
- **Poiseuille 流量**与**网络压力场**：根据 Poiseuille 定律计算圆管体积流量；基于水力阻力网络构建电导矩阵，施加 Dirichlet 边界条件来求解血管网络节点压力分布。

### 4. tissue_oxygen_diffusion.py —— 组织氧扩散与代谢
- 求解一维和二维（径向）反应‑扩散方程（Fisher‑KPP 型），采用 FTCS 显式格式，自动检测并调整时间步以满足 CFL 条件。一维支持 Dirichlet/Neumann 混合边界；二维径向模型模仿 Krogh 圆柱几何，毛细血管壁固定为高氧浓度，组织远端为无通量条件。
- 提供 Michaelis‑Menten 消耗速率函数和 Krogh 圆柱稳态氧张力解析解。

### 5. vascular_remodeling.py —— 血管重构动力学
- 定义 SIR 型血氧三室系统（含氧血 → 脱氧血、恢复室）和 Lotka‑Volterra 型内皮‑凋亡竞争系统的右端项。
- 用一个耦合 ODE 将以上两者与血管半径演化结合，半径变化受壁面剪切应力相对于参考值的偏差驱动，并使用 `scipy.integrate.solve_ivp` 求解。
- 提供 Murray 对称分支定律（母管半径与子管半径的立方和守恒）和基于牛顿流体的壁面剪切应力公式。

### 6. blood_cell_dynamics.py —— 血细胞动力学与统计变异性
- 通过经验公式计算微血管中的表观粘度（Fahraeus‑Lindqvist 效应）以及红细胞在分叉处的压积分配。
- 实现 ASA111 算法（正态分布下侧分位数），用于将均匀随机数转换为正态分布样本，进而生成血流速率变异性。
- 模拟“Jai‑Alai”淘汰赛模型：一组具有不同强度（代表流变特性）的选手（细胞群）通过两两概率竞争决出胜者，以此描述血细胞在分叉点的选择。
- 生成叠加了正弦脉动和高斯噪声的随机血流时间序列。

### 7. vascular_branching.py —— 血管分支递归生成
- 定义一个类 Collatz 分支规则：当当前血管半径大于毛细血管阈值时生成两个子血管（可根据随机数选择对称或非对称分叉）。
- 利用 Murray 能量最小化原理计算两个分支之间的角度。
- 构建 `VascularBranch` 节点类，并通过广度优先队列递归生成一整棵三维血管树，每级分支的长度和方向均带有随机扰动。
- 提供对生成树进行统计（分支数、代数、半径范围、总长度等）的函数。

### 8. flow_cycle_analysis.py —— 血流周期性与循环检测
- 实现 Brent 循环检测算法：对离散映射迭代快速找到循环长度 λ 和进入循环前的步数 μ。
- 定义一个离散脑血管自调节映射，包含血压反馈、自身调节项和心脏脉动项。
- 将连续血流序列量化为离散状态并构建转移规则，然后调用 Brent 检测是否存在周期。
- 使用 FFT 给出频谱主频，并结合周期和频谱对血流状态进行分类（正常、心律失常、病理振荡等）。

### 9. hemodynamic_integrals.py —— 血流积分与随机采样
- 提供单位四面体上单项式积分的解析公式和四面体体积计算，并能在四面体内均匀采样，用于基于四面体网格计算血容量。
- 实现超球面与超球体内的均匀采样（基于正态分布随机向量法），进而支持在三维血管截面上产生随机空间点。
- 用蒙特卡罗方法对给定的速度剖面函数求血管截面流量。
- 提供 TRIANGLE 格式的节点文件和单元文件的读写函数，实现临时网格数据的保存与加载。
