## 缺失文件列表及功能描述

### 1. `utils.py`
**职责：底层数值工具与数学辅助函数。**  
为所有模块提供基础函数，是项目的通用依赖。
- **Gauss‑Legendre 求积**：生成 `[-1,1]` 区间上的 `n` 点节点和权重，用于高精度积分与 Cauchy 主值计算。
- **Logistic 变换**：将实数映射到开区间 `(a,b)`，并支持反变换，用于约束参数到合法范围。
- **标准正态分布**：提供 `cdf` 和 `pdf` 的稳定计算。
- **正定性判断**：基于特征值判断矩阵是否正定。
- **最近相关性矩阵**：采用投影方法（Higham 2002）从任意对称矩阵构造一个对称半正定、对角线为 1 的相关性矩阵。
- **Cholesky 分解（带截断）**：先尝试普通 Cholesky，失败时用特征值截断构造下三角因子。
- **三对角线性方程组求解**：Thomas 算法，用于有限差分离散形成的三对角系统。
- **一维二阶中心差分**：用于有限差分运算。

### 2. `copula_quadrature.py`
**职责：三角形域数值积分与 Cauchy 主值积分，应用于高斯/t‑Copula 联合违约概率计算。**
- 实现 **Lyness‑Jespersen 三角形求积规则**：在内置权重表（规则编号 1、3、7）中将对称重心坐标展开为完整求积点，支持任意三角形上的积分。
- 提供 **标准三角形上的积分接口**。
- 实现 **Cauchy 主值积分**：基于 Gauss‑Legendre 节点的双段拆分方法，处理 `f(x)/(x - x_sing)` 型奇点，数值上使用减奇性技巧。
- 提供 **二元高斯 Copula 的直接数值积分**：利用 Gauss‑Legendre 张量积和二元正态密度近似计算联合违约概率。

### 3. `default_contagion_ode.py`
**职责：违约传染动态系统的 ODE 建模与 Theta 方法数值求解。**
- 定义了一个三变量耦合 ODE 系统（借鉴化学振荡模型的信用传染动力学），刻画违约强度、传染压力与系统性缓冲的演化。
- 实现 **Theta 方法求解器**：支持 `theta=0.0, 0.5, 1.0`，通过简化的不动点迭代处理隐式步，并输出时间序列。
- 封装 **模拟违约传染** 的便捷接口。
- 提供 **网络级联增强函数**：基于邻接矩阵和耦合强度，计算每个区域考虑网络效应后的违约强度。

### 4. `factor_orthogonalization.py`
**职责：基于 Gram‑Schmidt 正交化的宏观经济因子载荷矩阵正交化。**
- 实现 **修正 Gram‑Schmidt (MGS)** 和 **经典 Gram‑Schmidt** 分解，将因子载荷矩阵分解为 `Q`（正交基）和 `R`（上三角）并返回有效秩。
- 提供 **从正交载荷计算资产间相关性矩阵** 的函数，依据因子模型公式，确保对角线为 1 且半正定。
- 提供 **信用因子正交化接口**：对原始载荷转置做 MGS/CGS，再将资产投影到正交基上，并截断过大的载荷保证 `R² ≤ 1`。

### 5. `interpolation_surfaces.py`
**职责：多维曲线插值与离散节点生成。**
- 实现 **Lagrange 全局多项式插值**和**分段线性插值**，后者是信用曲线期限结构（如 PD、spread）的标准插值方法。
- 节点生成：**Clenshaw‑Curtis**、**Fejér 类型 1**、**Fejér 类型 2**，均映射到 `[a,b]` 区间。
- 实现 **弧长参数化**：给定多维点列，计算归一化弧长参数。
- 封装 **信用曲线插值统一接口**，支持 `"linear"` 和 `"lagrange"` 两种方法。

### 6. `lattice_enumeration.py`
**职责：N 维单形格点枚举，用于组合权重网格与相关性参数网格生成。**
- 采用递归算法生成 `n` 维非负整数向量满足 `Σx ≤ t` 的所有组合。
- 提供 **格点列表** 和 **迭代器** 两种形式。
- 生成 **组合权重网格**：将 `t` 个单位的格点归一化为和为 1 的权重向量。
- 生成 **相关性矩阵特征值单形网格**：用于系统性探索不同谱结构的相关性矩阵。

### 7. `linear_solver_cgne.py`
**职责：共轭梯度法求解法方程，用于隐含相关性校准。**
- 实现 **CG‑NE**（共轭梯度法应用于法方程）求解 `A^T A x = A^T b`，输出解、迭代次数和残差范数。
- 实现 **带 Tikhonov 正则化的 CG‑NE**，求解 `(A^T A + λI)x = A^T b`，用于病态情况。
- 包含 **Helmert 正交矩阵** 和 **LESP 三对角测试矩阵** 的构造函数，用于测试求解器。

### 8. `portfolio_knapsack.py`
**职责：0/1 背包问题求解与信用组合优化。**
- 实现 **经典 0/1 背包动态规划**，使用一维数组空间优化并支持回溯选择。
- 实现 **双约束信用组合优化**：在资本约束和风险价值约束下最大化预期收益，通过扫描惩罚参数将双约束转化为单约束背包，并用 RAROC 作为选择准则。
- 提供 **生成测试数据** 的函数。

### 9. `spherical_correlation_grid.py`
**职责：球面格点生成、Voronoi 剖分、邻接关系与区域违约相关性建模。**
- 在单位球面上用 **LLT（Latitude‑Longitude‑Triangle）** 网格生成代表地理区域中心的三维坐标。
- 基于 **Girard 公式** 计算球面三角形面积。
- 借助凸包/Delaunay 剖分估算每个点的 **球面 Voronoi 面积**，无外部依赖时使用近似方法。
- 基于剖分结果计算 **Voronoi 邻接矩阵**。
- 封装 **构建区域违约相关性模型** 的完整流程：生成网格→面积→邻接→以中心角为度量的指数衰减空间相关性矩阵，再用最近相关性矩阵修正正定性。

### 10. `structural_default_bvp.py`
**职责：结构信用模型中的病态 BVP 有限差分解与违约概率密度估计。**
- 定义并求解小参数 `ε` 的边值问题 `ε y'' - x y' + y = 0`，边界条件固定，`ε → 0` 时出现边界层。
- 使用的离散格式在局部 Peclet 数过大时自动切换为 **迎风差分**，并在两端通过 tanh 映射加密网格。
- 将 BVP 解通过变量替换映射到资产价值的稳态概率密度，并处理违约障碍以下区域。
- 提供 **Merton 模型解析违约概率**，作为数值方案的交叉验证。
