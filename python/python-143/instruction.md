# 项目概述

本项目是一个面向高频交易的策略回测与量化分析平台，整合了多尺度价格动力学模拟、离散事件市场仿真、限价订单簿引擎、做市策略优化与回测、风险分析、数据压缩、分形与混沌特征分析、特殊函数计算及高精度数值积分等多个模块。入口为 `main.py`，其他 `.py` 文件分别实现各领域能力，main 通过导入并按特定流程调用，输出统一的回测与诊断结果。

# 文件清单与职责

1. **main.py** — 系统入口
   - 串联所有模块，执行一次完整的回测与多维度分析流程。
   - 使用每个模块生成的模拟数据和指标，最终输出汇总报告。

2. **price_dynamics.py** — 多尺度价格动力学模型
   - 实现 Ornstein-Uhlenbeck (OU) 均值回复过程，支持 RK2 型 SDE 离散化以及精确转移公式（用于基准对比）。
   - 实现刚性松弛 ODE（快速均值回复），体现高阶刚性系统的数值求解。
   - 包含稳定性分析工具：计算显式 RK2 方案的绝对稳定域边界及最大稳定步长。
   - 参数扫描模块：在 (kappa, sigma) 平面计算 OU 过程的半衰期、稳态方差等统计量。

3. **market_simulator.py** — 离散事件市场仿真
   - 定义 `MarketEvent`、`OrderType`、`MarketState` 等基础数据结构。
   - 实现市场状态机，依据连续时间马尔可夫链在不同 regime（开盘、连续、波动聚集、收盘）间切换，并影响各订单类型的到达强度。
   - 订单流生成器：基于时变泊松过程生成市价单、限价单、撤单事件，支持多种成交量分布。
   - 仿真器封装：返回事件序列，并提供 VWAP 和订单不平衡度等市场统计量。

4. **order_book_engine.py** — 限价订单簿引擎与几何分析
   - 限价订单簿：管理离散价格层级上的买卖深度，支持挂单、撤单、市价单执行和最优报价查询。
   - 插值器：将离散深度曲面通过二次 Lagrange 插值升阶，用于更准确地估计冲击成本。
   - 几何分析器：计算订单簿深度剖面的凸性比率、赫芬达尔集中度、四边形面积等指标，刻画市场厚度与流动性分布。

5. **strategy_optimizer.py** — 做市策略优化与回测
   - 定义高频做市策略模型：基于中间价偏移挂单、库存管理、库存惩罚。
   - 回测引擎：在给定价格路径上模拟对手方到达，计算成交、PnL 和绩效指标（Sharpe、最大回撤等）。
   - 策略优化器：使用随机梯度下降（含 AdaGrad 自适应学习率）对策略参数进行多变量优化；提供基于 Brent 方法的一维最小化，用于优化对称价差。

6. **risk_engine.py** — 风险矩阵与凸几何
   - 协方差估计器：通过指数加权移动平均 (EWMA) 递归更新协方差矩阵。
   - 共轭梯度法求解器：用于求解最小方差组合等线性系统。
   - 最小方差组合优化：在权重和为 1 的约束下最小化组合方差。
   - 风险指标：提供历史 VaR、预期亏损 (ES)、Cornish-Fisher 修正 VaR、最大回撤和 Calmar 比率。
   - 风险几何：计算二维点集凸包面积，判断四边形凸性。

7. **chaos_analysis.py** — 分形与混沌分析
   - 分形维数：通过盒计数法估计价格路径的盒维数，反映价格序列的粗糙度。
   - Lyapunov 指数：采用 Rosenstein 算法从重构的相空间估计最大 Lyapunov 指数，用于检测混沌敏感性。
   - Hurst 指数：基于重标极差 (R/S) 分析方法，检测收益率序列的长期记忆性。
   - 综合分析器：综合上述指标给出价格路径的 regime 分类（如随机趋势、混沌趋势等）。

8. **data_compression.py** — 高频数据字典编码压缩
   - 将市场事件离散化为模式向量（价格变化档位、成交量档位、买卖方向、订单类型）。
   - 构建字典编码，将原始序列转换为模式索引序列。
   - 支持游程编码 (RLE) 进一步压缩索引序列。
   - 计算编码熵率和压缩比；提供模式之间的加权 L1 距离度量。

9. **special_functions.py** — 金融特殊函数
   - 实现余弦积分 Ci(x) 的正交分段算法（小参数幂级数、中参数 Bessel 展开、大参数渐近展开）。
   - 提供正弦积分 Si(x) 的级数计算。
   - 提供高精度正态 CDF（含 Hart 近似回退方案）。
   - 基于以上函数实现 Black-Scholes Delta 及基于 Ci 的核密度估计核函数。

10. **numerical_integration.py** — Fekete 点数值积分
    - Chebyshev 基函数：计算 Chebyshev 多项式及在给定区间上的积分矩。
    - Fekete 点计算：在候选 Chebyshev 节点中选择使权重非零的子集，构造数值积分方案。
    - 金融期望计算：用 Fekete 点法计算截断正态空间上的期望收益；利用核密度估计与 Fekete 积分计算期望亏损的积分形式。
    - 多维积分：通过全张量积方式实现二维 Fekete 点数值积分。

# 模块交互与数据流

- **价格路径生成**（`price_dynamics`）提供一条模拟 OU 价格路径，用于后续的策略回测、风险分析和混沌检测。
- **市场仿真**（`market_simulator`）生成离散事件流（`MarketEvent` 列表），该序列被注入订单簿引擎和字典编码压缩模块。
- **订单簿**（`order_book_engine`）以仿真事件填充，得到动态 LOB 状态，进行深度插值和几何指标计算。
- **策略优化**（`strategy_optimizer`）基于价格路径进行做市策略的回测与参数优化，输出优化前后绩效。
- **风险分析**（`risk_engine`）基于价格路径计算协方差、最小方差组合、VaR 等风险指标，并进行凸几何分析。
- **数据压缩**（`data_compression`）对市场事件序列建立模式字典，评估压缩比和熵。
- **混沌分析**（`chaos_analysis`）对价格路径进行分形、Lyapunov 及 Hurst 指数分析，给出市场 regime 判断。
- **特殊函数与数值积分**模块为上述计算提供基础数学支撑，如正态分布、Ci 函数、高维期望积分等。

# 核心算法与数据结构概要

- **价格模型**：OU SDE 的 Heun 型随机 RK2 格式；刚性 ODE 的显式 RK2 及精确解对比。
- **仿真**：基于泊松过程的随机事件生成，状态机管理多种市场 regime。
- **订单簿**：基于字典的价格层级管理，二次插值利用三节点 Lagrange 基；几何分析使用差积公式与鞋带公式。
- **策略回测**：模拟对手到达概率（指数或线性模型），计算浮动 PnL、库存惩罚，绩效指标采用均值/标准差/回撤计算。
- **策略优化**：有限差分估计梯度 + AdaGrad 更新；Brent 方法结合黄金分割与抛物线插值进行一维精确搜索。
- **风险**：EWMA 协方差更新；CG 法求解增广 KKT 系统；VaR/ES 通过分位数和经验尾部平均；凸包面积通过极角排序 + 鞋带公式。
- **混沌**：盒维数通过自适应 ε 的双对数回归；Lyapunov 通过嵌入延迟、最近邻追踪、对数距离线性拟合；Hurst 通过重标极差的尺度回归。
- **压缩**：量化离散化 -> 字典映射 -> R
