# 项目描述：量子退火组合优化模拟工具集

本项目是一个用于模拟量子退火组合优化过程的 Python 工具集。主程序 `main.py` 调用多个功能模块完成自旋玻璃建模、退火调度设计、噪声模拟、平均场求解、路径积分蒙特卡洛、几何嵌入以及通用数值工具等任务。

在后续 benchmark 中，**只会保留 `main.py` 文件**，其它所有 `.py` 文件将被删除。你需要根据本描述重新实现这些缺失的模块，使得 `main.py` 可以正常运行并输出与原始项目一致的结果。

## 文件清单与模块职责

### 1. `ising_hamiltonian.py` – 伊辛哈密顿量与 QUBO 构造
- **类 `IsingHamiltonian`**  
  表示一个包含 N 个自旋的伊辛系统，存储耦合矩阵 `J`（对称，零对角），纵向场 `h` 以及能量偏移量 `offset`。
- 可以从 **QUBO 矩阵**（通过变量替换 `x_i = (1 - s_i)/2`）推导出对应的 `J` 和 `h`。
- 可以将 **0/1 背包问题**（给定重量、价值、容量和惩罚因子）编码为 QUBO 矩阵，再转换为伊辛模型。
- 可生成 **随机自旋玻璃实例**（SK 型），以给定的连接概率和高斯分布生成 `J` 和 `h`。
- 提供 `energy(spin_config)` 方法计算给定自旋构型的伊辛能量。
- 对于小规模系统（N ≤ 20），实现基于 **Gray 码枚举** 的精确基态搜索，通过逐位翻转并利用增量能量更新避免全矩阵重算。
- 有 `qubo_energy` 方法计算二进制配置的 QUBO 能量。

### 2. `annealing_schedules.py` – 退火 schedule 生成
- **类 `AnnealingSchedule`**  
  输入总退火时间 `T_total` 和步数 `n_steps`，产生归一化时间 `s = t / T` 序列。  
  提供至少以下 5 种 schedule 类型，每种返回 `A(s) = 1 - B(s)` 和 `B(s)` 数组：
    - `linear`：线性 schedule，`B(s) = s`。
    - `polynomial_slowdown`：基于 **不完全 Beta 函数** 的非线性慢化，在指定 `s_star` 附近放缓。
    - `logistic_schedule`：Logistic 型平滑过渡。
    - `collatz_inspired_schedule`：受 Collatz 多项式迭代启发的分形型 schedule，通过在单调递增的基线上叠加由 Collatz 序列计算的小振幅正弦波动，并强制单调性。
    - `adiabatic_optimal_local`：基于绝热定理的局部最优 schedule，在能隙最小点附近用光滑函数（如 tanh）实现局部放缓。
- 包含工具函数 `incomplete_beta`（正则化不完全 Beta 函数的数值计算，使用连分数/级数展开，处理对称性）和 `collatz_polynomial_next`（在 GF(2) 上迭代多项式）。
- 提供 `generate_full_hamiltonian_schedule` 方法，返回包含时间、s、A、B 以及它们数值导数 `dA_dt`、`dB_dt` 的字典。

### 3. `iterative_solver.py` – 迭代法与自洽场求解
- 实现 **Jacobi 迭代** 求解线性方程组 `A x = b`，支持松弛因子 ω（JORM）。
- 实现 **Chebyshev 加速的 Jacobi 迭代**，通过估计迭代矩阵特征值范围并利用 Chebyshev 多项式加速收敛。
- 提供 **阻尼定点迭代** 求解量子伊辛模型的平均场自洽方程 `m_i = tanh(β (h_i + Σ_j J_{ij} m_j))`。
- 提供 **变分基态能量** 计算函数，在平均场近似下计算包含熵贡献的自由能。
- 提供 **幂迭代法** 近似计算矩阵最大模特征值。

### 4. `lattice_geometry.py` – 晶格几何与有限元基函数
- **类 `HexLattice`**：六边形晶格，包含实空间和倒格子基矢。  
  提供格点坐标生成（蜂窝状排列）、最近邻矢量、**边界词**（六方向编码）到坐标路径的转换、六方对称群的反射操作（多种对称轴），以及根据几何距离生成耦合图邻接矩阵。
- **类 `Q4Basis`**：四节点双线性有限元基函数。  
  提供参考单元上的形函数、形函数偏导数、牛顿迭代法将物理坐标逆映射到参考坐标、在 Q4 单元内插值标量场。
- **类 `Mesh2D`**：基于边界多边形的简易二维三角网格生成器。  
  在边界框内撒点，利用射线法剔除外部点，然后通过 Delaunay 三角化（或简化扇形三角化）生成网格。提供网格上的标量场分片常数积分。

### 5. `noise_model.py` – 量子退火噪声模型
- 提供 **截断正态分布** 的采样和统计矩计算函数（采用逆 CDF 采样，标准正态 CDF 使用 Acklam 近似）。
- **类 `QuantumAnnealingNoiseModel`**  
  - 按指定的标准差和截断区间给标称的 `h`、`J` 加上截断正态噪声。
  - 模拟横向场 `Γ` 的随机抖动。
  - 计算基于热浴温度的热激发 Metropolis 接受概率。
  - 提供一个方法 `sample_thermal_state`，在给定能量函数下对自旋构型进行 Metropolis 热化。

### 6. `transverse_field_basis.py` – 横向场基函数与隧穿核
- 计算 **物理学家厄米特多项式**、**概率学家厄米特多项式** 及其归一化形式。
- 提供 **厄米特函数基**（量子谐振子本征态在位置表象），用于隧穿计算。
- 实现一维 **隧穿振幅** 的估算。
- 构造稠密的横向场哈密顿量矩阵 `H_D = -Γ Σ_i σ_i^x`，仅限小自旋数。
- **类 `TunnelingKernel`**：用于 PIMC 中计算虚时间片之间的跃迁矩阵元（利用双曲函数），以及给定一条世界线时单自旋翻转的路径权重比。

### 7. `path_integral_monte_carlo.py` – 路径积分蒙特卡洛 (PIMC)
- 计算 **有效横向耦合** `J_perp`，基于 Trotter 分解公式。
- **类 `PathIntegralMonteCarlo`**  
  维护一个 `n_slices × n_spins` 的**世界线**（自旋构型沿虚时间轴排列），每个切片对应一个自旋副本，切片之间通过周期边界相连。  
  使用给定的能量函数和随时间变化的 `gamma_schedule`。  
  提供 **单自旋 Metropolis 更新**（同时考虑经典能量变化和世界线耦合变化）和 **虚时间方向的集群更新**（Swendsen-Wang 型，根据横向耦合建立键并整体翻转连通分量）。  
  实现热化、物理量测量（平均能量、磁化强度、磁化率、缠绕数）以及基态能量估计（多副本外推）。

### 8. `state_sampler.py` – 自旋构型采样器
- 生成 N 位 **Gray 码序列**，用于小系统的全状态枚举。
- 提供全状态能量枚举、**精确配分函数** 和热平均计算。
- **类 `MetropolisSampler`**：标准马尔可夫链蒙特卡洛，支持 burn-in 和 thinning。
- **类 `ParallelTemperingSampler`**：在多个温度上并行运行多个 Metropolis 链，并按一定频率尝试相邻温度副本之间的构型交换，以克服能量势垒
