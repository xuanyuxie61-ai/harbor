# 项目描述：多尺度煤粉燃烧 NOx 生成模拟系统

本项目构建了一个针对煤粉燃烧过程中 NOx 生成的多尺度耦合模拟框架，涵盖从单颗粒几何建模、颗粒内扩散反应、详细化学反应动力学、一维燃烧器有限元模拟、颗粒群空间分布，到参数空间优化、刚度分析和统计后处理的完整科学计算流程。代码通过 `main.py` 统一调度，各子模块负责不同物理尺度或数值方法。

## 文件清单与职责

### `main.py`
- **职责**：主入口，串联所有科学计算步骤，无命令行参数，直接运行。
- **流程**：依次执行颗粒几何建模 → 颗粒内扩散反应 → 反应动力学验证 → 1D 燃烧器 FEM 模拟 → 颗粒群 CVT 分布 → 参数空间优化 → 刚度分析 → 统计后处理，并输出关键结果。

### `particle_geometry.py`
- **职责**：非球形煤粉颗粒的几何建模与表征。
- **核心内容**：
  - 通用蛋形公式（Narushin 等），支持对称卵形和梨形，可调参数包括长度、最大宽度、偏移量。
  - 双三次 Bézier 曲面片定义，用于椭球体等光滑表面的参数化。
  - 旋转体轮廓的三角剖分以计算表面积和体积。
  - 边界词编码：将离散轮廓方向序列编码为字符串，用于形状分类。
  - `CoalParticle` 类：集成上述几何方法，提供表面积、体积、等效直径、球形度、比表面积等形状因子。

### `particle_diffusion.py`
- **职责**：颗粒内部扩散‑反应耦合模型，分析传质对反应的影响。
- **核心内容**：
  - 球贝塞尔函数及其零点计算（用于扩散特征值问题），基于牛顿法求根。
  - Thiele 模量和有效因子（球体及圆柱体），用于判断反应控制/扩散控制。
  - 多孔介质有效扩散系数（含 Knudsen 扩散修正）。
  - 拟稳态浓度场谱方法求解（利用贝塞尔函数展开，并与解析解对比）。
  - 燃料氮释放速率模型（基于 Arrhenius 反应与有效因子）。
  - 非均相焦炭氧化速率（n 阶 Arrhenius 形式）。

### `reaction_mechanism.py`
- **职责**：定义 NOx 生成的详细化学反应机理。
- **核心内容**：
  - 物种列表（16 种）及对应分子量，覆盖热力型、燃料型、快速型 NOx 路径。
  - 反应数据库（约 15 个基元反应），包含 Arrhenius 参数（指前因子、温度指数、活化能）和反应类型标注。
  - 质量作用定律计算物种摩尔生成速率（`compute_production_rates`），并支持按反应路径（热力、燃料、快速、再燃）分解 NO 生成贡献。
  - 有限差分 Jacobian 计算（`compute_jacobian_fd`），用于隐式积分和刚度分析。

### `reaction_kinetics.py`
- **职责**：刚性 ODE 系统的时间积分，针对化学反应动力学。
- **核心内容**：
  - 验证用标准 ODE（`dy/dt = -t*y`）及其精确解，用于测试积分器。
  - 向后 Euler 法单步实现（阻尼牛顿迭代求解隐式方程，含非负约束和组分归一化）。
  - 自适应步长向后 Euler 积分器，采用步长加倍误差估计控制精度。
  - 定温定压批式反应器封装（`ReactorODE`），提供右端项和 Jacobian，并输出最终 NOx 浓度及路径贡献。

### `reactor_fem1d.py`
- **职责**：一维稳态燃烧器有限元求解，模拟温度场和 NO 浓度分布。
- **核心内容**：
  - 非均匀网格生成（支持中心、入口、出口聚类）。
  - 对流‑扩散‑反应方程的 FEM 装配（P1 单元，含 SUPG 稳定化处理高 Peclet 数）。
  - 温度场求解：包含燃烧放热（高斯分布热源）和辐射热损失（简化辐射模型），采用 Robin 边界条件。
  - 物种场求解：简化热力型 NOx 源项，求解对流‑扩散方程得到 NO 质量分数分布。
  - 耦合求解流程：迭代更新温度场并计算 NO 浓度，返回峰值温度、出口 NO 浓度等。

### `thermophysical_props.py`
- **职责**：提供燃烧气体的热物理性质，基于表格插值。
- **核心内容**：
  - 采用 Newton 插值多项式（基于局部阶数控制）对 N₂、O₂、CO₂ 的比热容、混合气体导热系数、动力粘度、NO 扩散系数进行高精度求值。
  - 表格数据覆盖 300–5000 K，外推采用线性保护。
  - 混合物性质计算（质量分数加权）、Prandtl 数、Lewis 数、Schmidt 数等。

### `particle_population.py`
- **职责**：煤粉颗粒群的空间分布与聚集行为模拟。
- **核心内容**：
  - 多种密度函数定义（均匀、Chebyshev、燃烧器模拟分布）。
  - 3D Lloyd 质心 Voronoi 镶嵌（CVT）算法，通过密度加权采样实现生成器位置优化，输出能量和位移收敛曲线。
  - 簇统计量计算（平均间距、最小间距、径向分布）。
  - 湍流聚集核模型及 Smoluchowski 聚集方程的离散模拟（显式欧拉法），用于预测颗粒数浓度演化。

### `parameter_search.py`
- **职责**：燃烧运行参数空间的高效搜索与优化。
- **核心内容**：
  - 希尔伯特空间填充曲线（2D 及推广到 N 维），用于低差异采样。
  - Park‑Miller 线性同余发生器（LCG）伪随机数生成。
  - NOx 排放与燃尽度目标函数，综合热力 NOx、燃料 NOx 和燃尽惩罚项。
  - 优化函数 `optimize_combustion_parameters` 支持希尔伯特采样或随机采样，返回最优参数及成本统计。
