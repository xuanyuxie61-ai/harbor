## 项目描述

# 项目描述：智能电网潮流优化与暂态稳定性分析综合平台

本项目为一个模块化的智能电网仿真工具包，覆盖电网拓扑建模、交流潮流计算、暂态稳定仿真、经济调度与机组组合、负荷预测、状态估计及可靠性评估等环节。所有模块均通过 `main.py` 统一驱动，零参数运行时自动执行完整分析流程。

## 涉及文件与模块职责

**`main.py`**  
统一入口脚本。依次调用各功能模块执行7个步骤：环形‑径向配电网拓扑生成与 Delaunay 三角剖分质量评估、牛顿‑拉夫逊潮流计算、单机及多机暂态稳定性时域仿真、经济调度与动态规划机组组合、马尔可夫负荷预测与熵率分析、加权最小二乘状态估计与可观测性分析、线路可靠性与电压稳定裕度检测。同时包含简单的数值工具验证。

**`grid_topology.py`**  
电网拓扑几何建模。核心类 `GridTopology` 负责管理节点集和三角剖分：通过增量式 Delaunay 算法构建三角网格（保证最小角最大化）；基于三角网格生成节点邻接表并提取无向边列表；提供网格质量指标（最小角、面积比、面积方差）。静态工厂方法 `generate_ring_radial_topology` 利用 `utils.circle_arc_grid` 生成内、外环节点及径向射线，并叠加随机扰动以构造混合配电网拓扑。

**`power_flow.py`**  
牛顿‑拉夫逊潮流求解。`PowerFlowSolver` 类接收导纳矩阵、节点类型、电压初值和指定功率注入，通过极坐标形式节点功率方程计算功率失配，构造雅可比矩阵（稠密形式），采用带阻尼线搜索的牛顿迭代求解电压幅值与相角。模块还包含 `build_y_bus` 函数，根据线路电阻、电抗及对地导纳构建复数节点导纳矩阵。

**`transient_stability.py`**  
暂态稳定性仿真。`SwingEquation` 类实现单机无穷大系统的摇摆方程（二阶微分方程），定义电功率、状态导数函数，提供基于四阶 Runge‑Kutta 积分（调用 `utils.rk4_step`）的时域仿真，并依据等面积法则数值求解临界切除角。`MultiMachineStability` 类扩展至多机系统，使用降阶导纳矩阵描述发电机间电磁耦合，整体状态向量包含各机转角与角速度，同样使用 RK4 进行仿真。

**`optimal_dispatch.py`**  
经济调度与机组组合。`EconomicDispatch` 类基于二次成本函数的等微增率准则，通过二分搜索确定系统统一边际电价 λ 及各机组最优出力。`UnitCommitmentDP` 类先用单机组多时段动态规划处理启停约束及启停成本，再通过多机组聚合动态规划，利用多项式卷积（调用 `utils.polynomial_multiply`）枚举可行出力组合，以生成函数方式快速判断负荷需求可行性。

**`load_markov.py`**  
马尔可夫负荷预测。`LoadMarkovModel` 将连续负荷等频分箱为有限状态空间，从历史序列用最大似然估计转移概率矩阵（含拉普拉斯平滑）；提供 n 步预测分布、蒙特卡洛轨迹生成、熵率及 n 步自相关衰减分析等方法，用以量化负荷随机性和系统记忆特性。模块附有构造示例负荷曲线的工具函数。

**`state_estimation.py`**  
加权最小二乘（WLS）状态估计与可观测性分析。`WeightedLeastSquaresSE` 支持电压幅值、节点注入功率及支路功率量测类型，通过高斯‑牛顿迭代求取状态向量（电压幅值、相角），计算量测雅可比时采用有限差分近似。`ObservabilityAnalysis` 将量测矩阵缩放为整数矩阵，利用 `utils.i4mat_rref` 进行行简化，基于秩判断系统是否完全可观测。

**`reliability.py`**  
可靠性分析与电压稳定性。`LineReliability` 类根据线路长度和故障率计算各线路可用率，进而评估串联/并联路径可靠性和期望缺供电量。`VoltageStabilityMargin` 实现单负荷无穷大系统的 PV 曲线（鼻点、功率极限与电压裕度）。`ThreePhaseUnbalance` 利用对称分量法计算三相电压负序不平衡度，并借助三角形几何分析（调用 `utils.triangle_area_2d`、`utils.triangle_angles`）提供相量三角的面积与角度信息。

**`sparse_matrix.py`**  
稀疏矩阵工具。`SparseMatrix` 采用 COO 格式存储非零元，支持矩阵‑向量乘法、转置乘法、对角线提取和残差计算。模块提供 `conjugate_gradient` 函数求解对称正定线性方程，以及 `jacobi_sparse_solve` 用于对角占优系统的简单迭代。它们可用于大规模雅可比或导纳系统的快速求解（在 main 中主要作为基础设施引入，但未实际替代稠密解法）。

**`utils.py`**  
通用数值工具集。包括：圆弧均匀网格生成（`circle_arc_grid`）、多项式卷积乘法（`polynomial_multiply`）、二阶中心差分（`diff2_center`）、三角形面积与角度计算（`triangle_area_2d`, `triangle_angles`）、整数矩阵行简化（`i4mat_rref`）、经典四阶 Runge‑Kutta 单步积分（`rk4_step`）以及一个外部堆排序辅助函数。

## 模块间依赖关系

- `main.py` 导入并使用所有业务模块。
- `grid_topology.py` 使用 `utils.circle_arc_grid`、`utils.triangle_area_2d`、`utils.triangle_angles`。
- `power_flow.py` 在内部提及可能使用 `sparse_matrix` 进行稀疏求解（尽管当前实现为稠密雅可比），并导入 `utils.diff2_center` 作为数值验证。
- `transient_stability.py` 使用 `utils.rk4_step` 进行积分。
- `optimal_dispatch.py` 使用 `utils.polynomial_multiply` 实现机组聚合卷积。
- `state_estimation.py` 导入 `utils.i4mat_rref` 进行秩分析，并导入 `sparse_matrix` 以备稀疏实现。
- `reliability.py` 使用 `utils.triangle_area_2d`、`utils.triangle_angles`。
- `load_markov.py` 仅依赖 `numpy`。
- `utils.py` 为纯工具模块，不依赖其他业务文件。

## 关键算法与数据结构概览

- **Delaunay 三角剖分**：基于增量插入和空外接圆准则，添加超级三角形后逐步插入点，维护三角列表并移除含超级顶点的单元。
- **导纳矩阵构建**：根据线路阻抗计算串联导纳并累加到节点自导纳和互导纳，同时计入并联电纳。
- **牛顿‑拉夫逊潮流**：极坐标形式失配方程，手工组装雅可比矩阵子块，用阻尼线搜索改善全局收敛性。
- **摇摆方程积分**：RK4 求解二阶常微分方程；等面积法则通过数值求解方程求临界切除角。
- **经济调度 λ 迭代**：在可选 λ 范围内二分搜索，每次按微增率曲线求各机组出力并裁减到限值，直至总出力与负荷平衡。
- **机组组合动态规划**：单机组 DP 中状态包含启停状态及其持续时段，通过最小启停时间约束进行状态转移；多机组聚合时使用多项式卷积将机组离散出力分布卷积得到系统总出力分布。
- **马尔可夫负荷建模**：等频分箱离散化后统计转移计数并做拉普拉斯平滑，快速幂阵乘法实现多步预测，特征值分解求稳态分布，熵率衡量随机性。
