# 项目描述：机器人 SLAM 与稠密建图系统

## 项目目标
实现一套基于图优化的移动机器人同步定位与三角网格稠密建图系统，融合多种科学计算模块：有限元不确定性场分析、基于 CVT 的关键帧采样与最优停止策略、SOR 稀疏线性求解、随机游走环路闭合检测、置换正交性检验以及特征值可观测性分析。

系统输入为控制指令序列（线速度 v、角速度 w），在合成障碍物环境中仿真差分驱动机器人的运动、扫描与建图过程。系统应输出优化后的位姿轨迹、三角网格地图、不确定性场、网格质量指标及轨迹绝对误差（ATE）等评估结果。

## 涉及的文件及其职责

### 1. `robot_motion_model.py`
**机器人运动学与误差传播模块**

定义 `DifferentialDriveRobot` 类，维护机器人的 SE(2) 位姿（x, y, θ）和 3×3 协方差矩阵。核心功能包括：

- **精确圆弧运动模型**：根据控制输入 (v, w) 预测下一时刻位姿，处理直线 (w≈0) 与转弯 (w≠0) 两种情况。
- **误差传播**：通过一阶泰勒展开计算状态雅可比 F 与控制雅可比 G，并按 Σ ← F Σ Fᵀ + G Q Gᵀ 传播协方差（Q 为控制噪声对角阵）。
- **相对变换**：计算两个 SE(2) 位姿之间的相对变换（通过齐次矩阵求逆与乘法）。

模块对外提供 `propagate(v, w)` 方法，带噪声执行一步传播并返回新位姿与协方差。

### 2. `lidar_observation_model.py`
**激光雷达观测模型与点云配准**

包含两个主要类：
- **`Lidar2D`**：二维激光雷达模拟器。给定机器人位姿与障碍物列表（圆形和线段），沿离散角度发射射线，通过射线-圆/射线-线段求交计算测距值，并叠加高斯噪声。提供世界坐标系与局部坐标系之间的点云坐标变换。
- **`PointCloudRegistration`**：基于 SVD 的 2D ICP 配准。迭代执行最近邻对应搜索与闭式刚体变换求解（去中心化 → 协方差矩阵 → SVD → R = V Uᵀ），并处理反射修正，返回旋转矩阵、平移向量与配准误差。

### 3. `triangular_mesh_map.py`
**三角网格地图构建与质量评估**

定义 `TriangularMeshMap` 类，核心流程：

- **从点云构建网格**：对二维点云执行 Delaunay 三角剖分（优先使用 scipy，否则回退到 Bowyer-Watson 算法）；移除退化的狭长或过小三角形。
- **边界边检测**：统计每条边出现的次数，仅出现一次的边构成网格边界，并通过链式连接排序形成闭合边界环。
- **法向量估计**：将 2D 三角面片升维至 3D（z=0），通过叉积计算面法向。
- **自适应细分**：对面积超过阈值的三角形在三条边中点插入新顶点，分裂为 4 个子三角形。
- **网格质量评估**：计算最小内角与最大长宽比（外接圆半径与内切圆半径之比）。

### 4. `sparse_matrix_ops.py`
**广义对角稀疏矩阵与 SOR 迭代求解**

- **`R8GDMatrix`**：采用广义对角存储格式，用偏移量数组和 (n, ndiag) 值矩阵表示稀疏矩阵。提供矩阵-向量乘法 `mv`（y[i] = Σ A[i,d] * x[i+offset[d]]）和转置乘法 `mtv`。
- **`SORSolver`**：逐次超松弛迭代求解器。对于稠密矩阵使用分量形式的 SOR 迭代；对于 R8GD 稀疏矩阵利用其存储结构直接遍历非零对角线。松弛参数 ω ∈ (0,2)。

### 5. `graph_slam_optimizer.py`
**图优化 SLAM 与可观测性分析**

- **`PoseGraph`**：位姿图数据结构，维护顶点列表（SE(2) 位姿）和边列表（含测量值 z 与 3×3 信息矩阵 Ω）。
- **`GraphSLAMOptimizer`**：Levenberg-Marquardt 位姿图优化器。计算 SE(2) 相对位姿误差（通过 T_pred * T_z⁻¹ 得到误差向量 e）及雅可比 Jᵢ, Jⱼ，组建线性系统 H Δx = -b；固定第一个位姿消除规范自由度；LM 阻尼调整与代价下降检验。
- **`ObservabilityAnalyzer`**：对 Hessian 矩阵进行特征值分解，计算条件数、零空间维数、可观测性指标，并支持生成随机 Schur 矩阵用于测试。

### 6. `cvt_keyframe_sampler.py`
**基于 CVT 的关键帧采样与最优停止策略**

- **`CVTKeyframeSampler`**：在特征空间（如 [x, y, α·θ]）中对点集进行 Centroidal Voronoi Tessellation 采样。采用 K-means++ 初始化生成元，Lloyd 迭代交替执行 Voronoi 划分与质心更新（密度加权），并计算 CVT 能量泛函以监控收敛。
- **`OptimalStoppingKeyframeSelector`**：将关键帧选择建模为秘书问题变体。计算最优跳过比例 r/T ≈ 1/e，跳过前 r 帧后选择第一个超过参考最大值的帧。提供蒙特卡洛模拟以验证理论成功率 1/e。
- **`InformationGainEstimator`**：基于 Fisher 信息的观测信息增益估计，对给定姿态与地标集合计算观测雅可比并构建信息矩阵，以行列式与迹组合作为增益指标。

### 7. `fem_uncertainty_field.py`
**有限元不确定性场与环形协方差估计**

- **`FEMUncertaintyField`**：在矩形区域上求解定位不确定性 PDE：`-∇·(a∇u) + c u = f`，采用双线性四边形单元与 3×3 高斯求积进行 Galerkin 有限元离散，施加 Dirichlet 边界条件 u=0，求解线性系统。支持在任意点通过双线性插值采样场值。
- **`AnnularCovarianceEstimator`**：在环形区域上对被积函数进行数值积分，使用径向 Legendre-Gauss 节点与角度等距采样，经坐标变换与雅可比计算环内协方差的加权积分。

### 8. `loop_closure_detector.py`
**环路闭合检测：随机游走、随机搜索与置换正交性**

- **`RandomWalkLoopDetector`**：基于随机游走模型的环路似然估计。计算位姿位置间的实际距离与随机游走期望距离的比值作为相似度得分，超过阈值则视为候选环路闭合对。
- **`RandomSearchAssociator`**：随机采样部分候选扫描进行匹配，接受分数最高的匹配（若超过阈值），并提供理论搜索成功概率（组合公式）与蒙特卡洛验证。
- **`PermutationOrthogonalityChecker`**：通过 SVD 求解两组点云对应关系的最优刚体变换，检验旋转矩阵是否正交（det=+1）及重投影误差，并演示置换正交性性质。
- **`IntegratedLoopClosureDetector`**：整合上述三种策略，对轨迹和扫描序列进行多阶段环路闭合检测与验证，返回通过的闭合对及其估计的 SE(2) 变换。

### 9. `utils.py`
**通用工具函数**

包含 SE(2) 指数/对数映射、角度归一化、半正定性检验与最近半正定矩阵投影、马氏距离、卡方置信区间近似、ATE 计算、Huber 鲁棒损失函数等辅助功能。
