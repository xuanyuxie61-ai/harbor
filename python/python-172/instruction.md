## 各模块详细描述

### 1. Chebyshev 谱方法核心 (`chebyshev_spectral.py`)
提供一维 Chebyshev 谱方法的基础设施。
- 生成 Chebyshev‑Gauss‑Lobatto（CGL）节点。
- 构造 Chebyshev Vandermonde 矩阵，用于从节点值计算多项式展开。
- 建立谱微分矩阵（一阶导数），具有解析对角与非对角项。
- 用 Clenshaw 递推算法高效计算 Chebyshev 级数的值。
- 离散 Chebyshev 变换（分析）：从 CGL 节点值计算级数系数。
- 合成：从系数恢复 CGL 节点上的函数值。
- 辅助函数：在解向量上施加 Dirichlet 边界条件，以及基于系数的插值。

### 2. 系数空间谱运算 (`spectral_differentiation.py`)
在 Chebyshev 系数空间完成高级操作，模拟连续函数的微积分。
- 系数微分：利用 TOMS 算法给出的三项递推关系。
- 系数积分：递推计算不定积分（满足在 x = –1 处零值条件）。
- 系数乘法：利用 T_j·T_k 的恒等式进行两个级数的乘积。
- 系数级数的反函数：通过 Newton 迭代在给定 y 值下解出 x。
- 加权 L2 范数：根据 Chebyshev 系数直接计算函数的 L2 范数（带权 1/√(1–x²)）。

### 3. 三对角线性求解器 (`tridiagonal_solvers.py`)
基于 R83T 紧凑存储格式，提供多种求解器，用于求解谱离散化中产生的线性系统（或近似系统）。
- R83T 格式：使用 (N×3) 数组存储下对角线、主对角线、上对角线。
- 矩阵‑向量乘积。
- 直接法：Thomas 算法，适用于严格三对角系统，O(N) 时间。
- 迭代法：Jacobi、Gauss‑Seidel、共轭梯度（CG），均提供收敛历史。
- 工厂函数 `r83t_dif2` 构造一维离散 Laplacian（中心差分）的三对角矩阵。
- 辅助函数：从稠密谱二阶微分矩阵中提取三对角近似，以备迭代求解器使用。

### 4. θ 方法时间积分 (`theta_time_stepping.py`)
实现单参数 θ 方法时间推进，用于常微分方程（组）的半离散系统。
- 残差计算：根据 θ 方法格式写出步进残差。
- 单步推进：用牛顿迭代求解隐式步进（θ≠1），支持用户提供 Jacobian 近似；若不提供则采用对角近似。
- 全时域积分：从初始值出发，输出所有时间层上的解，并可选记录能量历史。
- 离散能量范数：基于解向量和二阶谱矩阵 `D2` 计算动能 + 势能近似，用于监测能量守恒。

### 5. 广义多项式混沌展开 (`polynomial_chaos.py`)
用于随机输入的不确定性量化，以 Legendre 多项式为基函数（对应均匀随机变量）。
- 多指标（grlex 序）枚举：生成 d 维中总度数 ≤ p 的所有组合。
- 一维归一化 Legendre 多项式求值（使用标准正交归一化）。
- gPC 基函数评估：在随机样本点 ξ 上计算所有基函数的值（张量积形式）。
- 系数计算：通过最小二乘回归从采样解得到 gPC 系数。
- 统计量提取：从系数直接计算均值和方差。
- 一阶 Sobol 灵敏度指数：基于系数分解计算。

### 6. 随机场生成 (`random_field.py`)
为反应‑扩散方程生成随机扩散系数场 ν(x, ξ)。
- Box‑Muller 正态变量生成。
- 基于 Cholesky 因子的 Wishart 分布采样（采用 AS 53 近似算法），用于构造或扰动协方差矩阵。
- 随机场生成：利用指数协方差核，通过离散特征分解构造 Karhunen‑Loève (KL) 展开，并结合 Wishart 校正来确保正定性；返回平均场、KL 模态和特征值。
- 根据具体 ξ 样本评估随机场：ν(x) = ν̄(x) + σ ∑ √λ_k φ_k(x) ξ_k，并裁剪为正。
- Monte Carlo 统计估计：对一组样本计算均值、方差、标准差和 95% 置信区间。

### 7. 自适应节点与超收敛点 (`adaptive_nodes.py`)
生成适用于谱方法的自适应 CGL 型节点，并提取超收敛点。
- 密度函数：提供指数形式的自适应密度。
- CVT Lloyd 迭代：在给定密度函数下，通过蒙特卡洛采样和质点重分配生成一维质心 Voronoi 镶嵌节点。
- 映射函数：将 CVT 节点逆 CDF 映射到标准 CGL 网格，并输出映射导数，用于谱算子链式法则。
- 三点二次插值：拟合抛物线并返回顶点，用于估计超收敛点。
- 超收敛点扫描：遍历 Gr id 上相邻三点，提取极值点位置和值。

### 8. Hamilton 结构分析 (`hamiltonian_analysis.py`)
分析 PDE 离散系统的 Hamilton 结构及能量保持性质。
- Chirikov 标准映射：一步迭代、Hamilton 量计算、轨道生成。
- PDE 半离散 Hamilton 量：动能+势能（利用谱二阶矩阵）+非线性势能。
- 速度 Verlet 步进：用于分子动力学风格的时间积分，输入位置、速度和力函数。
- 系综能量漂移统计：对一组初始条件做 Verlet 积分，计算相对能量变化。

### 9. 谱‑有限元桥接 (`fem_spectral_bridge.py`)
将谱解投影到 P1 有限元网格上进行交叉验证与误差估计。
- 两点 Gauss‑Legendre 求积节点与权重。
- P1 质量矩阵组装：单元循环，利用高斯积分。
- RHS 投影
