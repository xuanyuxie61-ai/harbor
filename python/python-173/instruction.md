# 项目描述：自适应网格细化（AMR）求解二维对流‑扩散‑反应方程

## 1. 项目概述
本项目实现一个用于求解二维非定常对流‑扩散‑反应方程的自适应网格细化（AMR）求解器。物理区域为矩形域，网格由三角形单元构成，采用有限元法进行空间离散，时间离散采用隐式或半隐式格式。自适应循环通过后验误差估计驱动网格局部细化，并结合图论重排序与解传递技术，在保持精度的同时控制计算成本。

## 2. 源文件列表与职责
项目根目录包含一个入口文件 `main.py` 以及多个功能模块文件。后续复现工作中仅保留 `main.py`，其他模块均需根据本描述重新实现。

### 2.1 `main.py`
程序入口。负责任务配置、主循环（AMR 迭代）、调用各模块并输出结果。不包含任何核心算法实现，仅做流程编排与参数设置。

### 2.2 `advection_diffusion.py`
负责二维对流‑扩散‑反应方程的单步时间推进。  
- 识别域边界边及 Dirichlet/Neumann 边界节点。  
- 组装对流项的有限元刚度矩阵（速度场 v 的 Galerkin 离散）。  
- 计算非线性反应项的载荷向量（通过三角形积分与当前解的插值）。  
- 计算集中质量矩阵（lumped mass matrix）的对角元。  
- 根据网格尺寸和物理参数估算 CFL 稳定性条件，给出最大时间步长和局部 Peclet 数。  
- 实现一个时间步的隐式/半隐式求解，将扩散、对流、反应、源项和 Dirichlet 边界条件组合成线性系统并求解。

### 2.3 `cvt_mesh.py`
基于 Centroidal Voronoi Tessellation（CVT）的二维节点分布优化与三角剖分。  
- 计算采样点相对于生成元（Voronoi 种子）的最近归属。  
- 执行一次 Lloyd 迭代，根据密度加权更新生成元位置，并计算离散 CVT 能量。  
- 可选地评估全量离散 CVT 能量。  
- 生成均匀或密度驱动的 CVT 优化节点分布（随机初始种子 + 迭代 + 边界裁剪）。  
- 将二维点集 Delaunay 三角剖分为三角形网格（包含去重和简单法兜底）。  
- 计算三角形面积。

### 2.4 `error_indicator.py`
后验误差估计模块，提供两种误差指示子。  
- 生成 Chebyshev 求积/插值节点。  
- 计算 Newton 差商表，并利用 Newton 形式进行多项式插值。  
- 在一维区间上构造 Chebyshev 插值并估计最大误差。  
- 对单个三角形单元，基于边上的 Chebyshev 插值和高阶逼近与线性解的比较，结合梯度变化产生误差指示子。  
- 对所有单元批量计算误差指示子，并合成全局误差估计。  
- Zienkiewicz‑Zhu（ZZ）梯度恢复误差估计：先计算单元梯度，再通过面积加权平均恢复节点梯度，比较恢复梯度与原始梯度的差异。

### 2.5 `fem_solver.py`
二维三角形有限元求解器内核。  
- 提供参考三角形上的 P1 形函数及其参考梯度。  
- 在单个物理三角形上计算局部刚度矩阵（扩散项 + 反应项），支持任意扩散系数和反应系数函数，使用数值积分。  
- 组装全局刚度矩阵和载荷向量，处理 Dirichlet 边界（直接消去法）和 Neumann 边界（边中点积分）。  
- 求解稳态椭圆型 PDE，返回节点解、刚度矩阵和载荷向量。

### 2.6 `graph_mesh.py`
网格的图论分析工具。  
- 从三角形网格构建节点的邻接表及 CSR 格式的邻接矩阵。  
- 计算邻接矩阵的带宽。  
- 实现 Reverse Cuthill‑McKee（RCM）重排序算法（选最小度节点，BFS 按度排序，逆序输出）以降低带宽。  
- 将 RCM 应用于网格，重新排列节点和三角形索引，并报告带宽变化。  
- BFS 计算节点间最短距离。  
- 判断网格节点图的连通性。  
- HITS 算法计算节点的 authority 和 hub 分数。  
- 构建单元间的邻接关系（通过共享边）。

### 2.7 `hex_boundary.py`
六边形离散化与边界近似工具。  
- 六边形轴向坐标与笛卡尔坐标相互转换。  
- 浮点轴向坐标舍入到最近的六边形格点。  
- 生成指定半径的六边形格点集。  
- 将边界词（六边形移动方向序列）转换为多边形顶点。  
- 用六边形格点近似参数化连续边界曲线。  
- 根据六边形边界点上的解值计算边界细化指示子。

### 2.8 `quadrature_rules.py`
三角形参考域上的高阶数值积分规则。  
- 实现 `TriangleQuadrature` 类，封装 1‑5 阶的积分点与权重，可对参考三角进行积分。  
- 提供在物理三角形上通过仿射映射进行积分的实用函数。  
- 提供一维 Gauss‑Legendre 求积节点与权重（1‑5 点），用于边积分等。

### 2.9 `shepard_transfer.py`
基于 Shepard 插值的解在不同网格间的传递。  
- 实现 N 维 Shepard 插值（逆距离加权，幂指数可调，精确匹配处理）。  
- 从粗网格到细网格的 prolongation（延拓）。  
- 从细网格到粗网格的 restriction（限制，使用高斯权重平均的简化策略）。  
- 统一接口：给定旧网格节点、三角形和解，以及新网格节点和三角形，将解传递到新网格上。

### 2.10 `time_integrator.py`
时间积分与刚性分析工具。  
- 实现向后 Euler、BDF2 和 Crank‑Nicolson 三种单步格式（均采用简化的不动点迭代处理非线性）。  
- 自适应时间步进控制器：以局部误差估计（比较一阶/二阶近似）自动调整步长，支持容差、最大最小步长等参数。  
- 分析离散系统刚度比：计算广义特征值问题，给出刚度比和谱半径。

### 2.11 `triangulation_refine.py`
三角形网格细化与粗化操作。  
- 对三角网进行一致或自适应细化（边中点插入，将一分为四的划分），并维护父子单元映射和节点细化层级。  
- 基于误差指示器按阈值标记需细化的单元并执行细化（Dörfler 标记策略）。  
- 提供简单的网格粗化功能（移除标记单元及其独享节点）。  
- 计算三角形网格的质量指标（基于边长与面积的等边比例）。

## 3. 核心数据结构
- **节点坐标**：`(n_nodes, 2)` 的浮点数组，每一行列出一个二维点。  
- **三角形单元**：`(n_tri, 3)` 的整数数组，每一行存储三个顶点索引（逆时针）。  
- **物理场函数**：扩散系数 `D(x,y)`，反应系数 `c(x,y)`，速度场 `v(x,y) -> (v_x,v_y)`，源项 `f(x,y,t)`，反应项 `R(u, x,y)`，初值 `u0(x,y)`，边界值 `g(x,y,t)` 等，均为可调用对象。  
- **边界条件**：Dirichlet 节点索引和对应值数组，Neumann 边界边列表和对应通量函数。  
- **解向量**：`(n_nodes,)` 浮点数组，存储每个节点上的近似解。  
- **质量矩阵**：对角集中质量矩阵存储为一维数组。  
- **错误指示器**：`(n_tri,)` 数组，每个单元一个标量误差估计。  
- **网格图**：邻接表、CSR 格式行指针和列索引数组
