## 模块功能与边界

### 1. `spherical_geometry.py` – 球面几何与球谐基
**职责**：提供球坐标与笛卡尔坐标互转、球面上几何量（大圆距离、球冠面积、四边形面积）计算、归一化连带 Legendre 函数及球谐基求值、单位球面/球面上均匀采样、三维点集的最小包围球计算，以及平面圆周点生成。

**关键接口**：
- 坐标转换函数。
- 归一化连带 Legendre 函数通过递推公式计算到指定阶数，返回归一化后的值数组。
- 球谐基函数（给出实部和虚部）。
- 均匀球面采样（利用正态分布归一化）。
- 最小包围球（质心+最大距离）。
- 四边形面积的三角形分解公式。

**算法要点**：连带 Legendre 用经典递推，归一化因子涉及组合数和阶乘，实现时需注意平方根、递推初值及符号问题。球谐基使用该归一化函数乘上 cos/sin 因子。

### 2. `nbody_kernel.py` – 直接 N 体核函数与辅助工具
**职责**：实现 O(N²) 的直接库仑势能和力计算，提供单项式求值、分段常数核近似、转移矩阵构建以及核函数梯度/拉普拉斯计算。

**关键接口**：
- `coulomb_potential_direct`：给定位置与电荷，计算所有粒子的势能（带有软化参数避免自作用奇点）。
- `coulomb_force_direct`：类似地计算受力。
- `monomial_value`：多点求单项式值。
- `pwc_kernel_approx` 与 `evaluate_pwc_kernel`：在距离区间内分段用常数近似 1/r 核函数。
- `build_transition_matrix_from_neighbors`：由邻居计数构建行归一化的转移矩阵（用于马尔可夫链分析）。
- `kernel_gradient_laplacian`：某一目标点的核函数值、梯度与拉普拉斯量。

**算法要点**：直接求和需对每个目标点遍历所有源点，排除自身；分段常数近似采用等距分段和中点值。

### 3. `fmm_tree.py` – 八叉树空间划分
**职责**：构造并管理 FMM 所需的层次空间树。节点存储粒子索引、中心、半径（外接球）、深度等信息，支持粒子插入、节点分裂、邻居与交互列表查询，以及自底向上的多极矩聚合（调用翻译算子）。

**核心数据结构**：
- `OctreeNode`：表示一个立方体区域，记录中心、半边长、深度、最大容量、子节点列表、粒子索引、多极矩系数表和局部展开系数表（均为按 (l,m) 索引的实虚部数组）。提供 `is_leaf`, `insert`, `_split` 等方法。
- `FMMOctree`：管理整棵树，根据所有粒子构建根节点并逐粒子插入，分裂过程中重新分配粒子；提供 `get_all_nodes`, `get_leaves`, `compute_moments_upward` 等方法。

**关键算法**：
- 插入粒子时，若叶子节点粒子数超过阈值且未达最大深度，则沿中心三分裂成 8 个子节点，并重分配粒子。
- 节点的分裂利用粒子坐标判断所属子节点（用二进制编码）。
- 提供基于边界距离判断相邻节点的方法。
- 交互列表通过父节点的邻居中不与当前节点相邻的子节点或叶子来构造（充分分离条件）。
- 向上计算多极矩：叶子节点直接调用 `MultipoleExpansion` 添加粒子，然后通过 M2M 转换逐层合并到父节点（递归实现）。

### 4. `multipole_expansion.py` – 多极展开类
**职责**：管理一个区域（节点）内的所有粒子的多极矩，支持累加粒子的贡献，以及在远场评估势能和电场。

**核心类**：`MultipoleExpansion`
- 构造函数：指定展开中心和最大阶数，初始化实数/虚数多极矩系数表（按 l,m 索引）。
- `add_particles`：对每个粒子计算 r^l 和球谐基函数，乘电荷后累加到相应系数。
- `evaluate_potential`：对于给定目标点，计算 1/R^{l+1} 与球谐基的线性组合得到势能（使用多极矩系数）。
- `evaluate_field`：通过数值差分近似计算电场（负梯度）。
- 提供截断误差上界估计（基于源半径和距离）。

**算法要点**：球谐函数调用 `spherical_geometry` 中的归一化连带 Legendre，注意 m=0 时虚部为零。多极矩系数为实数形式 Y^{m,c} 和 Y^{m,s}。

### 5. `local_expansion.py` – 局部展开类
**职责**：管理局部展开系数，支持直接累加远场源对局部区域的贡献，以及在局部区域内评估势能。还提供 Hermite‑Gauss 积分和楔形体上的单项式积分等数学工具。

**核心类**：`LocalExpansion`
- 结构与 `MultipoleExpansion` 类似，以展开中心为原点。
- `add_source_contribution`：根据源点位置与电荷直接添加局部展开系数（计算 1/r^{l+1} 与球谐基的乘积）。

**算法要点**：球谐基计算与多极展开类似，但幂次不同。楔形体积分通过非负整数指数下的公式递推得到结果。
