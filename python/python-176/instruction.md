## 项目概述

本项目解决一个二维椭圆域上的非定常反应-扩散方程约束的最优 Neumann 边界控制问题。控制目标是寻找边界热流输入 \(q(s,t)\)，使得域内的状态 \(y(x,t)\) 跟踪一个期望状态 \(y_d(x,t)\)，同时最小化控制能量和光滑性惩罚。数学上，这是一个 PDE 约束的最优控制问题，采用伴随方程方法计算目标泛函的梯度，并使用梯度下降与 Armijo 线搜索进行优化。

状态方程为前向反应-扩散方程（非线性项 \(c y^3\)），伴随方程为后向线性化方程。空间离散使用三角形线性有限元（FEM），时间离散采用隐式欧拉方法。整个项目将几何建模、网格生成、有限元组装、PDE 求解、伴随梯度计算、优化迭代、以及多种验证算法（椭圆积分、QMC、光谱时间离散、特殊函数、稀疏线性代数等）集成在一个统一框架中。

## 文件结构与职责

项目包含若干 Python 模块和一个主入口脚本 `main.py`。各个文件的主要职责如下：

- **main.py**：顶层入口。负责设置问题参数、调用网格生成、组装 FEM 矩阵、定义源项和期望状态、执行最优化求解、运行各类验证计算、输出结果文件，并打印性能统计。
- **ellipsoid_geometry.py**：三维椭球几何计算与二维椭圆截面网格生成。提供 Carlson 椭圆积分、椭球表面积/体积、二维椭圆域三角形网格生成（Delaunay 三角化）、网格 I/O（简化的 TECPLOT 格式读写）以及几何辅助功能（识别边界边、计算单元面积）。
- **fem_core.py**：二维 P1 有限元离散的核心。组装质量矩阵 M、刚度矩阵 A 和边界控制矩阵 B；提供源项载荷向量组装、L2 投影、FEM 解的插值求值，以及 L2 和 H1 范数计算。
- **adjoint_control.py**：最优控制伴随方程方法的核心模块。实现状态方程的前向隐式欧拉推进、伴随方程的后向隐式欧拉推进、目标泛函评估、离散梯度计算、边界一维 Laplace 矩阵的构建、Armijo 线搜索，以及主优化循环（梯度下降 + 线搜索）。
- **ode_integration.py**：常微分方程时间积分器与敏感性分析工具。包含显式欧拉、隐式欧拉、Crank‑Nicolson 方法；复合梯形法则数值积分；敏感依赖 ODE（\(y''=y\)）的右端函数与解析解；以及伴随相容性验证指标。
- **quadrature_advanced.py**：一维与多维数值求积规则。实现一维复合梯形、Romberg 外推；参考三角形上的对称求积规则（Dunavant 型）；单位六面体高阶求积规则（Jaskowiec‑Sukumar）；多维 Monte Carlo 和 P5 张量积规则。
- **qmc_verification.py**：准蒙特卡洛验证。基于 Hammersley 低差异序列，提供椭圆域内均匀采样、椭圆域积分估计、任意超矩形上的 QMC 积分，以及 QMC 与 FEM 积分结果的对比验证。
- **spectral_time.py**：时间方向谱离散工具。计算 Legendre 多项式及其导数、Lobatto 多项式及其导数；生成 Gauss-Lobatto-Legendre 节点与权重；构造 Lagrange 导数矩阵和 GLL 时间质量、刚度矩阵。
- **nonlinear_solvers.py**：非线性方程求解与特殊函数。包含 Lambert W 函数（主分支与次分支）的分段近似及 Halley 精化；Newton 法求解标量方程；辅助求解隐式非线性反应项的函数。
- **sparse_linear_algebra.py**：面向大规模稀疏矩阵的 CRS（压缩行存储）格式类。支持矩阵-向量乘法、转置乘法、与稠密矩阵互转；提供一维二阶差分稀疏矩阵的构建；共轭梯度法（CG）和 Jacobi 迭代求解稀疏线性系统。
- **unicycle_boundary.py**：边界执行器模型与序列分析。实现单轮车（unicycle）运动学模型及 RK4 积分；椭圆边界参数化、执行器定位与控制扩散到边界节点；Levenshtein 编辑距离、序列相似度评分，以及将连续控制值离散化以供比较的功能。

## 核心数据结构与接口

项目中的主要数据结构通过函数参数和返回值在模块间传递。关键对象包括：

- **网格**：节点坐标数组 `(n_nodes, 2)`，单元连接数组 `(n_elements, 3)`（逆时针方向），边界节点索引列表，边界边列表。
- **FEM 矩阵**：稠密的质量矩阵 `M`（节点基函数内积）、刚度矩阵 `A`（梯度内积）和边界控制矩阵 `B`（边界基函数内积，包含扩散系数 ν），均为 `(n_nodes, n_nodes)` 方阵。
- **时间序列**：状态轨迹 `y_seq`、伴随轨迹 `p_seq`、控制序列 `q_seq`，形状分别为 `(n_time+1, n_nodes)` 和 `(n_time+1, n_boundary)`。
- **源项与期望状态**：函数对象 `f_fn(x,y,t)` 和 `yd_seq`（期望状态在全部时间步和节点的值）。
- **优化参数**：扩散系数 ν，非线性系数 c，控制代价系数 α，光滑系数 β，终止时间 T，时间步数 n_time。
- **稀疏矩阵**：CRSMatrix 对象，包含非零元数值数组 `val`、列索引数组 `col` 和行指针数组 `rowptr`。

## 主要算法流程

主程序 `main.py` 的顶层流程如下：

1. **几何与网格**：指定椭圆半轴，调用 `generate_ellipse_mesh_2d` 生成三角形网格（边界节点和内部节点），同时计算椭圆面积等几何量。
2. **FEM 组装**：调用 `assemble_fem_matrices` 获得 `M, A, B` 和边界边信息。
3. **问题数据**：定义时间离散（步数、步长），构造期望状态序列 `yd_seq` 和初始状态 `y0`。
4. **最优化**：以零控制初始化 `q_seq`，调用 `optimize_control` 执行梯度下降迭代。每一次迭代中：
   - 求解状态方程（前向隐式欧拉，含 Picard 线性化的非线性项）。
   - 求解伴随方程（后向隐式欧拉）。
   - 计算梯度（边界上 α q + p + β 拉普拉斯光滑项）。
   - 评估目标泛函 `J`。
   - 执行 Armijo 线搜索以确定步长，更新控制。
5. **验证与输出**：运行一系列独立验证，包括梯形积分验证、Romberg 积分验证、敏感 ODE 验证、Lambert W 验证、QMC 积分验证、稀疏矩阵求解验证、执行器模型演示、编辑距离分析以及六面体求积规则测试等。最后将最优状态和伴随状态以 TECPLOT 格式写出。
