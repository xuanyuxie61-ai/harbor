## 项目描述

# 项目概述

本项目实现了一个基于高阶间断 Galerkin 方法的三维守恒律求解器，支持非结构化四面体网格。主要能力包括：

- 求解可压缩 Euler 方程（欧拉方程）和标量线性对流方程。
- 使用模态（正交）或节点（拉格朗日）基函数在参考四面体上构造高阶近似。
- 提供多种数值通量（Rusanov、Roe），并支持 slope 限制器和熵粘度捕捉。
- 包含网格生成、时间推进（显式 Runge‑Kutta 族）、自适应步长策略、后验误差估计和收敛性分析。
- 融合了整数算术、稀疏矩阵、蒙特卡洛积分、径向基函数（RBF）重构等辅助模块。

程序入口文件为 `main.py`，它通过调用上述模块完成一次完整的验证流程：生成网格、初始化 DG 求解器、投影初值、时间推进、误差估计与结果输出。其余 `.py` 文件为功能模块，需要在 benchmark 中根据本描述予以复现。


# 文件职责与模块边界

## `dg_basis.py` — 多项式基函数

提供一维和三维参考单元上的基函数构建。

- 一维 Lagrange 基：基于 Chebyshev 极值点生成节点，计算 Lagrange 基函数值及插值。
- 离散正交多项式（Gram 多项式）：等距横坐标上的三项递推生成正交多项式，可求系数、多点求值以及投影到多项式空间。
- 三维模态基 `ModalBasisTet`：给定多项式阶数，生成参考四面体上的正交多项式基函数。通过多指标遍历所有自由度，利用数值积分（四面体 Gauss 规则）和修正 Gram‑Schmidt 过程正交化，并预计算梯度（有限差分）。提供 `evaluate` 和 `gradient` 方法。
- 三维节点基 `NodalBasisTet`：在四面体内部生成均匀节点，通过范德蒙德矩阵将模态基转换为节点拉格朗日基，支持任意点求值。

## `dg_solver.py` — 三维 DG 守恒律求解器

核心类 `DGSolver3D`，针对 Euler 方程（5 个守恒变量）实现空间离散。

- 初始化时接收 `TetrahedralMesh` 和多项式阶数，选择模态或节点基，并预计算体积/面高斯积分点、物理坐标、雅可比、基函数及其梯度。
- 投影初值函数 `set_initial_condition` 通过求解局部质量矩阵完成 L2 投影。
- 右端项计算 `compute_rhs`：对每个单元循环体积积分（物理通量散度/源项），对面循环数值通量（Rusanov 或 Roe）。边界处理支持反射壁或给定边界函数。最后乘以质量矩阵的逆。
- 斜率限制器 `apply_limiter`：基于单元平均值和邻居单元平均值，利用最小二乘梯度重建和 minmod 限制
