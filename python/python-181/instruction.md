# 项目描述：各向异性流形降维与拓扑特征分析框架（python-181）

该项目实现了一个高维数据流形降维和特征提取的集成框架，融合了非线性薛定谔方程谱分析、几何积分、离散代数编码、拓扑不变量计算等多种数学工具。主入口 `main.py` 生成合成流形数据，依次调用多个功能模块进行采样、近邻图构建、谱嵌入、球谐分析、几何积分、梯度流特征选择、拓扑特征提取、曲线参数化、分段常数密度估计和布尔特征编码，并最终计算降维质量指标。

后续 benchmark 将保留 `main.py`，删除其他模块源文件（即所有非 `main.py` 的 `.py` 文件）。待实现者需要根据本描述复现这些缺失模块。

## 模块间主要依赖关系

- `main.py` 依赖于所有其他模块。
- `schroedinger_embedding.py` 使用 `linear_algebra_core.py` 的 Jacobi 特征值分解和 Cholesky 求解；它还调用 `neighbor_graph.py` 中的 k 近邻图和图 Laplacian 构建。
- `discrete_algebra.py` 中的 `lights_out_feature_transform` 调用了 `topological_invariants.py` 中的 `lights_out_matrix`。
- `topological_invariants.py` 使用了 `linear_algebra_core.py` 中的 Jacobi 特征值分解进行 PCA 降维。
- 多数模块依赖于 NumPy，部分模块还使用了 `typing`。

## 核心数据结构与约定

- 所有数据集均表示为二维 NumPy 数组，形状为 `(N, D)`，其中 N 为样本数，D 为特征维数。
- 图结构以边列表 `(M,2)` 整数数组和对应权重 `(M,)` 浮点数组表示。
- 图 Laplacian 以方阵 `(N,N)` 返回。
- 几何网格点以 `(N, D)` 数组返回。
- 求积规则以节点 `(K, D)` 和权重 `(K,)` 数组成对返回。
- 时间序列轨迹以 `(n_steps+1, state_dim)` 数组表示。
- 大部分计算使用双精度浮点数。
