# Thermodynamic-Geometric Collaborative Filtering (TGCF) 项目描述

## 总体介绍
本项目是一个前沿推荐系统协同过滤流程，融合了热力学、几何、准周期动力学、有限元方法、CORDIC 快速计算、Hilbert 曲线哈希、多项式混沌不确定性量化等多种科学计算技术。主入口文件 `main.py` 负责按阶段串联调用各模块，生成合成数据、执行模型填充与评估。除 `main.py` 外的所有模块源文件（`.py`）将被删除，需根据本描述重新实现其功能与接口。

## 模块说明

### aggregate_stats.py
提供 `AggregateStatistics` 类，负责用户分组与聚合统计。  
核心功能：  
- 基于用户嵌入向量，使用 K‑means 风格的分组算法（采用 K‑means++ 初始化与 Lloyd 迭代）将用户聚类。  
- 依据分组标签，对评分矩阵计算每组的均值、标准差、最小值、最大值和有效计数，处理缺失值。  
- 提供一种流式聚合方法，支持对键‑值对序列在线更新统计量（和、计数、最小、最大、均值）。  
- 对一组嵌入向量计算简单平均向量。

### cordic_engine.py
提供 `CordicEngine` 类，利用 CORDIC 算法实现快速三角函数、指数、对数、平方根计算，避免硬件乘法。  
核心功能：  
- 旋转模式：通过一系列伪旋转与幅值修正，计算给定角度的余弦和正弦。角度会自动归一化以保证收敛。  
- 指数模式：将指数分解为整数部分和小数部分，结合预计算的指数表与小量相乘，并使用残留泰勒修正。  
- 对数模式：通过反复缩放参数并与预计算表比较，构建对数分量，再用泰勒展开修正余项。  
- 平方根：采用逐位逼近的二分搜索实现。  
- 基于上述近似计算用户‑物品的 RBF 相似度核矩阵。

### fem_embedding.py
提供 `FemEmbeddingInterpolator` 类，将用户潜空间视为低维流形，使用基于 3D 有限元的插值填充评分矩阵。  
核心功能：  
- 对填充了行均值的评分矩阵进行 SVD 降维，得到用户的三维坐标。  
- 对坐标点进行 Delaunay 四面体剖分。  
- 对每个缺失评分位置，寻找包含该点的四面体，通过重心坐标（体积坐标）对四个顶点的已知评分进行加权平均实现插值。  
- 若点位于凸包外或退化情况，降级为最近邻填充。  
- 辅助方法包括计算四面体体积与重心坐标。

### gaussian_solver.py
提供 `RobustGaussianSolver` 类，实现带部分主元选取的高斯消元，用于求解线性系统、PLU 分解、行列式与逆矩阵。  
核心功能：  
- 在增广矩阵上执行消元与回代求解 Ax = b，通过部分主元提升数值稳定性，支持多右端项。  
- 计算方阵的 PLU 分解 (PA = LU)，记录行交换并返回 P、L、U。  
- 基于 PLU 先后求解 L y = P b 与 U x = y。  
- 从 U 对角线与置换次数推导行列式值。  
- 通过逐列求解获得矩阵的逆，并在奇异时降级为伪逆。

### geometric_sampler.py
提供 `GeometricSampler` 类，集成了与推荐多样性分析相关的几何采样与蒙特卡洛积分。  
核心功能：  
- 在单位圆上均匀采样及限定正象限的采样。  
- 计算单位圆上单项式积分的解析结果（利用对称性与 Gamma 函数）。  
- 蒙特卡洛估计圆上任意函数的积分值。  
- 估计正象限圆上随机点对距离的均值与方差，用于度量多样性。  
- 计算三维空间中平行四边形和四边形的面积（基于叉积与 Varignon 中点构造）。  
- 计算平面与四面体的交线/交面：根据顶点到平面的有符号距离确定交点，并重组为凸多边形。

### heat_diffusion.py
提供 `HeatDiffusionRecommender` 类，将评分矩阵视为二维温度场，通过求解热传导方程传播信息并填充缺失值。  
核心功能：  
- 构建离散拉普拉斯算子（五点差分），边缘使用 Neumann 零通量边界；已知评分位置作为固定 Dirichlet 条件。  
- 时间离散采用后向 Euler，对每个时间步构造隐式系统，并用 Jacobi 迭代求解，保持已知值不变。  
- 输出扩散后的完整评分矩阵。

### hilbert_hashing.py
提供 `HilbertLSH` 类，基于三维 Hilbert 空间填充曲线实现局部敏感哈希，用于加速近邻搜索。  
核心功能：  
- 将三维整数网格坐标通过递归的象限映射与变换转换为唯一的一维 Hilbert 索引。  
- 对一批三维向量进行最大‑最小归一化与量化，然后计算 Hilbert 哈希值。  
- 基于哈希索引排序与二分查找，为每个用户返回哈希空间中 top‑k 候选物品作为近似近邻。

### laguerre_chaos.py
提供 `LaguerrePolynomialChaos` 类，使用 Laguerre 多项式构建广义多项式混沌展开，量化评分不确定性。  
核心功能：  
- 利用三项递推关系在任意点处计算 0 至指定阶的 Laguerre 多项式值。  
- 通过构造对应 Jacobi 矩阵并结合 Newton 迭代求解，生成 Gauss‑Laguerre 求积节点和权重。  
- 计算指数加权或幂次加权的 Laguerre 内积表（用于表达二阶统计量）。  
- 将观测评分投影到多项式基上，利用正交性合成展开系数并估计预测方差。

### quasiperiodic_dynamics.py
提供 `QuasiperiodicPreferenceDynamics` 类，建模用户偏好随时间演化的准周期行为。  
核心功能：  
- 基于一个四阶线性常微分方程（特征频率包含 1 和 π，不可公约），给出由余弦项叠加而成的精确解析解。  
- 提供右端项函数，供数值积分器使用。  
- 使用经典四阶 Runge‑Kutta 方法（固定步长）数值积分该 ODE。  
- 结合解析解生成一个时间调制因子，用于调整基础偏好。

### string_similarity.py
提供 `StringSimilarityEngine` 类，基于编辑距离为冷启动提供文本相似度。  
核心功能：  
- 使用完整动态规划矩阵计算两个字符串的 Levenshtein 编辑距离。  
- 将编辑距离归一化为 [0,1] 的相似度。  
- 计算字符串列表的成对相似度矩阵，并按需返回 top‑k 最相似项。

### triangulation_boundary.py
提供 `TriangulationBoundaryDetector` 类，通过 Delaunay 三角剖分识别用户嵌入空间中的边界节点。  
核心功能：  
- 从三角形列表提取所有有向边，排序后统计每条边的出现次数，区分内部边（出现两次）与边界边（仅一次），并保留原始方向。  
- 将边界边列表贪心地连接成闭合边界路径。  
- 对二维点集执行 Delaunay 三角剖分，提取边界节点集合（用于识别利基用户社区）。

### truncated_distribution.py
提供 `TruncatedNormalRatingModel` 类，为有界评分（如 1~5）建立截断正态分布模型。  
核心功能：  
- 基于正态分布的 CDF 和 PDF 计算截断后的概率密度、解析均值与方差。  
- 采用逆 CDF 变换生成符合截断正态分布的随机样本。  
- 能够根据一个预测均值重新计算对应的截断正态期望评分，并可裁剪至边界。
