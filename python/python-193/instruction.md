## 项目描述

# 项目描述：稀疏线性代数 HPC 优化框架

该项目是一个面向高维参数化反应扩散方程的稀疏线性代数高性能计算原型框架。它整合了网格生成、有限元装配、矩阵重排序、多层次预条件子构造、迭代求解、稀疏网格积分、稀疏格式 I/O 以及科学基准测试集。各个功能由独立的 Python 模块实现，并由主入口脚本 `main.py` 串联成完整的数值实验管线。

后续会保留 `main.py`，删除其他 `.py` 文件，要求 agent 根据此描述重新实现缺失的模块，使 `main.py` 能够正常运行并输出一致的实验结果。下面按照模块说明各文件的职责和提供的关键功能。

## 文件清单及职责

### `utils.py`
公共数学工具模块。
- 提供安全除法、整数舍入除法（用于任务划分）、各种特殊函数（双阶乘）等稳健数值例程。
- 提供基于给定权重函数（Legendre、Chebyshev、Hermite、Laguerre）的单项式精确积分公式，用于验证正交多项式对应的求积准确性。
- 包含弧长参数化、在一维有序数组中定位区间左端点的函数。
- 提供矩阵对称性检查和基于幂迭代的条件数估计。

### `mesh_cvt.py`
基于质心 Voronoi 网格（CVT）的二维网格生成与三角剖分模块。
- 实现密度加权的 Lloyd 迭代，生成在区域边界附近聚类的二维点集。
- 利用 Delaunay 三角剖分（优先调用 scipy，否则回退到简单扇形三角化）将点集转化为三角形单元。
- 包含网格质量评估函数（等边三角形度量为 1）和节点值到单元平均的转换函数。

### `fem_assembler.py`
有限元稀疏矩阵装配模块。
- 提供参考三角形上的 3 点和 7 点高斯求积规则，用于计算线性三角元的弱形式积分。
- `assemble_fem_matrices` 函数对给定的节点、三角形单元、扩散系数、反应系数和源项函数，组装全局刚度矩阵和载荷向量，默认采用分片常数近似并处理可能的退化单元。
- `apply_dirichlet_bc` 函数将 Dirichlet 边界条件强行施加到线性方程组，生成修改后的矩阵和右端项。
- `exactness_test_fem_quadrature` 验证三角形求积规则对多项式的精确度。

### `reordering.py`
稀疏矩阵重排序与置换分析模块。
- 实现反向 Cuthill-McKee (RCM) 排序算法，通过 BFS 和按度排序生成降低带宽的置换向量。
- 提供了根据置换向量对矩阵进行重排序的函数，以及带宽计算函数。
- 提供了随机置换的生成、置换循环分解和分析函数，能够统计随机置换的循环长度分布并与调和数理论期望对比。

### `preconditioner.py`
多层次预条件子构造模块。
- 构造 Jacobi 预条件子（返回对角元的倒数向量）和 SSOR 预条件子（以函数闭包形式提供求解操作）。
- 构造一维分段线性延拓算子，用于几何多重网格。
- 实现几何粗化（基于 Morton 序选取粗节点），并用最近邻插值生成二维延拓。
- 实现多重网格 V-cycle，支持 Jacobi 前后光滑，递归进行粗网格校正或粗层直接求解。

### `iterative_solver.py`
迭代稀疏线性求解器模块。
- 实现了 PCG（预条件共轭梯度）求解器，支持用户给定的预条件子函数（如 Jacobi、SSOR、多重网格）以及模拟并行矩阵向量乘的任务划分。
- 实现了 GMRES(m) 求解器，适用于非对称系统，支持重启。
- 任务划分函数基于 `i4_div_rounded` 实现负载平衡的行分块策略。

### `sparse_formats.py`
稀疏矩阵格式读写与转换模块。
- 支持以 Matrix Market 坐标格式或数组格式读写稀疏/稠密矩阵，能处理对称、反对称、厄米性等结构符号，并自动扩展。
- 支持将稠密矩阵导出为 Harwell-Boeing 格式（CSC 存储），包括列指针、行索引、数值以及可选的右侧向量。
- 提供 COO 到 CSR 的转换和 CSR 格式的矩阵向量乘。

### `sparse_grid.py`
稀疏网格求积模块（Smolyak 构造）。
- 实现基于 Clenshaw-Curtis 节点的 Smolyak 组合公式，可在 d 维超立方体上生成稀疏网格点集和对应积分权重。
- 提供函数积分接口，直接在稀疏网格上求和。
- 实现自适应稀疏网格精细策略，基于连续层级积分差值作为层次盈余估计，根据容差自动决定停止层级。
- 含有一维层次盈余生成函数，用于插值误差分析。

### `benchmark_suite.py`
基准测试矩阵生成模块。
- 提供多个具有明确物理或数学背景的线性系统生成器：
  - **logistic 反应扩散矩阵**：一维 Dirichlet 边界的有限差分离散，生成三对角 SPD 矩阵。
  - **Feynman-Kac 确定性有限差分矩阵**：一维随机 PDE 的参考有限差分离散，右侧需考虑边界条件。
  - **Chirikov 标准映射系综平均矩阵**：由混沌映射的雅可比平均构成 2×2 块，并经过对角修正后平铺成更大系统。
  - **Menger 海绵层次矩阵**：递归构造具有自相似块结构和衰减耦合的层次 SPD 矩阵。
  - **糖果循环矩阵**：基于 `mod(i+j, block_size)` 的稀疏结构，施加对角占优。
- 提供 Feynman-Kac 方程的精确解函数和基于 Monte-Carlo 的随机求解器，用于验证确定性近似。
- `generate_all_benchmark_matrices` 将上述矩阵组合成字典返回，供主流程统一测试。

### `main.py`
项目集成入口。
- 按固定流程调用各模块：
  1. 调用 `mesh_cvt` 生成 CVT 网格并进行 Delaunay 三角化。
  2. 调用 `fem_assembler` 在变系数扩散反应问题上装配 FEM 矩阵和右端项，并施加 Dirichlet 边界。
  3. 调用 `reordering` 进行 RCM 重排序，展示带宽缩减效果，并进行随机置换的循环统计。
  4. 调用 `preconditioner` 构造 Jacobi、SSOR 和（如可能）多重网格预条件子，并用 `iterative_solver` 中的 PCG 求解，比较迭代次数。
  5. 调用 `sparse_grid` 进行高维稀疏网格积分，并验证一维求积公式的精确性。
  6. 调用 `sparse_formats` 将 FEM 矩阵写入 Matrix Market 和 Harwell-Boeing 文件，读回验证，并演示 CSC 格式转换。
  7. 调用 `benchmark_suite` 生成所有基准矩阵，用 PCG 求解并报告迭代数与残差，同时验证 Feynman-Kac 随机求解和 logistic 稳态解。
- 最终输出所有科学公式和度量摘要，无任何外部命令行参数。

## 核心算法与数学背景概括

- **网格与离散化**：基于质心 Voronoi 网格生成二维点云，利用 Delaunay 三角剖分形成线性三角形单元。扩散反应方程经 Galerkin 有限元离散，单元刚度矩阵由扩散项和反应项组成，在参考三角形上使用高斯求积或解析公式计算。
- **稀疏矩阵处理**：支持 CSR/CSC 等稀疏格式，可进行 Matrix Market 和 Harwell-Boeing 的读写；使用 RCM 重排序降低带宽，改善直接法或预条件子的效率。
- **预条件迭代**：预条件共轭梯度法求解 SPD 系统，提供对角、SSOR 和基于延拓的几何多重网格预条件子。多重网格 V-cycle 在细网格上光滑高频误差，粗网格校正低频误差。
- **不确定性量化与积分**：Smolyak 稀疏网格在 d 维超立方体上构建嵌套积分点，用于高维参数积分，自适应版本可依据层次盈余控制截
