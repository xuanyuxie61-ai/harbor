# 项目描述：内存受限外排序算法

## 项目目标
本项目构建一个可处理超大规模异构科学数据流的内存受限外排序流水线。模拟场景为高能物理实验中产生的粒子事件数据，数据记录数远大于可用内存容量。系统需要在外部存储约束下完成全序排列，为后续物理分析提供有序数据流。  
整个流水线包含：异构数据生成、Toeplitz变换预处理、自适应分区估计、替换选择与多路归并排序、分区优化与约束满足、数值稳定性分析以及缓冲区动力学预测。

**关键约束**：内存可容纳的记录数（M）远小于总记录数（N）。主要入口位于 `main.py`，该文件将保留；其他 `.py` 模块需根据本描述重新实现。

## 文件结构与职责

### `main.py` (保留)
- **流程编排**：按顺序调用各模块，输出评估结果。
- 不包含具体算法实现，只负责参数配置、调用子模块、格式化和打印诊断信息。

### `utils.py`
- **基础工具库**：提供数值鲁棒操作、素数生成、哈希种子构造、分布评价函数。
- 主要功能：
  - Miller‑Rabin 素性测试与素数生成。
  - 通用哈希函数族种子生成（基于素数）。
  - 安全的除法、平方根、边界裁剪。
  - 最大公约数（欧几里得算法）。
  - 熵与 KL 散度计算，用于负载均衡评估。

### `data_generator.py`
- **异构科学数据生成器**：模拟 LHC 探测器输出，产生复合键记录。
- 包含的模型与函数：
  - 圆周蒙特卡洛积分（含 Gamma 函数精确积分验证）。
  - SIR 传染病模型（模拟数据流传播，用显式 Euler 法积分）。
  - Logistic 混沌映射生成序列（带参数控制动力学行为）。
  - `generate_heterogeneous_dataset`：按指定总量和内存上限生成记录，每条记录包含时间戳、动量分量、能量、噪声键等复合字段。

### `toeplitz_solver.py`
- **下三角 Toeplitz 矩阵运算**：用于键值预处理，增强数据的时间/空间相关性。
- `R8LTTSolver`：由第一列构造矩阵，支持矩阵‑向量乘、前向替换求解、行列式、逆矩阵、条件数估计。
- 辅助函数：构造带指数衰减权重的前缀矩阵，对键值序列施加 Toeplitz 变换。

### `adaptive_sampler.py`
- **自适应采样与分区边界估计**：融合直方图、RBF 插值、有限元投影和二维多边形采样。
- 主要类：
  - `HistogramPDFSampler`：基于等宽直方图的概率密度估计，支持逆 CDF 分位数和分区边界生成。
  - `RBFInterpolator`：径向基函数（高斯、多二次、逆多二次、薄板样条）全局插值，内部用高斯消元求解权重。
  - `FEM1DProjector`：一维分段线性有限元 Galerkin 投影，用 Gauss‑Legendre 积分和 Thomas 算法求解三对角系统。
  - `PolygonPartitionSampler`：二维多边形耳切法三角剖分及面积加权采样。
  - `adaptive_partition_estimation`：组合直方图粗估计和可选的 RBF 平滑，输出分区分位数边界。

### `external_sort_engine.py`
- **外排序核心引擎**：实现替换选择生成初始归并段，以及 k 路归并（败者树/堆）。
- 类/函数：
  - `ReplacementSelection`：模拟替换选择算法，用最小堆和死区记录生成若干有序归并段。
  - `KWayMerge`：使用堆（替代败者树）执行多路归并，输出全序列表。
  - `PiecewiseConstantPartition`：根据边界将键值快速分到固定区间（二分查找）。
  - `ExternalSortPipeline`：整合替换选择 → 多路归并，提供理论 I/O 代价估计（Aggarwal‑Vitter 模型）。
  - `verify_sorted`：检查记录是否按指定键非递减排序。

### `partition_optimizer.py`
- **数据分区优化与约束满足**：借鉴覆盖约束思想，求解近似平衡的分区分配。
- 主要内容：
  - `CoverConstraintSolver`：贪心算法将数据块分配到容量受限的分区，支持平衡度评分。
  - `HashPartitioner`：基于素数哈希的均匀分区。
  - `AdaptivePartitionOptimizer`：结合分布采样、边界估计和贪心调整，输出最终分区边界和每记录的分配。
  - `optimal_page_alignment`：利用 GCD 计算页对齐的最优块大小。

### `stability_analyzer.py`
- **数值稳定性与动力学分析**：评估 Euler 法截断误差、Logistic 映射混沌特性、SIR 模型稳定性以及排序过程倾斜度。
- 类/函数：
  - `EulerErrorAnalysis`：局部截断误差估计、全局误差界、推荐步长。
  - `LogisticBifurcationAnalyzer`：不动点、Lyapunov 指数计算、混沌判定。
  - `SIRStabilityAnalyzer`：基本再生数 R₀、地方病平衡点、Jacobian 特征值近似。
  - `SortStabilityMonitor`：分区倾斜度、归并段长度变异系数、溢出风险评估。

### `stream_dynamics.py`
- **数据流缓冲区动力学预测**：将内存/外存数据交换建模为受迫振动和双曲型守恒律。
- 主要内容：
  - `ArteryFlowModel`：二阶受迫阻尼振动方程，Euler 法求解，提供稳态解析振幅。
  - `LaxWendroffBuffer`：Lax‑Wendroff 格式模拟数据密度对流，满足 Courant 稳定性条件。
  - `predict_optimal_buffer_size`：结合稳态偏移与振幅，乘以安全系数输出最优缓冲区大小。

## 模块依赖与数据流
1. `main.py` 配置参数并依次执行各阶段。
2. **数据生成**：`data_generator` 产生异构记录列表（每条为多元组）。
3. **键值预处理**：`toeplitz_solver` 对排序键施加指数衰减变换。
4. **分区估计**：`adaptive_sampler` 从采样键中估计均衡分区边界。
5. **外排序**：`external_sort_engine` 对全量数据执行替换选择 + 多路归并，得到有序列表。
6. **分区优化**：`partition_optimizer` 使用边界或哈希进行分区，并用贪心算法调整负载均衡；提供页对齐建议。
7. **稳定性分析**：`stability_analyzer` 评估排序过程中的误差、混沌风险和分区倾斜。
8. **缓冲预测**：`stream_dynamics` 利用动脉模型和 Lax‑Wendroff 格式预测最优缓冲大小。
9. 所有模块均可能调用 `utils` 中的素数、哈希种子、安全运算和分布度量函数。

## 关键算法与数据结构摘要（不提供实现细节）
- **替换选择（Replacement Selection）**：利用堆和“死区”生成平均长度约为 2M 的初始归并段。
- **k 路归并**：通过最小堆（模拟败者树）在多段间选出全局最小记录，多趟归并直至只剩一个有序序列。
- **直方图 PDF / 逆 CDF**：等宽分箱估计密度，二分查找或线性搜索实现分位数。
- **RBF 插值**：构造距离矩阵，高斯消元求权，用于平滑 CDF。
- **FEM 投影**：分段线性基函数，Gauss‑Legendre 积分组装质量矩阵，Thomas 算法快速求解。
- **Toeplitz 系统**：仅存第一列，利用下三角结构进行矩阵‑向量乘和前向替换。
- **Euler 法**：一阶显式步进，与理论局部/全局误差分析相结合。
- **Logistic 映射**：参数 r 控制分岔与混沌
