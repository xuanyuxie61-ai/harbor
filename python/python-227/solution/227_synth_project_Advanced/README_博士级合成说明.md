# PROJECT_227 — 计算高能物理：粒子径迹重建与 Kalman 滤波拟合

## 博士级合成项目说明文档

**项目主题**: 高阶有限差分与稳定性分析（小规模可复现实验）

**学科领域**: 计算高能物理 (Computational High-Energy Physics)

**核心问题**: 带电粒子在螺线管磁场中的径迹重建，使用扩展 Kalman 滤波 (EKF) 与高阶数值传播方法，并进行数值稳定性与收敛性分析

---

## 一、项目概述

本项目融合 15 个种子项目的核心算法，构建完整的带电粒子径迹重建流水线。模拟 LHC 型硅微条追踪探测器中的 π⁺ 介子径迹，实现从探测器几何建模、磁场计算、击中模拟、Kalman 滤波重建到数值稳定性分析的全流程。

### 科学问题深度

项目涉及的高能物理核心计算问题包括：

1. **非线性状态估计**: 扩展 Kalman 滤波 (EKF) 在非高斯、非线性系统中的递推最优估计
2. **刚性常微分方程**: 带电粒子在强磁场中的运动方程 (Lorentz ODE) 的数值求解
3. **物质效应建模**: Bethe-Bloch 电离能量损失、Highland 多次散射、Landau 涨落
4. **统计推断**: χ² 似然推断、p-value 假设检验、参数后验估计
5. **数值稳定性**: 向后 Euler 收敛性、放大矩阵谱半径、条件数估计、扰动传播

## 三、核心物理模型与数学公式

### 3.1 带电粒子在磁场中的运动

**Lorentz 力方程** (状态向量 y = (x, y, z, p_x, p_y, p_z)):

```
dp/dt = q · (v × B)
dx/dt = v = p / (γm)
```

**螺旋线精确解** (均匀场 B = B₀ẑ):

```
x(t) = r_L · sin(ωt + φ₀) + x_c
y(t) = r_L · cos(ωt + φ₀) + y_c
z(t) = v_z · t + z₀
```

其中:
- r_L = p_T / (qB) 为 Larmor 半径
- ω = qB / (γm) 为回旋频率

### 3.2 Track 参数化

5维状态向量: **x = (κ, tanλ, φ, d, z₀)^T**

| 参数 | 物理意义 | 单位 |
|------|---------|------|
| κ = q/p_T | 横向曲率 | 1/mm |
| tan λ | 偶极角正切 | - |
| φ | 方位角 | rad |
| d | 横向冲击参数 | mm |
| z₀ | 纵向冲击参数 | mm |

### 3.3 Extended Kalman Filter (EKF)

**预测步骤**:
```
x̃_{k|k-1} = f(x̂_{k-1})                     (非线性传播)
C̃_{k|k-1} = F_k · Ĉ_{k-1} · F_k^T + Q_k   (协方差传播)
```

**更新步骤** (Joseph 形式保证数值稳定):
```
r_k = m_k - H_k · x̃_{k|k-1}               (残差/创新)
G_k = H_k · C̃ · H_k^T + V_k               (创新协方差)
K_k = C̃ · H_k^T · G_k^{-1}                 (Kalman 增益)
x̂_k = x̃ + K_k · r_k                       (状态更新)
Ĉ_k = (I-KH)·C̃·(I-KH)^T + K·V·K^T         (Joseph 形式)
χ²_k += r_k^T · G_k^{-1} · r_k              (χ² 递推)
```

**后向平滑** (Rauch-Tung-Striebel):
```
A_k = Ĉ_k · F_{k+1}^T · C̃_{k+1|k}^{-1}    (平滑增益)
x̂^s_k = x̂_k + A_k · (x̂^s_{k+1} - x̃_{k+1|k})
```

### 3.4 Bethe-Bloch 电离能量损失

```
-dE/dx = K·z²·(Z/A)·(ρ/β²)·[½·ln(2m_e·c²·β²γ²·T_max/I²) - β² - δ/2]
```

其中:
- K = 4π·N_A·r_e²·m_e·c² = 0.307075 MeV·cm²/g
- T_max = 2·m_e·c²·β²γ² / [1 + 2γ·m_e/M + (m_e/M)²]
- δ 为密度效应修正 (Sternheimer 参数化)

### 3.5 Highland 多次散射

```
θ₀ = (13.6 MeV / βcp) · z · √(x/X₀) · [1 + 0.038·ln(x/X₀)]
```

### 3.6 数值传播方法

**RK4** (经典 4 阶 Runge-Kutta):
```
k₁ = h·f(tₙ, yₙ),  k₂ = h·f(tₙ+h/2, yₙ+k₁/2)
k₃ = h·f(tₙ+h/2, yₙ+k₂/2),  k₄ = h·f(tₙ+h, yₙ+k₃)
yₙ₊₁ = yₙ + (k₁ + 2k₂ + 2k₃ + k₄)/6
```

**向后 Euler + Picard** (来自 [064]):
```
y_{n+1} = y_n + dt · f(y_{n+1})
Picard: yp^(j+1) = y_n + dt · f(yp^(j)),  j = 0, ..., it_max-1
```

**ETDRK4** (来自 [614]):
```
E = exp(dt·L),  E₂ = exp(dt·L/2)
将运动方程分为线性 (精确积分) + 非线性 (RK4)
```

### 3.7 稳定性分析

**向后 Euler 收敛条件**: ||∂f/∂y|| · dt < 1

**滤波放大矩阵**: G_k = (I - K_k·H_k)·F_k
**稳定条件**: 谱半径 ρ(G) < 1

**条件数**: cond(C) = λ_max / λ_min

**状态转移矩阵**: Φ(n,0) = Π_{k=0}^{n-1} F_k

## 六、科学计算难度说明

### 6.1 数学难度

- **非线性矩阵递推**: Kalman 滤波的协方差更新涉及 5×5 矩阵求逆、乘法、Joseph 稳定化
- **刚性 ODE**: 强磁场中粒子的回旋频率可达 10^9 rad/s，与传播步长形成刚性系统
- **多重积分**: χ² 似然积分需要在 5 维参数空间上进行 Gauss 求积
- **特征值问题**: 放大矩阵谱半径计算涉及非对称矩阵的特征值分解
- **动态规划**: Levenshtein 编辑距离在 (m+1)×(n+1) 矩阵上的递推

### 6.2 物理深度

- **相对论运动学**: γ 因子可达 ~16 (2 GeV π介子)，需精确处理 β → 1 极限
- **量子效应**: Landau 涨落、密度效应修正、壳修正
- **量子色动力学**: 多次散射的 Molière 理论、辐射修正
- **探测器物理**: 辐射长度、电离能损、空间分辨率的参数化

### 6.3 工程复杂性

- **11 个模块的协同**: 每个模块职责单一，通过清晰接口组合
- **边界处理**: 协方差正则化、零动量保护、角度范围限制
- **数值鲁棒性**: Joseph 形式、Tikhonov 正则化、log-sum-exp 技巧
- **可复现性**: 固定随机种子，确定性输出

## 七、边界条件与鲁棒性处理

| 边界场景 | 处理方法 |
|---------|---------|
| 零动量粒子 | β → 0 时 Bethe-Bloch 返回 0 |
| 协方差矩阵奇异 | Tikhonov 正则化 A + εI |
| 磁场超出范围 | 返回 B = 0 |
| 击中超出层接受范围 | 跳过该层 |
| 向后 Euler 发散 | 限制最大迭代次数 it_max |
| χ² 过大 | 输出诊断警告 |
| 条件数过大 | 特征值截断 + 伪逆回退 |
| 死道/热道 | 返回 None (击中丢失) |

## 九、唯一性说明

本项目在以下方面区别于其他合成项目:

1. **领域独特性**: 唯一聚焦计算高能物理的径迹重建问题
2. **算法融合深度**: 不是简单换皮，而是将 15 个算法深度嵌入 EKF 流水线的各个环节
3. **物理公式密度**: 每个模块都包含完整的物理公式推导和实现
4. **数值方法多样性**: 融合显式 (RK4)、隐式 (向后 Euler)、指数积分 (ETDRK4) 三类方法
5. **诊断完备性**: 提供 χ² 检验、pull 分析、谱半径、条件数等多维诊断
